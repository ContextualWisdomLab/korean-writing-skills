# APA 7 학술 논문 작성

먼저 [근거 장부](references/source-ledger.md)의 확인 범위를 읽는다. JARS-Quant Table 1은 Appelbaum et al.(2018) task force report(S8)와 APA 공식 2024 표(A-JARSQ)에서 확인했다 — [jars-quant-table1.md](references/jars-quant-table1.md). 통계·참고문헌 안내서(A-NUM·A-REF)와 Manual 7판에서 직접 연 절(2.1·2.2·2.8·2.12·2.18–2.24, 6.36·6.44, 7.1·7.4·7.5·7.6·7.17·7.18, 8.4·8.10, 10.1–10.3 도입)만 세칙으로 쓴다. 학생 논문 안내(A-STU)만으로 투고본을 수용하지 않는다. 한글 글꼴·개별 절 인쇄쪽은 미확인이다. 투고 서식·DOCX/HWPX 생성 점검은 [document-format-checklist.md](references/document-format-checklist.md)를 따른다. 고정 렌더 PNG 전쪽 점검은 그 파일의 구현 검증 절이며 8.4 인용 규칙이 아니다. 이 스킬을 APA 7 전체 규칙이나 JARS 전체 적합성 인증으로 사용하지 않는다. 확인하지 못한 서식·쪽수·보고 의무는 원문을 확보한 뒤 적용한다.

## 적용 범위를 정한다

원고 언어, 논문 유형, 대상 학술지와 최신 투고 규정, 연구 질문, 분석 산출물, 인용 자료를 확인한다. 없는 자료는 필요한 위치에 `[확인 필요: 자료명]`으로 남긴다.

| 근거 | 적용 범위와 충돌 처리 |
| --- | --- |
| 학술지 투고 규정 | 초록 길이, 익명화, 항목 순서, 파일·인용 형식을 해당 투고에 적용한다. APA와 다르면 차이를 기록하고 학술지 규정을 따른다. 연구 사실을 바꾸는 근거로 쓰지 않는다. |
| 한국어 어문 규정 | 한국어 맞춤법·띄어쓰기·문장 부호에 적용한다. 전문용어·고유명·직접 인용과 충돌하면 원문과 용례를 확인한다. |
| APA 7 및 JARS | 실제 확인한 출처의 범위에서 보고·인용·표시 관례를 적용한다. 영어 문법·대문자 규칙을 한국어 어순에 직역하지 않는다. |
| 편집 판단·사용자 문체 | 논리와 가독성을 개선한다. 피동·명사화·한자어를 일괄 금지하지 않는다. 짧은 문장 선호를 공적 규정으로 표기하지 않는다. |

## 증거를 고정하고 구조부터 수정한다

1. 주장마다 `연구 질문 → 자료·분석 파일/버전 → 실제 결과 → 주장 가능 범위 → 원고 위치`를 연결한다. 다른 모델·표본·분석 버전의 수치를 합치지 않는다. 현재 프로젝트가 fast-mlsirm 결과만 허용한다면 그 제한을 적용하되 다른 프로젝트의 보편 규칙으로 만들지 않는다.
2. 아래 표로 문단의 역할과 증거를 점검한다. 논리·문단 → 문장 → 맞춤법·띄어쓰기·문장 부호 순으로 수정한다. 문장만 요청받았다면 구조 문제는 별도 의견으로 남긴다.

| 부분 | 편집 질문 |
| --- | --- |
| 제목·초록 | 연구 대상·설계·질문이 드러나는가? 초록의 방법·핵심 결과·결론이 본문과 같은 표본·수치·불확실성을 사용하는가? 길이와 구조는 학술지 규정을 확인했는가? |
| 서론 | 알려진 사실의 근거, 남은 문제, 이번 질문이 이어지는가? 탐색 결과를 사전 가설로 바꾸지 않았는가? |
| 방법 | 표본·모집·측정·설계·절차·분석 선택을 원자료로 추적할 수 있는가? IRB·동의·등록·제외 기준을 실제 기록으로 확인했는가? |
| 결과 | 연구 질문 순서로 추정치·불확실성·분석 대상을 제시했는가? 미완료 분석을 완료 결과로 쓰지 않았는가? |
| 논의 | 결과가 뒷받침하는 답, 선행연구와의 관계, 대안 설명, 제한, 함의를 구별했는가? 관찰된 관련성을 인과 효과로 바꾸지 않았는가? |

3. 문장 수정 전후에 주체·대상·방향·부정·조건·시간·수치·인용·전문용어를 대조한다. 행위자가 확인된 경우에만 능동문으로 바꾼다. 행위자를 확인할 수 없으면 원문을 유지하거나 `[확인 필요]`를 남기며 연구자나 참여자를 추정해 넣지 않는다.

## 양적 연구 보고와 표시를 점검한다

세부 작업에는 [보고·교정 절차](references/reporting-workflow.md)와 [JARS-Quant Table 1](references/jars-quant-table1.md)을 읽는다. 설계별 추가표는 S8 본문에서 해당할 때만 연다. 연구 설계에 맞는 공통표와 추가표를 선택하고 `원문 항목 | 원고 위치 | 근거 파일 | 충족/누락/해당 없음·이유`를 만든다. 아래 점검만으로 JARS 전체 충족을 주장하지 않는다.

표·그림의 숫자는 분석 산출물과 대조한다. 본문에 없는 새 결과를 만들지 않는다. 검증된 필수 수치는 칸에 채운다. 필수 결과 표를 삭제해 제출을 끝낸 것처럼 치지 않는다. 연구별 제출 차단(예: 라이브러리 미재현)과 APA 원문 규칙을 한 문장으로 섞지 않는다. 인용·참고문헌은 실제 읽은 자료와 서지정보를 대조한다. 제목이나 DOI만 보고 그 문헌이 주장을 뒷받침한다고 판단하지 않는다.

## 심사 응답과 인계

심사 의견별로 `의견 | 수용·부분 수용·이견 | 근거 | 실제 수정문 | 절·쪽·줄`을 작성한다. 분석 추가가 필요하면 계획과 수행 결과를 분리한다. 수행하지 않은 분석·수정은 완료했다고 답하지 않는다. 이견은 자료와 연구 범위로 설명한다. 최종 편집 후 위치를 다시 확인한다. 이 절은 편집 절차이며 APA의 고정 답변 양식이 아니다.

인계할 때 수정 원고, 의미에 영향을 주는 수정 이유, 누락 자료, 적용 규정 충돌, 검증 범위를 제공한다. 구조·의미·수치 검증과 APA 서식 검증을 구분한다. 결과·IRB·동의·유의성·서지정보를 빈칸 보충 목적으로 발명하지 않는다.
