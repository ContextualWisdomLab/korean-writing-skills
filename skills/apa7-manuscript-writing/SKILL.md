# APA 7 학술 논문 작성

먼저 [근거 장부](references/source-ledger.md)의 확인 범위를 읽는다. 연구팀에 제안을 넘길 때는 [확인 범위 한 장 요약](references/verified-scope.md)을 함께 준다. 실제로 확인한 절·쪽·자료만 근거로 사용한다.

## 적용할 근거를 확인한다

- **JARS-Quant Table 1:** Appelbaum et al.(2018)의 특별위원회 보고서(S8)와 APA 공식 2024 표(A-JARSQ)에서 확인했다. 항목은 [JARS-Quant 점검표](references/jars-quant-table1.md)를 따른다.
- **통계·참고문헌과 Manual:** 통계·참고문헌 안내서(A-NUM·A-REF)와 Manual 7판에서 직접 연 절(2.1·2.2·2.8·2.12·2.18–2.24, 6.36·6.44, 7.1·7.4·7.5·7.6·7.17·7.18, 8.4·8.10, 10.1–10.3 도입)의 확인 범위 안에서만 세칙을 적용한다. 아래에 적은 재열람 한계를 함께 따른다. Manual 8.6절은 2차 출처를 드물게 쓰라는 대목만 짧게 확인했다.
- **APA 공식 웹:** 2026-10-04에 직접 읽은 A-SECONDARY-WEB의 재인용 표기와 A-BIAS-WEB의 편견 없는 언어 일반 원칙은 [보고·교정 절차](references/reporting-workflow.md)에 한정해 적용한다. 2026-11-08에 직접 읽은 A-HEADER-WEB·A-PLAGIARISM-WEB·A-QUOTE-WEB는 아래 러닝헤드, 자료 출처 공개, 직접 인용의 위치 표기에 적용한다. 웹 안내를 확인한 것을 Manual 해당 절의 직접 열람으로 보고하지 않는다.

### 서식 재열람에서 확인한 내용

2026-09-21 14:31Z–14:45Z에 다시 읽은 범위는 다음과 같다. 러닝헤드의 적용 대상과 길이는 2026-11-08 공식 웹 A-HEADER-WEB로 보완했다.

| 항목 | 확인한 내용과 한계 |
| --- | --- |
| 2.8 러닝헤드·공식 웹 보완 | 전문 원고에는 적용하고, 학생 논문은 교수자나 기관이 요구하면 적용한다. 공백·문장 부호를 포함해 최대 50자, 대문자, 쪽머리 왼쪽이며 `Running head` 표지를 붙이지 않는다(A-HEADER-WEB). |
| 쪽번호 | 매뉴얼이 Section 2.18로 가리킨다. 모든 논문에 적용하며 오른쪽에 놓고 제목 쪽을 1로 센다. |
| 문단 간격 | “Do not add extra spacing between paragraphs.”라는 문장을 확인했다. 검색 결과에서는 `2.22 Margins` 바로 앞에 있었고, 장 목록의 앞 절 이름은 2.21 Line Spacing이다. |
| 2.22 여백 | 네 면에 1인치 여백을 둔다. |
| 2.1 필수 요소 | 표제 “Professional Paper Required Elements”만 다시 읽었다. 요소 목록은 재열람으로 확인한 세칙에 포함하지 않는다. |

이 재열람에서는 표 제목과 표 본문의 쪽 분리 금지를 확인하지 못했다. 그림 제목의 위치, 표의 계속 표지, 표 주 형식을 다루는 절도 열지 못했다. 그림과 제목이 다른 쪽에 있거나 행이 쪽을 가로지르면 조판에서 관찰한 문제로 기록하고, 확인하지 않은 APA 위반으로 채점하지 않는다.

### 서식 점검과 적용 한계

학생 논문 안내만으로 투고 원고의 서식을 승인하지 않는다. A-HEADER-WEB에서 러닝헤드의 학생 논문 예외를 확인했지만, 별도 학생 논문 안내서 전체를 읽은 것은 아니다. 한글 글꼴과 개별 절의 인쇄 쪽수도 아직 확인하지 못했다.

투고 서식과 DOCX/HWPX 생성은 [문서 형식 점검표](references/document-format-checklist.md)를 따른다. 같은 판본을 렌더링한 PNG로 모든 쪽을 확인하는 절차는 그 파일의 구현 검증에 속하며, 8.4의 인용 규칙이 아니다. 이 스킬은 APA 7이나 JARS 전체의 적합성을 인증하지 않는다. 확인하지 못한 서식·쪽수·보고 의무는 원문을 확보한 뒤 적용한다.

## 적용 범위를 정한다

원고 언어, 논문 유형, 대상 학술지와 최신 투고 규정, 연구 질문, 분석 산출물, 인용 자료를 확인한다. 학술 점검용 초안에서는 없는 자료를 필요한 위치에 `[확인 필요: 자료명]`으로 남긴다. 제출본을 요청받았다면 해당 자료를 확보하고 저자와 내용을 확정한다. 아직 확정하지 못한 항목을 완료한 것으로 보고하지 않는다.

학술지에 처음 제출하는 독립 원고를 현재형 자기 서술로 써 달라는 요청이 있으면, 이 연구의 질문·채택한 측정모형·분석·해석을 그 방식으로 쓴다. 앞선 학위논문을 고쳐 쓴 과정이나 그 논문의 쪽수를 이 원고의 본문·표·심사 응답 위치를 대신하는 대조 근거로 쓰지 않는다. 학위논문과의 대조 위치가 작업에 필요하면 투고 원고 밖의 출처 대조 기록에 보관한다. 현재형 자기 서술과 작업용 대조 기록의 분리는 원고에 대한 저자 요청이며 APA의 보편 규칙이 아니다. 다만 학위논문을 실제로 직접 인용한 구절에는 저자·연도·쪽수(쪽수가 없으면 다른 위치 정보)를 보존한다(A-QUOTE-WEB). 실제로 끝난 수집·절차의 시제까지 현재형으로 바꾸거나 수행하지 않은 분석을 현재형으로 확정하지 않는다.

**자료가 어디서 왔는지라는 출처 사실**(예: 이전 학위논문 연구에서 수집한 자료를 쓴다)은 경위와 구별한다. 자료의 출처·재사용·겹침은 본문 또는 저자 주 등 공개 원고에서 독자가 확인할 수 있는 위치에 남긴다. 학위논문을 전부 또는 일부 바탕으로 학술지 논문을 발표할 때는 그 기반 관계를 본문 인용 대신 저자 주에 밝힌다(A-PLAGIARISM-WEB). JARS-Quant Table 1의 Author Note에도 기존 출판물과 겹치는 자료와 학위논문·학회 논문의 선행 보고를 밝히는 항목이 있다(A-JARSQ). 본문 위치가 적절하지 않으면 다른 공개 위치로 옮기는 안을 저자에게 확인한다. 비공개 출처 기록이나 확인 요청만으로 공개 원고에 필요한 고지를 대신하지 않는다. 실제로 선행 출판된 연구와 필요한 인용도 사실대로 남긴다.

학위논문 경위를 빼더라도 이 연구 자체에 관한 사실은 교정문 본문에 남긴다. 결과가 아직 산출되지 않았으면 그 사실을 본문 문장으로 쓰고, 같은 자료로 이미 수행한 분석처럼 해석에 영향을 주는 절차(예: 탐색적 분석 뒤의 확인적 분석)는 작업용 학위논문 대조 쪽수 없이 중립적으로 적는다. 표현을 저자와 정해야 하면 본문 문장을 먼저 두고 확인 요청을 붙인다. 본문에 있어야 할 사실을 확인 요청으로만 옮기지 않는다.

척도·구성개념은 첫 언급에 확인된 한국어 이름과 필요한 약어·기호를 함께 정의하고, 뒤에도 독자가 이름을 알 수 있게 쓴다. `X`·`E` 같은 내부 변수명만으로 척도 이름을 대신하지 않는다. 변수와 척도의 대응·점수 방향은 원자료와 채점표에서 확인하며, 확인되지 않은 이름을 추정하지 않는다. 확인된 정식 명칭은 원고·표·심사 응답·보충 자료에서 한 가지로 일관되게 쓴다. 줄인 이름이나 비슷한 말로 바꿔 쓰지 않고, 이름 일부가 겹치는 다른 개념·하위 영역·도구 이름은 그 척도로 바꾸지 않는다.

| 근거 | 적용 범위와 충돌 처리 |
| --- | --- |
| 학술지 투고 규정 | 초록 길이, 익명화, 항목 순서, 파일·인용 형식을 해당 투고에 적용한다. APA와 다르면 차이를 기록하고 학술지 규정을 따른다. 연구 사실을 바꾸는 근거로 쓰지 않는다. |
| 한국어 어문 규정 | 한국어 맞춤법·띄어쓰기·문장 부호에 적용한다. 전문용어·고유명·직접 인용과 충돌하면 원문과 용례를 확인한다. |
| APA 7 및 JARS | 실제 확인한 출처의 범위에서 보고·인용·표시 관례를 적용한다. 영어 문법·대문자 규칙을 한국어 어순에 직역하지 않는다. |
| 편집 판단·사용자 문체 | 논리와 가독성을 개선한다. 피동·명사화·한자어를 일괄 금지하지 않는다. 짧은 문장 선호를 공적 규정으로 표기하지 않는다. |

## 증거를 고정하고 구조부터 수정한다

1. 주장마다 `연구 질문 → 자료·분석 파일/버전 → 실제 결과 → 주장 가능 범위 → 원고 위치`를 연결한다. 다른 모델·표본·분석 버전의 수치를 합치지 않는다. 현재 프로젝트가 fast-mlsirm 결과만 허용한다면 그 제한을 적용하되 다른 프로젝트의 보편 규칙으로 만들지 않는다.
2. 아래 표로 문단의 역할과 증거를 점검한다. 논리·문단 → 문장 → 맞춤법·띄어쓰기·문장 부호 순으로 수정한다. 문장만 요청받았다면 구조 문제는 별도 의견으로 남긴다.

| 부분 | 편집 질문 |
| --- | --- |
| 제목·초록 | 연구 대상·설계·질문이 드러나는가? 초록의 방법·핵심 결과·결론이 본문과 같은 표본·수치·불확실성을 사용하는가? 길이와 구조는 학술지 규정을 확인했는가? |
| 서론 | 알려진 사실의 근거, 남은 문제, 이번 질문이 이어지는가? 탐색 결과를 사전 가설로 바꾸지 않았는가? |
| 방법 | 표본·모집·측정·설계·절차·분석 선택을 원자료로 추적할 수 있는가? IRB·동의·등록·제외 기준을 실제 기록으로 확인했는가? |
| 결과 | 연구 질문 순서로 추정치·불확실성·분석 대상을 제시했는가? 미완료 분석을 완료 결과로 쓰지 않았는가? |
| 논의 | 결과가 뒷받침하는 답, 선행연구와의 관계, 대안 설명, 제한, 함의를 구별했는가? 관찰된 관련성을 인과 효과로 바꾸지 않았는가? |

3. 문장 수정 전후에 주체·대상·방향·부정·조건·시간·수치·인용·전문용어를 대조한다. 문장을 나누거나 순서를 옮길 때 인용이 뒷받침하는 주장을 원문과 대조한다. 적용 대상이 불분명하면 인용을 다른 주장 뒤로 옮기지 말고 기존 연결을 유지한 채 저자에게 확인한다. 이는 출처 귀속을 보존하는 편집 절차이며 APA의 별도 표기 규칙으로 주장하지 않는다. 행위자가 확인된 경우에만 능동문으로 바꾼다. 행위자를 확인할 수 없으면 원문을 유지하거나 `[확인 필요]`를 남기며 연구자나 참여자를 추정해 넣지 않는다.

## 양적 연구 보고와 표시를 점검한다

세부 작업에는 [보고·교정 절차](references/reporting-workflow.md)와 [JARS-Quant Table 1](references/jars-quant-table1.md)을 읽는다. 설계별 추가표는 S8 본문에서 해당할 때만 연다. 연구 설계에 맞는 공통표와 추가표를 선택하고 `원문 항목 | 원고 위치 | 근거 파일 | 충족/누락/해당 없음·이유`를 만든다. 아래 점검만으로 JARS 전체 충족을 주장하지 않는다.

표·그림의 숫자는 분석 산출물과 대조한다. 분석 산출물로 확인되지 않은 결과를 만들어 넣지 않는다. 검증된 필수 수치는 칸에 채운다. 필수 결과 표를 삭제한 상태를 제출 준비가 끝난 것으로 보고하지 않는다. 연구별 제출 차단(예: 라이브러리 미재현)과 APA 원문 규칙을 한 문장으로 섞지 않는다. 인용·참고문헌은 실제 읽은 자료와 서지정보를 대조한다. 제목이나 DOI만 보고 그 문헌이 주장을 뒷받침한다고 판단하지 않는다.

## 심사 응답과 인계

심사 의견별로 `의견 | 수용·부분 수용·이견 | 근거 | 실제 수정문 | 절·쪽·줄`을 작성한다. 분석 추가가 필요하면 계획과 수행 결과를 분리한다. 수행하지 않은 분석·수정은 완료했다고 답하지 않는다. 이견은 자료와 연구 범위로 설명한다. 최종 편집 후 위치를 다시 확인한다. 이 절은 편집 절차이며 APA의 고정 답변 양식이 아니다. **원고와 심사 응답을 같이 볼 때** 같은 절차의 표본 수·제외 수·민감도 숫자를 한 표로 대조한다. 값이 다르면 어느 쪽이 1차 분석인지 밝히고, 산출물 없이 맞추지 않는다.

인계할 때 수정 원고, 의미에 영향을 주는 수정 이유, 누락 자료, 적용 규정 충돌, 검증 범위를 제공한다. 구조·의미·수치 검증과 APA 서식 검증을 구분한다. 결과·IRB·동의·유의성·서지정보를 빈칸 보충 목적으로 발명하지 않는다.
