# 보고·교정 절차

아래는 편집자가 수행하는 확인 절차다. S1·S2 외의 항목을 원문 확인된 APA 세칙으로 주장하지 않는다. 출처 상태는 source-ledger.md에서 확인한다.

## JARS 원문 확보 후 적용할 점검 틀

연구 설계를 먼저 확인한다. 무작위 실험, 비실험 관찰, 종단 연구, 재분석 등에 같은 추가표를 강제하지 않는다. 각 항목은 원문과 대조하여 적용 여부를 결정한다.

- 표본: 모집 경로·기간, 포함·제외 기준, 계획·실제 표본 수, 표본 크기 결정 근거, 분석별 대상 수와 탈락을 확인한다.
- 측정: 구성개념, 도구·판본, 점수 방향·코딩, 현재 자료에서 평가한 측정 특성, 자료 수집 절차를 확인한다.
- 분석: 사전 계획과 탐색 분석, 결측 처리, 제외·이상치 처리, 추정법·소프트웨어 버전, 다중검정·모형 가정·민감도 분석의 실제 수행 여부를 확인한다.
- 결과: 기술통계·효과 추정·불확실성, 분석별 표본, 계획에서 벗어난 부분을 산출물에 연결한다. 해당하지 않거나 수행하지 않은 항목은 이유를 기록한다.
- 윤리·공유: 제공된 승인·동의·등록·자료 공유 기록만 기술한다. 없다는 이유로 승인 면제나 공개 가능을 추론하지 않는다.

## 표·그림

S2는 정보의 효율적 전달과 접근성을 안내한다. 그 목적에 따라, 편집 판단으로 다음을 점검한다.

1. 한 표·그림이 답할 질문을 정하고 본문과 중복되는 숫자 나열을 줄인다. 번호·제목·본문 지시가 맞는지 확인한다.
2. 행·열·축의 단위, 분석 대상 수, 약어·코딩, 오차막대의 종류를 실제 분석과 맞춘다. SE·SD·CI를 서로 바꾸지 않는다.
3. 색에만 의존하지 않는 구분, 읽을 수 있는 글자, 설명문을 점검한다. 축·범위 변경으로 효과를 과장하지 않는다.
4. 상세 선·주석·제목 서식은 확인된 학술지 규정 또는 APA 원문을 연다. 원문 미확인 상태에서 모두 APA 준수라고 표시하지 않는다.

## 통계 표기

수치와 서식을 별도로 점검한다. 먼저 분석 산출물에서 추정치, 통계량·자유도, p 값, 구간의 종류·수준·하한·상한, 표본 수를 가져와 대조한다. 표본 전체 N과 부분집단 n의 의미를 뒤집지 않는다. 반올림 전 값을 확인하고 표·본문·초록의 정밀도를 일관되게 조정한다.

기울임, 소수점 앞 0, 정확한 p 값과 임계값 표기는 A-NUM 확인 범위에서만 적용한다: 표·그림의 정확 *p*(*p* < .001은 "<.001"), 1을 넘을 수 없는 통계량의 선행 0 생략, 라틴 통계 기호 기울임·그리스 문자 비기울임, *M*·*SD*·*p*·*N*·*n* 미정의·CI 등 다른 약어 정의, 표·본문 통계 중복 금지. Manual 6장 본문·Table 6.5 미확인 항목은 `[확인 필요]`로 남긴다. 출력의 p = 0.000을 영 확률로 해석하지 않는다. 수치 정밀도를 복구할 수 없으면 원출력을 요청한다. 유의하지 않다는 이유만으로 효과가 없다고 결론 내리지 않는다. CI와 신용구간, 표준화·비표준화 계수를 바꾸지 않는다. 영어 숫자-단어 규칙을 한글 수사에 직역하지 않는다.

## 인용·참고문헌

본문 인용과 참고문헌의 양방향 대응, 저자 순서·연도·제목·출처·DOI를 실제 문헌과 확인한다. 직접 인용은 문구와 위치를 확인한다. 미독 문헌, 재인용, 미출판 자료는 각각의 공식 규칙을 확인하기 전 일반 논문처럼 처리하지 않는다.

S1에서 직접 확인한 범위: 영문 학술지 논문 제목은 sentence case, 학술지명은 주요 단어 대문자를 사용한다. 학술지명과 권은 기울이고 호는 기울이지 않는다. DOI가 있는 자료에는 DOI를 넣고 DOI 뒤에 마침표를 붙이지 않는다. 책은 판 정보를 제목 뒤에 두며 출판사 소재지는 넣지 않는다. 이 영문 대문자·이니셜 규칙을 한국어 저자명·제목에 기계적으로 적용하지 않는다. 구체적인 국문 처리 방식은 투고 규정을 확인한다.

## 편견 없는 언어

이 절은 S7 접근 미완료에 따른 잠정 편집 점검이다. 집단을 기술하는 이유, 자료가 뒷받침하는 구체성, 당사자의 확인된 호칭 선호를 확인한다. 나이·장애·성별·인종 등 특성을 근거 없이 추정하거나 다른 변수로 바꾸지 않는다. 진단 여부가 불명확한 집단을 환자로 바꾸지 않는다. 원자료의 범주명과 원문 인용은 보존하고, 설명이 필요하면 구분하여 덧붙인다. 정체성 우선·사람 우선 표현 중 하나를 모든 집단에 강제하지 않는다.

## 직접 쓴 교정 예문

실제 연구 결과가 아닌 연습용 문장이다.

- 원문: 이 횡단 연구에서 X와 Y의 관련성이 관찰되었다. 피해야 할 수정: X가 Y를 증가시켰다. 관련성과 설계를 유지한다.
- 원문: 자료가 수집되었다. 피해야 할 수정: 연구자가 자료를 수집했다. 수집 주체가 제공되지 않았다면 원문을 유지하거나 주체 확인을 요청한다.
- 원문: 신뢰구간에는 0이 포함되었다. 피해야 할 수정: 효과가 없었다. 불확실성의 진술을 효과 부재로 바꾸지 않는다.
- 문단 연습: 기존 연구는 X와 Y의 관련성을 보고했다. 본 연구는 이 관련성을 다른 표본에서 검토한다. 기존 연구가 다루지 않은 문제를 뒷받침할 자료가 없으면 최초 연구나 공백 해소라는 문장을 덧붙이지 않는다.
- 원문: p = .015, N = 120. 피해야 할 수정: p < .05로 임계값 대체. 표·그림의 정확 *p*를 유지한다(A-NUM).
- 원문: 95% CI [0.12, 0.48]. 피해야 할 수정: CI를 신용구간으로 바꾸거나 반올림으로 부호를 뒤집기. 첫 사용에 `95% 신뢰구간(CI)`으로 정의한다(A-NUM).
- 원문: 참고문헌末 `https://doi.org/10.1037/amp0000191.` 피해야 할 수정: 한글 논문 제목 영문화. 끝 마침표만 제거한다(A-REF, 영문 자료 한정).
- 원문: 기존 공개자료 재분석. 피해야 할 수정: 가상 모집 절차로 Sampling 전체 채우기. 2차 자료 표시를 유지하고 새 모집 항목은 `해당 없음`으로 둔다(A-JARSQ).
