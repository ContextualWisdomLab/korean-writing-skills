# 확인 범위 한 장 요약 (연구팀 인계용)

이 파일은 두 스킬이 **어느 원문을 실제로 읽고 규칙으로 쓰는지**만 모은 목록이다. 연구팀이 교정 제안을 받을 때 “이 제안이 규정인지, 편집 판단인지, 아직 확인 안 된 것인지”를 이 표로 구분하면 된다. 상세 인용과 쪽수는 각 근거 장부에 있다.

확인일 기준: 2026-09-24. 연구 원고·참여자 자료는 이 저장소에 두지 않는다.

## 2. 규정이 아니라 편집 판단·권고로 쓰는 것

- 대학 글쓰기 자료(경희대 U-KHU1–4): 교육 권고다. 학술지 규범으로 확대하지 않는다.
- 저자 권고: 확인 범위가 저마다 다르다.

  | ID | 자료 | 실제 확인 범위 |
  | --- | --- | --- |
  | G1 | 강원국 『강원국의 글쓰기』 | 전자책 미리보기 p. 21 인용 1건만 본문 확인. 4장 퇴고 표는 목차만 보이고 본문·쪽 미확인 |
  | G2 | 강원국 『강원국의 책쓰기 수업』 | **목차만** 확인. 본문 미독 |
  | J1 | 김정선 『열 문장 쓰는 법』 | **2차 자료(한겨레 편집자 서평)**가 전하는 방법만 확인. 저자 직접 인용·쪽 없음 |
  | J2 | 김정선 『내 문장이 그렇게 이상한가요?』 | 서지와 목차 주제만. **원서 본문 미독**, 쪽수 미확인 |

  이 네 항목은 ‘능동형으로’, ‘-적/-의 제거’ 같은 표현을 일괄 규칙으로 바꾸는 근거가 되지 않는다.
- 표·목록 보고 규칙, 운영 보고 문장 경로: 이 스킬의 편집 절차다.

## 4. 타당화 상태

- 사례별 블라인드 채점 기록은 `evaluations/runs/`에 있다. 사례 통과는 그 사례에 한정된다.
- 표·각주 장르 전체 타당화, 채점자 일치도, 일반 성능 주장은 **없다**.
- 스킬 적용 결과를 “APA 전체 준수”나 “투고 가능”의 근거로 쓰지 않는다.

## 5. 연구팀이 교정 제안을 받을 때

1. 제안마다 위 1·2·3 중 어디에 해당하는지 확인한다.
2. 3에 해당하면 규정 위반으로 취급하지 않는다. 학술지 지침이 있으면 그쪽이 우선한다.
3. 수치·가설·해석을 바꾸는 제안은 이 스킬의 범위가 아니다. 연구팀이 산출물로 판단한다.
