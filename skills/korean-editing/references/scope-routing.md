# 적용 범위 확장과 실전 선택 절차

이 문서는 현재 확인된 개별 조항을 무리하게 전체 규범으로 확대하지 않으면서, 초안 작성과 교정에서 적용 한계를 줄이는 운영 절차다. 새 규칙을 만들지 않는다. 문장의 기능과 장르를 확인한 뒤 공식 규범·사전·기관 지침의 적절한 출처로 라우팅한다.

## 1. 요청을 네 층으로 분리한다

문장을 고치기 전에 요청을 다음 중 하나 이상으로 분류한다.

1. **표기**: 맞춤법, 띄어쓰기, 문장 부호, 외래어·로마자 표기
2. **어휘**: 표준어 여부, 한 단어 여부, 의미·품사·용례
3. **문장**: 호응, 수식 범위, 지시 대상, 행위자, 연결 관계
4. **장르·출판**: 학술지, 공공문서, 보고서, 안내문, 인용·참고문헌 스타일

한 층의 근거를 다른 층의 규칙으로 확대하지 않는다. 예를 들어 표준국어대사전의 표제어 등재는 문장의 인과나 학술지 스타일을 결정하지 않는다.

## 2. 근거 라우터

| 질문 | 우선 확인할 출처 | 판정 범위 |
|---|---|---|
| 조사·의존 명사·단위·보조 용언·전문용어 띄어쓰기 | 한국어 어문 규범의 한글 맞춤법 | 조항·해설·허용형을 확인한 문맥만 |
| 표준어·발음 | 한국어 어문 규범의 표준어 규정·표준 발음법 | 해당 조항과 용례만 |
| 외국어를 한글로 적기 | 한국어 어문 규범의 외래어 표기법 | 언어별 표기 세칙과 용례를 확인한 말만 |
| 한국어를 로마자로 적기 | 국어의 로마자 표기법 | 표준 발음 기반의 표기와 예외·관용 표기 |
| 단어의 품사·뜻·활용·한 단어 여부 | 표준국어대사전 | 검색한 표제어·뜻·품사·용례 |
| 학습자에게 쉬운 풀이·기본 예문 | 한국어기초사전 | 학습용 설명이며 일반 규범 전체가 아님 |
| 구체적인 문맥 질문 | 국립국어원 온라인가나다 | 해당 답변의 질문·답변 범위. 규정 본문과 구분 |
| 투고 형식·인용·표·그림 | 투고 학술지·출판사 지침 | 해당 장르와 제출 버전 |

국립국어원 어문 규범 포털은 한글 맞춤법, 표준어 규정, 외래어 표기법, 국어의 로마자 표기법을 별도 규정과 항목으로 제공한다. 이 저장소는 각 규정의 전체를 이미 검증했다고 주장하지 않으며, 새 항목을 쓸 때 실제 해당 페이지와 용례를 다시 확인한다.

## 3. 두 출처가 다룰 때의 우선순위

- 규정 본문과 상담 답변이 직접 충돌하는 것처럼 보이면 임의로 조정하지 말고, 조항·다만·붙임·답변일·질문의 문맥을 함께 기록한다.
- 표준어 규정과 사전의 표제어가 필요한 경우에는 어느 판단을 위해 사용했는지 적는다. 사전 등재 여부만으로 표준어·비표준어를 단정하지 않는다.
- 공식 상담은 적용 예를 제공할 수 있지만, 상담이 다루지 않은 다른 문맥까지 일반화하지 않는다.
- 출판사·학술지 지침은 규범 오류와 장르 선택을 구분한다. 투고 지침에 따른 표기 통일을 맞춤법의 유일한 정답으로 설명하지 않는다.
- 외래어·로마자·고유명사는 실제 표기 대상의 언어·이름·관용 표기 여부를 확인한다. 한글 맞춤법의 일반 띄어쓰기 규칙을 로마자 토큰이나 브랜드명에 자동 적용하지 않는다.

## 4. 초안에서 확인을 미루지 않는 질문

다음 질문은 현재 확인 범위 밖의 표현을 억지로 고치는 대신, 확인해야 할 대상을 분명히 한다.

- 이 말은 표준어 여부를 묻는가, 아니면 문맥상 자연스러움을 묻는가?
- 이 표현은 한 단어인가, 접사 결합인가, 구인가?
- 외국어 원어와 언어권이 확인되었는가?
- 로마자 표기가 필요한가, 기존 공식·관용 표기를 보존해야 하는가?
- 표준국어대사전의 어느 뜻과 품사를 사용했는가?
- 인용문·고유명사·브랜드·파일명처럼 원형을 보호해야 하는가?
- 학술지·기관이 별도 표기나 인용 방식을 요구하는가?

확인 자료가 없으면 원문을 유지하고, 작업 메모나 교정문 밖의 확인 사항에 `[확인 필요: 표준어/사전/외래어/로마자/장르 지침 중 무엇을 확인할지]`로 남긴다. 막연한 `[문법 확인]`보다 재검증 가능한 질문을 쓴다. 업무 보고서에서는 [조사와 교정 절차](reader-facing-reports.md)에 따라 작성 전에 확인하고 조사용 표식을 본문에 넣지 않는다. 원문에 있는 실제 불확실성·실패·위험·한계는 그대로 보존한다.

## 5. 외부 자료와 사전의 사용 한계

- 검색 결과의 제목·요약만으로 규칙을 만들지 않는다. 원문 페이지의 해당 조항·표제어·뜻·용례를 읽는다.
- 표준국어대사전은 규범 중심 사전이지만, 사전 검색 결과 하나가 문장 전체의 적절성이나 장르 적합성을 보증하지 않는다.
- 한국어기초사전은 쉬운 풀이와 학습 예문에 유용하지만, 전문 학술 용어·법률 문구·투고 스타일의 최종 기준으로 쓰지 않는다.
- 온라인가나다는 최근 2년 내 자료를 공개하는 상담 게시판이며, 다량 교정·감수 요청 전체를 대신하는 서비스가 아니다(N-ON1). 질문일·답변일·확인일과 적용 문맥을 구별해 기록한다.
- 오래된 자료는 현재 효력, 개정 여부, 장르 지침과의 관계를 확인한 뒤 참고한다. 확인하지 않은 현재성을 표현하지 않는다.

### 온라인가나다 답변을 새 근거로 사용할 때

아래는 E1 편집 절차다. 새 답변을 찾았거나 기존 상담을 재확인할 때 적용한다.

1. **기존 기록과 원문을 대조한다.** URL의 `qna_seq`와 원문 제목으로 같은 항목인지 확인한다. 검색 요약이나 질문자의 설명을 답변자의 판단으로 옮기지 않는다. 질문·답변·첨부된 재질문의 경계를 읽는다.
2. **확인한 정보를 같은 항목에 기록한다.** 발행기관, 정확한 원문 제목, URL·식별번호, 질문일, 답변일, 최초 확인일, 이번 확인일, 실제 읽은 범위, 핵심 설명, 적용 조건·예외를 적는다. 표시되지 않은 날짜는 미표시로 남기고 검색 수집일이나 열람일로 대신하지 않는다. 질문자 이름·연락처와 상담 전문은 옮기지 않는다.
3. **규정과 상담의 역할을 구별한다.** 답변이 인용한 조항·사전도 실제 열람한 범위만 기록한다. 상담의 요령을 필요충분조건으로 만들거나, 새 답변이라는 이유만으로 기존 규정·허용형을 폐기하지 않는다. N-Q13의 예문 귀속 정정과 N-Q14의 판별 한계가 대조 사례다.
4. **상충·수정·접근 실패를 따로 처리한다.** 수정 공지가 관련되면 공지와 해당 답변을 함께 읽는다. 해석이 충돌하면 해당 규칙의 확대 적용을 보류하고 확인할 쟁점을 남긴다. 원문을 열지 못한 경우 이전 확인 날짜와 요약을 보존하며 이번 접근 실패를 덧붙인다. 규정·사전·상담 사례 모음에서 같은 주장을 직접 확인하면 대체 근거와 확인 범위를 연결한다.
5. **바뀐 판단만 반영한다.** 교정해야 할 예와 유지해야 할 허용 예를 직접 쓴다. 기존 장부가 틀렸으면 정정 내용과 날짜를 같은 항목에 남긴다. 오래된 답변의 최초 검토, 저장소의 정정, 기관의 실제 답변 수정은 서로 다른 사건이다. 달라진 내용이 없으면 새 규칙을 만들거나 확인하지 않은 항목의 날짜를 일괄 갱신하지 않는다.

### 온라인가나다 답변 정정을 적용한 수정·유지 예

2026-11-09 등록된 주간 수정 공지는 `qna_seq=337820`의 영어 `Bulletin` 표기 답변이 2026-11-04에 정정됐음을 알린다(N-Q17). 답변 본문의 `[고침]`까지 확인해야 원래 제시된 `불리틴`과 수정된 `불러틴`을 혼동하지 않는다. 다음은 **직접 쓴 가상 문장**이며 원문의 예문이 아니다.

- **수정**: 직접 작성 중인 새 안내문의 표기 설명 `영어 bulletin의 한글 표기: 불리틴`을 `영어 bulletin의 한글 표기: 불러틴`으로 고친다. 이는 해당 상담의 정정 결과를 안내문 자체에 적용하는 예이며, 다른 문서가 과거에 무엇을 설명했는지를 바꾸거나 외래어 표기 규칙을 새로 제정하는 것이 아니다.
- **유지**: `제품 이름은 Bulletin이다.`라는 문장에서 실제 고유 이름 `Bulletin`을 한글로 강제 치환하지 않는다. 고유 명칭을 확인한 뒤 필요한 경우에만 전사한다.
- **인용 보존**: 정정 이전 답변을 역사적으로 인용하는 문헌의 직접 인용은 몰래 변경하지 않고, 별도 주석에서 2026-11-04에 수정된 표기를 밝힌다.

정정 공지의 **처리 일시**와 질문·답변의 표시 날짜, 이번 열람일은 서로 다른 사건이다. 첫 답변이 표기 미확정·발음과 관용의 가능성을 설명했다는 사실과 후속 정정의 명시적 결론을 한 문장으로 섞지 않는다.

### 새 상담의 확정 교정과 판단 유보 (N-Q18)

2026-11-10 답변이 등록된 상담 338211은 일반 문장에 적용할 수 있는 표기 판단과 문학 인용에서 결론을 유보해야 할 경우를 함께 보여 준다. 아래 문장은 **직접 만든 예**이며 질문자의 작품·기사 인용문이 아니다.

- **수정 — 용언**: 새 안내문의 `행사장 직원이 통로 쪽으로 상자를 밀어부쳐 놓았다.`를 `행사장 직원이 통로 쪽으로 상자를 밀어붙여 놓았다.`로 고친다. 해당 표기는 상담이 확인한 `밀어붙이다`의 활용형에 따른다.
- **수정 — 띄어쓰기**: `그후 방문객이 문을 닫았다.`를 `그 후 방문객이 문을 닫았다.`로 고친다.
- **유지**: 이미 `그 후 방문객이 문을 닫았다.`로 적은 문장과 정확한 원문 인용은 고칠 필요가 없다.
- **보류 — 문학 구절**: 작품에서 따온 `벗어 붙이고`라는 구절을 그 문맥의 의도나 원본 판본을 확인하지 않은 채 `벗어부치고`로 자동 교체하지 않는다. 국립국어원 답변도 해당 용례의 옳고 그름을 확정하지 않았다.

이 사례는 표기를 교정할 때 사전 설명을 참고하되, **확정된 표기와 문학적 사용의 판단 불가를 구별**하는 적용 예다. 사전 표제어를 새로 직접 확인했다고 주장하지 않고 상담 답변에서 확인한 부분만 인용한다.

## 6. 실행 결과의 범위 표기

결과를 다음처럼 분리해 보고한다.

- **확정 교정**: 문장 기능과 확인된 근거가 일치한다.
- **선택 교정**: 허용형을 장르·문서 안에서 통일한 것이며 오류 수정과 구분한다.
- **보류**: 원형·행위자·출처·장르 지침을 확인해야 한다.
- **확인하지 못함**: 필요한 원문이나 사전 정보를 아직 읽지 않았다.
- **미적용**: 해당 규정이 코드·인용·브랜드·전문 분야 형식에 적용되지 않는다.

이 분류는 스킬 전체의 규범 범위를 넓혀 보이게 하지 않으면서, 사용자가 다음 확인 행동을 바로 선택하게 한다.
