# 능동·피동과 주동·사동의 선택

이력서·보고서·소개문을 쓰거나 고칠 때, **누가 무엇을 했는지와 어떤 대상을 중심으로 말할지**에 맞춰 표현을 고른다. 이 문서는 사역 표현을 한국어 문법의 **사동**이라는 용어로 다룬다. 피동이나 사동의 개수를 줄이는 것이 목표가 아니다. 권할 표현은 적극적으로 제시하고, 고칠 표현은 그 문맥의 오류·의미 불일치·불필요한 중복을 밝혀 수정한다.

## 1. 문법적 지위와 근거의 범위

능동·피동·사동을 서로 배타적인 세 등급으로 나누지 않는다. 국립국어원은 **능동–피동**, **주동–사동**을 각각 대립 관계로 설명한다(N-V1). 피동은 한국어의 정상적인 문법 구성이다. Kim의 학술서도 어휘적 피동과 통사적 피동의 형성 방식·생산성·제약을 분석한다(P-VOICE1). 피동이라는 이유만으로 번역투나 비문으로 판정하지 않는다.

| 구별 | 확인할 관계 | 직접 만든 가상 예 |
| --- | --- | --- |
| 능동–피동 | 행위와 그 영향을 받는 대상을 어느 쪽에서 서술하는가 | `위원회가 안건을 검토했다.` / `안건이 위원회에서 검토되었다.` |
| 주동–사동 | 해당 동작·상태에 다른 주체가 관여하여 하게 하거나 그렇게 되게 하는가 | `아이가 옷을 입었다.` / `보호자가 아이에게 옷을 입혔다.` |
| 사동과 피동의 결합 | 사동 의미를 가진 말이 다시 피동으로 서술되는가 | `알리다`에 `-어지다`가 결합해 굳어진 `알려지다`는 이중 피동으로 처리하지 않는다(N-V3). |

주동·능동이라는 이름은 무엇과 대조하는지에 따라 붙는다. 사동주는 행동이나 상태 변화를 일으키는 주체이고, 피사동주는 그 동작을 하거나 상태 변화를 겪는 주체다. 사동주가 직접 관여하는 경우도 있으므로 사동을 언제나 간접 지시로만 풀지 않는다. 피동·사동의 주체가 반드시 사람이거나 의도적으로 행동한다고 덧붙이지 않는다. 사동구문을 사역성·인과성·타동성의 결합으로 분석하는 연구도 있다(P-VOICE4). 이 지침에서는 문맥에 나타난 참여자와 원인·결과의 관계를 확인하는 데 참고한다.

형식은 판단의 단서다. 피동 접미사 `-이-/-히-/-리-/-기-`와 사동 접미사 `-이-/-히-/-리-/-기-/-우-/-구-/-추-`는 일부 형태가 겹치므로 낱말의 뜻과 문장 성분을 먼저 확인한다(N-Q1). 모든 동사에 접미사를 임의로 붙일 수 있는 것은 아니다(P-VOICE1). 사동에는 `-게 하다` 구성, 접미사 `-시키다`, 독립 동사 `시키다`도 쓰인다. `훈련시키다`처럼 접미사가 붙은 말과 `훈련을 시키다`처럼 목적어를 받는 동사를 구별한다(N-V5).

`-어지다`를 피동 전용 표지로 보지 않는다. `날씨가 따뜻해졌다`에는 사전상 상태 변화 용법이 있다(N-V2). Ahn·Yap은 `-어지다`의 자발적·기동적 중간태와 피동 용법의 관계를 분석한다(P-VOICE2). 구체적인 문법 범주는 학설에 따라 다를 수 있으므로 뜻을 먼저 보존한다. `보이게 되었다`의 변화·새 상태 도달을 단순한 `보였다`와 항상 같다고 보지도 않는다.

**근거를 구별한다.** N-V1–7·N-Q1·N-Q3은 사전·개별 공식 설명이고, P-VOICE1–4는 학술 분석이다. 아래의 우선순위·예문은 이를 참고한 E1 편집 판단이다. 학술 가설이나 간결성 권고를 한글 맞춤법의 금지 조항이라고 설명하지 않는다. 직접 읽은 범위와 한계는 [출처 장부](source-ledger.md)에 기록한다.

## 2. 적극 권할 패턴

| 목적·확인된 문맥 | 우선 권할 표현 | 선택 이유와 보존 조건 |
| --- | --- | --- |
| 누가 수행했는지와 책임이 핵심이며 행위자가 확인됨 | `연구팀이 응답을 분류했다.` | 행위자를 주어로 두는 능동문을 우선 검토한다. 이력서는 본인 행동과 팀 성과를 구별한다. 이미 문맥상 분명한 주어를 매번 반복할 필요는 없다. |
| 대상의 처리 상태가 핵심이고 행위자도 필요한 정보임 | `신청서는 심사위원회에서 검토되었다.` | 피동으로 대상의 흐름을 이어 가면서 확인된 수행자도 남길 수 있다. 화제를 유지한 `신청서는 심사위원회가 검토했다.` 같은 능동 대안도 가능하다. |
| 행위자를 모르고 대상의 변화만 확인됨 | `문서가 삭제되었다.` | 피동을 유지한다. 편집자가 삭제자를 추측해 넣지 않는다. 책임을 확인해야 하는 업무라면 먼저 조사하되 미확인 행위자를 본문에 채우지 않는다. |
| 다른 주체에게 실제로 일을 하게 한 관계가 있음 | `연구원이 참여자에게 설문지를 작성하게 했다.` | 사동주와 실제 작성자를 구별한다. `연구원이 작성했다`나 `참여자가 작성했다`만 남겨 역할 또는 사동 관계를 지우지 않는다. |
| 실제로 대상의 상태를 바꾸었다는 뜻임 | `안내자가 아이를 진정시켰다.` | 사동은 지시·명령에만 쓰이지 않는다. 상태 변화의 원인 관계가 제공되어 있을 때 사용한다. 관찰된 변화만으로 원인을 새로 만들지는 않는다. |
| 변화 자체가 핵심이며 외부 행위자는 제시되지 않음 | `방 안이 조용해졌다.` | 상태 변화 표현을 유지한다. `방 안이 조용했다`로 줄이면 변화의 뜻이 사라진다. |

주어를 드러내는 능동문, 대상을 이어 가는 피동문, 역할을 구분하는 사동문은 각각 목적에 맞을 때 권한다. 능동문을 썼다는 이유만으로 책임이 확인되거나 피동문을 썼다는 이유만으로 책임을 회피했다고 판정하지 않는다.

## 3. 이 문맥에서는 사용하지 말고 고칠 패턴

| 확인된 문제와 문맥 | 피할 표현 → 수정 예 | 판단의 지위 |
| --- | --- | --- |
| 선정된 후보를 주어로 말하는데 목적격 조사를 붙임 | `후보 3명을 선정되었다.` → `후보 3명이 선정되었다.` | 문장 성분과 서술어의 호응 문제. 선정자를 만들거나 피동을 없앨 필요가 없다(K1, E1). |
| 글이 적혀 있다는 뜻만 전달하며 별도 의미 차이가 없음 | `안내문에 기한이 쓰여져 있다.` → `안내문에 기한이 쓰여 있다.` | `쓰이다`만으로 충분한 문맥의 중복을 줄이는 공식 권고를 적용한 편집(N-V4). 모든 `-어지다`를 금지하는 규칙이 아니다. |
| 본인이 직접 검토했으며 다른 사람에게 하게 한 일이 없음 | `담당자가 자료를 검토시켰다.` → `담당자가 자료를 검토했다.` | 제공된 사실과 사동 의미의 불일치. `검토시키다`라는 형태 자체를 언제나 비문으로 판정하지 않는다(N-V5, E1). |
| 누가 한 일인지 모르는 문장을 능동으로 만들려고 행위자를 추가함 | `자료가 삭제되었다.` → `담당자가 자료를 삭제했다.`라는 수정은 채택하지 않는다. | 없는 행위자·책임을 추가하는 의미 훼손(E1). 원문을 유지한다. |
| 변화와 인과가 확인되지 않았는데 원인 주체를 만듦 | `처리 속도가 빨라졌다.` → `새 도구가 처리 속도를 높였다.`라는 수정은 채택하지 않는다. | 관찰을 인과로 바꾸는 의미 훼손(E1). 사동형이 자연스러워도 근거가 생기지 않는다. |
| 다른 뜻을 가진 보조 표현을 군더더기로 삭제함 | `검토할 수 있게 되었다.` → `검토했다.`라는 수정은 채택하지 않는다. | 가능성·상태 도달을 완료 사실로 바꾸는 의미 훼손(E1). |

사동 의미 없이 `-시키다`를 `-하다` 대신 쓰는 관행은 국립국어원도 엄격한 규범 관점에서 구별한다(N-V5). 고칠 때에는 원문에 실제로 사동 관계가 없는지부터 확인한다. `검토했다`·`검토를 맡겼다`·`검토하게 했다`는 수행자와 관여 방식이 같지 않다. 요청만 한 사실을 실제 수행 완료나 강제 행위로 바꾸지 않는다.

직접 소개했다면 `소개했다`, 다른 사람에게 소개하게 했다면 그 사동 관계를 쓴다. `소개시키다` 자체를 금지하지 않는다. 마찬가지로 `담당자가 신입 사원을 회의에 참여시켰다`를 `담당자가 회의에 참여했다`로 바꾸면 참여자가 달라진다. `-시키다`는 생산적인 접미사이므로 개별 파생어가 사전에 없다는 사실만으로 틀렸다고 하지 않는다(N-V5).

`검토되어졌다`처럼 이미 피동 의미가 있는 말에 `-어지다`가 덧붙어 있고 새 의미 없이 길어졌다면 `검토되었다`를 우선 제안한다(E1). 다만 `되다` 자체가 늘 피동인 것은 아니다. 독립 동사 `되다`와 보조 용언 결합도 필요한 의미가 있는지 따로 본다(N-V4). 직접 인용이나 의도적인 문학 표현은 이 표로 몰래 고치지 않는다.

## 4. 겉모양이 비슷해도 같은 처리를 하지 않는 경우

| 대조할 표현 | 적용 조건 |
| --- | --- |
| `화면이 잘 보여졌다.` / `자료가 참석자에게 보여졌다.` | 전자가 단순 가시성만 뜻하면 `잘 보였다`를 제안한다. 후자가 누군가 자료를 보게 한 사동의 피동이면 제시 행위를 보존한다. `보여지다` 전체를 이중 피동이라고 금지하지 않는다(N-Q3). 실제 제시자가 확인되면 `진행자가 참석자에게 자료를 보여 주었다`도 가능하다. |
| `교사가 학생을 앉혔다.` / `교장이 교사에게 학생을 앉히게 했다.` | 둘째에는 서로 다른 주체가 관여하는 두 사동 단계가 있다. 사동이 겹친다는 이유만으로 교사 단계를 없애지 않는다(N-V6). 학술자료의 논리적 분석 예를 모든 중첩의 자연스러움 보장으로 확대하지 않는다(P-VOICE3). |
| `보호자가 아이에게 밥을 먹게 했다.` / `보호자가 아이에게 밥을 먹였다.` | 두 사동 형식의 의미가 언제나 같다고 가정하지 않는다. 누가 어떻게 관여했는지 확인하고 원문에 없는 직접 행위·의도·강제성을 덧붙이지 않는다(E1). |
| `품질을 향상시켰다.` / `품질을 향상했다.` | 국립국어원은 `향상시키다`를 비문으로 판정하지 않으며, `향상`의 사동 뜻을 고려해 간결한 `향상하다`를 권한다(N-V7). 따라서 간결성 제안으로 구분한다. 의미·문체에 맞으면 `품질을 높였다`도 검토하되 원인과 성과를 발명하지 않는다. |
| `알려지다`, `굽혀지다`, `숙여지다` | 사동사에 피동 표현이 붙는 문맥을 확인한다. 표면에 접미사와 `-어지다`가 함께 있다는 이유만으로 삭제하지 않는다(N-V3). |

문맥이 충분하면 적절한 수정문을 바로 완성한다. 여러 해석이 남아 행위자·사동 단계·초점이 달라질 때만 해당 문장을 유지하고 필요한 관계를 묻는다.

## 5. 채택 전 대조

1. **참여자:** 원문에 있는 수행자·대상·사동주·피사동주가 모두 같은가?
2. **사건:** 직접 수행, 요청·허용·강제, 실제 완료, 상태 변화의 관계를 새로 정하지 않았는가?
3. **주장:** 시제·부정·가능성·추정·수량·인과의 범위가 같은가? `모두 검토된 것은 아니다`를 `하나도 검토되지 않았다`로 바꾸지 않았는가?
4. **초점과 형식:** 독자가 따라가는 대상과 필요한 책임 정보가 유지되는가? 문법 오류와 문체상의 간결성 제안을 구별했는가?

의미가 같고 목적에 더 잘 맞을 때 수정한다. 피동·사동 비율이나 변경 글자 수를 품질 점수로 사용하지 않는다.
