# 업무 보고서의 조사와 교정

## 적용 범위

업무·진척·결과 보고서를 작성하거나 내용까지 교정할 때 적용한다. 기존 스킬의 독자·장르·수정 범위 판단과 의미 보존 조건을 따른다. 맞춤법만 의뢰받았다면 조사나 구조 개편으로 범위를 넓히지 않는다. 아래 절차는 E1 편집 판단과 U1 사용자 선호이며 어문 규정이 아니다.

## 작성 전에 확인할 일

요청된 항목의 원자료와 실행 결과를 읽고, 필요한 사실은 담당자에게 확인한다. 에이전트가 더 조사할 일은 자신의 작업 노트·할 일 관리에 기록한다. 문서 파일과 초안에는 에이전트의 확인 표지나 조사 과제 목록을 넣지 않는다. 접근 가능한 자료를 먼저 확인하고, 필요한 자료·권한을 얻지 못하면 의뢰자에게 구체적으로 요청한다. 보고의 핵심 사실을 해결할 수 없다면 납품 범위를 의뢰자와 조율한다.

결과에 내재한 불확실성과 에이전트가 덜 조사한 상태를 구별한다. 연구의 추정치·신뢰구간·설계 한계, 확인된 기능 제한·실패·위험은 보고할 내용이다. 조사 과제를 문서 밖에서 관리한다는 이유로 이러한 사실이나 원문의 필요한 부정·조건을 삭제하지 않는다.

## 의사결정에 필요한 내용을 앞에 둔다

NARA·GSA의 공공문서 지침(W-RPT1·2)과 Broad Institute Communication Lab의 정책 메모 지침(W-RPT4)을 참고한다. 아래 업무 보고서 절차는 이 자료를 적용한 E1 편집 판단이다. 기관 권고와 연구의 확인 범위는 [출처 장부](source-ledger.md)에 기록한다.

1. **독자가 해야 할 일을 정한다.** 의사결정 보고서는 권고와 결정 요청, 분석 보고서는 핵심 발견, 진척 보고서는 실제 실적을 앞에 둔다. 시간 순서가 중요한 경위·절차 설명은 그 순서를 따른다. 모든 보고서에 같은 목차를 강제하지 않는다.
2. **첫 문단에 판단에 필요한 정보를 모은다.** 권고, 주요 비용·효과·위험, 지금 요청하는 결정을 연결한다. 비용 증감이 핵심이면 아래의 기존 대비 요약 원칙을 적용한다. 실제로 주어진 범위·금액·기한을 쓰며, 작성자가 결정권자의 승인을 이미 받은 것처럼 쓰지 않는다.
3. **실제 대안을 같은 기준으로 비교한다.** 주어진 선택지를 비용·효과·위험 등 공통 항목으로 비교한다. 현행 유지도 실제 선택지라면 포함한다. 비교표를 채우려고 대안이나 비용 0원을 만들어 넣지 않는다. 일회성 비용과 반복 비용, 파일럿 결과와 장기 전망을 구분하고 권고에 불리한 근거도 보존한다.
4. **관찰·예상·해석·권고를 구별한다.** 관찰 결과에는 자료의 기간·대상·비교 기준을, 예상에는 전제와 범위를 붙인다. 시간 감소를 인건비 절감액으로 바꾸거나 전후 차이만으로 인과를 확정하지 않는다. 원문 교정에서 저자가 이미 한 인과 주장은 임의로 약화하지 말고 문서 밖에서 근거를 확인한다. W-RPT3는 불확실성 표현과 신뢰의 관계를 다룬 연구이며, 불확실성을 쓰면 언제나 신뢰가 높아진다는 근거가 아니다.
5. **다음 조치를 실행 가능한 단위로 쓴다.** 확인된 담당·행동·기한·판단 기준을 연결하고, 지금 승인할 일과 추가 검증 후 결정할 일을 구분한다. 정해지지 않은 담당자나 합의를 만들지 않는다. 필요한 자료는 먼저 조사하고 남은 확인은 의뢰자에게 문서 밖에서 요청한다.

### 합성 예: 요청과 실행 조건을 구분한다

주어진 사실이 `7월 파일럿 예산 300만 원, 6월 30일까지 승인 요청, 운영팀 담당`이라면 다음처럼 쓸 수 있다.

> 7월 파일럿 예산 300만 원의 승인을 6월 30일까지 요청합니다. 승인되면 운영팀이 파일럿을 진행합니다.

효과 자료가 없다면 비용 절감·품질 향상 규모를 보태지 않는다. 실제 승인 전에는 `도입 확정`이나 `예산 확보`로 바꾸지 않는다. 이 예의 날짜·담당·금액을 다른 보고서에 옮기지 않는다.

### 수치·표·출처를 맞춘다

요약·본문·표에서 같은 항목의 값·단위·기간이 일치하는지 대조한다. 비교표에는 단위와 기간을, 추정치 가까이에는 주요 전제와 출처를 둔다. 출처는 독자가 원자료를 찾을 수 있도록 문서명·판본·쪽 또는 절을 남기고, 수시로 바뀌는 자료에는 확인일도 기록한다. 이는 E1 편집 절차다. 정확한 값의 비교에는 표, 변화 추세를 읽는 데는 적절한 그래프를 쓰되, 축·분모·기간을 바꿔 차이를 과장하지 않는다. 짧은 문장으로 충분한 내용에 장식용 도식을 추가하지 않는다.

## 불필요한 부정 대비를 피한다

설명은 대상의 성격·행위·결과를 직접 밝히는 문장으로 시작한다. 독자가 제기하지 않은 오해를 먼저 만들어 `…는 …이 아니다`로 부정한 뒤 본론으로 돌아오는 구성을 반복하지 않는다. 예를 들어 `이 조치는 공격 행위가 아니다`를 반복하기보다 `담당자가 공용망 접근을 차단했다`처럼 확인된 주체와 행동을 쓴다. 이는 E1 편집 판단과 U1 사용자 선호이며, 해당 문형 전체를 금지하는 어문 규정이 아니다. 실제 오해에 답하는 반박, 중요한 적용 제외, 부재·실패·불확실성을 전달하는 부정, 직접 인용은 뜻에 필요하면 보존한다.

## 내용과 문장을 고치는 순서

1. **의미를 대조한다.** 원자료와 원문의 행위자·대상·수치·시점·조건·부정·주장 강도를 확인한다. 모르는 상태를 완료·진행 중·예정으로 바꾸거나 자료에 없는 원인·담당·기한을 보태지 않는다.
2. **독자에게 필요한 순서로 정리한다.** 진척 보고에서는 실적 → 남은 작업 → 조치 계획을 기본으로 삼는다. 주어진 양식과 독자의 목적에 맞게 배열하고, 시간·절차 순서가 필요한 글은 그 순서를 유지한다. 완료된 항목에 남은 작업을 억지로 만들거나 모든 항목에 같은 설명을 반복하지 않는다.
3. **문장을 완성한다.** [문장 수리 절차](sentence-repair.md)에 따라 뜻이 분명한 호응 오류는 바로 고친다. 불필요한 확인 질문으로 교정을 대신하지 않는다. 표현을 다듬을 때는 대상·수량·기간·결과로 실적을 정확히 쓴다. 독자에게 필요하지 않은 작성 과정 해설을 덧붙이지 않는다. 특정 어미나 낱말을 일괄 금지하거나 동의어로 자동 치환하지 않는다.
4. **의미가 갈리는 부분만 묻는다.** 원문 교정에서 저자의 뜻을 새로 정해야 하면 해당 원문을 보존하고 질문은 교정문 밖에서 전달한다. 에이전트 자신의 조사 과제는 작업 노트에 둔다. 다른 명백한 오류의 교정은 계속한다.

진척률을 보고할 때는 원 계획의 작업량·단계·가중치와 실제 실적을 대조한다. 기존 산정 기준을 먼저 확인하고, 기준이 없으면 의뢰자와 산정 방식을 정한다. 항목 종결 수와 작업 진척률을 혼동하지 않으며, 근거 없는 백분율을 만들지 않는다.

## 증감은 기존 대비 규모부터 쓴다

비용·예산·물량 등 수치의 증가나 감소가 핵심인 보고서는 **증감 요약 → 상세 내역** 순서로 쓴다. 리더가 먼저 판단할 수 있도록 보고서 상단의 요약이나 첫 문단에 기존 대비 증감 방향과 대략적인 규모를 밝힌다. 고정 양식이면 허용된 요약란이나 해당 절의 첫 문장을 쓴다. 이는 U1 사용자 선호와 E1 편집 판단이며 모든 글의 구성을 바꾸는 어문 규정이 아니다.

- **같은 기준으로 비교한다.** 기준값과 비교값(실적 또는 예상값)의 대상·기간·단위·통화·세금 포함 여부를 맞춘다. 월 비용과 연 비용, 일회성 도입비와 반복 운영비를 섞어 증감률을 만들지 않는다. 공통 기준으로 환산할 근거가 있으면 환산 조건을 밝히고, 없으면 각각 제시한 뒤 필요한 자료를 의뢰자에게 요청한다.
  첫해 총비용의 증감률은 기존 총비용의 포함 항목도 확인한다. 기존 운영비만 주어졌다면 새 첫해 총액과 운영비 증감을 분리하고 총비용 증가율을 단정하지 않는다.
- **차이와 비율을 함께 밝힌다.** 비교 가능한 비용은 기존 금액 → 변경 금액, 증감액, 증감률을 요약한다. 증감액은 `비교값 - 기준값`, 양수인 기준값의 증감률은 `(비교값 - 기준값) / 기준값 × 100`으로 계산한다. 감소는 감소액과 감소율로 방향을 분명히 쓰고, 차이가 없으면 동일하다고 쓴다. 금액 외 수치는 해당 단위의 증감량을 쓴다. 비율 자체의 차이는 `%p`로 표시하고 상대 증감률 `%`와 구별한다.
- **대략적인 규모와 추정 조건을 함께 쓴다.** 상단에서는 읽기 좋은 자릿수로 반올림해 `약`으로 나타내되, 원자료의 정밀도보다 정확해 보이게 쓰지 않는다. 예상값은 `예상`·`추정`을 유지하고 범위와 주요 전제를 함께 둔다. 범위의 중간값을 확정액으로 바꾸지 않는다. 상세 내역에는 원래 수치, 산식, 비교 기간·범위와 출처를 남긴다.
- **계산할 수 없는 비율을 만들지 않는다.** 기준값이 0이면 전후 값과 증감액을 쓰고 증감률은 산출하지 않는다. `0 → 0`은 변동 없음으로 쓰고, 새 비용은 근거에 따라 실제 발생과 예상 발생을 구별한다. 기준값이 없으면 먼저 원자료를 확인하고, 확보하지 못하면 변경 금액만으로 증가율을 추측하지 않는다. 기준값이 음수이면 같은 비교 기준의 전후 값과 차이를 쓰되 기계적으로 비율을 붙이지 않는다. 비교 기간·범위가 다르고 환산 근거가 없으면 차이도 계산하지 않는다. 각 값을 따로 제시하고 비교에 필요한 기준을 확인한다.

다음은 같은 범위·세금 기준의 합성 예다. 기존 연 비용 1억 원, 예상 연 비용 1억 2천만 원이면 `연 비용은 기존 1억 원에서 1억 2천만 원으로, 약 2천만 원(20%) 늘어날 것으로 예상된다.`를 상세 내역보다 먼저 쓴다. 기존 연 비용 1억 원, 예상 연 비용 8천만 원이면 `연 비용은 기존보다 약 2천만 원(20%) 줄어든 8천만 원으로 예상된다.`라고 쓴다. 실제 보고서에는 확인한 해당 수치를 쓰며 이 예의 금액을 옮기지 않는다.

## 채택 전 대조

기존 스킬의 **의미·자료·자연스러움·과잉 교정** 조건으로 원문과 수정본을 대조한다. 보고 내용의 누락, 주장의 과장, 필요한 불확실성·실패·위험의 삭제를 확인한다. 조사 과제와 작성 과정 해설을 제거한 뒤에도 문장 호응과 지시 대상이 분명한지 읽는다. 맞춤법·띄어쓰기·문장 부호는 [표기 판단](orthography-decisions.md)에 따라 마지막에 점검한다.

문서 파일을 납품할 때는 [보고서 조판과 판본 대조](report-layout-verification.md)를 따른다. 조판 검증은 텍스트 추출과 별도로 한다. 최종 판본의 모든 쪽을 이미지로 보고, 절 제목이 다음 내용 없이 쪽 아래에 남지 않았는지, 이어지는 표의 머리행이 다음 쪽에도 반복되는지, 셀 안에서 단어가 의미 단위와 무관하게 갈리지 않았는지 확인한다. 한 쪽의 검사를 전체 합격으로 확대하지 않는다. 이 항목은 E1 편집 절차이며 맞춤법 오류와 구별한다.
