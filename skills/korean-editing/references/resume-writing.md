# 이력서와 경력기술서

채용 공고와 실제 경력 자료를 연결해 지원자의 적합성을 설명한다. 한국어 의미 보존 조건을 먼저 적용하고, 제출처의 지정 양식·항목·분량을 확인한다. 이력서의 경력 요약, 프로젝트를 풀어 쓰는 경력기술서, 연구 실적을 폭넓게 싣는 학술 CV를 구분한다.

## 근거와 적용 범위

Harvard의 직무 맞춤·사실 중심·읽기 쉬운 배열 권고(W-CV1), MIT의 프로젝트·행동·결과 구성(W-CV2)을 참고한다. 두 자료는 대학의 실무 권고다. 비생성형 글쓰기 보조를 시험한 온라인 노동시장 현장실험(W-CV3)은 명료한 표현의 가치를 뒷받침하지만 특정 양식·문장 공식·한국어 이력서의 합격률을 보장하지 않는다. 아래 근거 대조와 기여 구분은 E1 편집 절차다. 서지·열람 범위는 [출처 장부](source-ledger.md)에 둔다.

## 작성 순서

1. **지원 직무의 요구를 추린다.** 채용 공고의 필수 요건, 수행 업무, 우대 요건을 구분한다. 각각에 대응하는 실제 경험·산출물·성과를 작업 노트에서 연결한다. 공고가 없으면 제공된 목표 직무로 정리하되 특정 회사의 요구를 만들지 않는다.
2. **쓸 수 있는 사실을 확정한다.** 직장·직책·기간·학위·자격·프로젝트·본인 행동·팀 결과·근거 자료를 대조한다. 학위 과정과 학위 취득, 개발과 기획, 참여와 총괄, 시험 운영과 정식 도입을 구별한다. 경력 자료가 충돌하면 원자료나 의뢰자에게 확인하고 임의로 최신·유리한 값을 고르지 않는다. 연락처와 비공개 자료는 공개 예문·평가 기록으로 옮기지 않는다.
3. **직무와 관련된 근거부터 배열한다.** 상단 요약에는 전문 영역과 그 영역을 보여 주는 확인된 경험을 쓴다. 관련성이 높은 항목을 앞에 두고, 경력 항목 안의 시간 순서는 일관되게 유지한다. 역할에 맞춰 내용을 선별하되 경력 기간·직책을 바꾸지 않는다. 형용사 목록보다 실제 수행을 제시한다.
4. **경험을 행동과 결과로 쓴다.** 무엇을 해결하려 했는지, 본인이 무엇을 했는지, 어떤 산출물·결과가 확인되는지 연결한다. 한국어에서는 영어처럼 모든 항목의 첫 단어를 동사로 강제하지 않는다. `정의했다`, `분석했다`, `조율했다`, `개발했다`, `검수했다` 중 실제 책임에 맞는 서술어를 고른다. 한 항목에 서로 무관한 프로젝트를 몰아넣지 않는다.
5. **성과의 범위와 수치를 대조한다.** 전후 값·기간·표본·분모·단위를 확인한다. 비율 차이는 `%p`, 상대 변화는 `%`로 구별한다. 팀 성과는 팀 성과로 쓰고, 개인 기여율이나 인과관계가 확인되지 않으면 본인의 행동만으로 그 결과를 만들었다고 쓰지 않는다. 수치가 없으면 확인된 산출물·적용 범위·업무 규모를 쓴다. 매출·절감액·효율 개선율을 추정해 채우지 않는다.
6. **제출 형태에서 읽는다.** 공고의 용어 중 경험에 해당하는 표현만 자연스럽게 사용한다. 제목·날짜·목록 형식을 일관되게 맞추고, 파일을 제출할 때는 실제 렌더와 텍스트 추출 순서를 확인한다. PDF 변환에서 이름·직책·성과가 잘리거나 순서가 바뀌면 고친다. ATS의 통과·점수나 고정된 몇 초의 심사 시간을 약속하지 않는다.

## 확인된 사실로 구체화하는 예

아래는 직접 만든 가상 자료다. 실제 지원자의 성과로 재사용하지 않는다.

- 자료: 3명 팀에서 본인이 현업 15명을 인터뷰하고 문의 분류 기준 30개를 정리했다. 검수 회의 2회를 조율했다. 처리 시간과 비용 효과는 측정하지 않았다.
- 초안: `뛰어난 소통 능력으로 업무 효율을 크게 개선했습니다.`
- 수정: `현업 15명을 인터뷰하고 문의 분류 기준 30개를 정리했으며, 3명 팀의 검수 회의 2회를 조율했습니다.`

수정문은 행동·범위·산출물을 보여 준다. 자료에 없는 효율 개선이나 절감액을 덧붙이지 않는다. `검수 담당`을 `개발 총괄`로 바꾸는 식의 직무 확대도 하지 않는다.

## 제출 전 확인

- 각 요약·경험 항목이 채용 공고의 어떤 요구와 연결되는가?
- 면접에서 본인의 행동과 산출물을 설명하고, 수치의 출처·산식을 제시할 수 있는가?
- 팀 성과·개인 역할·프로젝트 단계와 실제 기간이 원자료와 같은가?
- 근거 없는 최상급·능력 평가를 실제 경험으로 바꾸었는가?
- 요구 분량과 양식에 맞고, 출력 파일에서도 연락처·날짜·경력 순서가 읽히는가?

이력서 본문을 먼저 전달한다. 내부 근거표나 모든 조사 경위를 이력서에 붙이지 않는다. 필요한 사실을 확보하지 못한 부분은 다른 항목의 작성을 진행하면서 의뢰자에게 별도로 묻는다. 지원자의 확인 없이 경력·학력·자격을 보완하지 않는다.
