# 문서 조판과 판본 대조

보고서·이력서·경력기술서·자기소개서 등 문서 파일을 납품할 때 적용한다. 표·도식에 관한 항목은 해당 요소가 있을 때만 확인한다. 아래 절차는 E1 편집 절차이며 맞춤법 규칙이 아니다.

## 전 페이지 확인

1. 최종 원본으로 문서를 다시 렌더한 뒤 모든 쪽을 이미지로 본다. 텍스트 추출, 구조 검증, 일부 쪽 검사는 전체 조판 합격이 아니다.
2. 절 제목은 다음 내용과 같은 쪽에 둔다. 제목만 쪽 아래에 남으면 다음 쪽으로 함께 넘긴다.
3. 다음 쪽으로 이어지는 표는 머리행을 반복한다. 한 칸의 긴 내용은 의미 단위로 나누고, 단어 중간에서 줄을 바꾸지 않는다.
4. 도식의 라벨이 아이콘·테두리와 겹치거나 밖으로 나가지 않는지 본다. 캡션은 도식에 실제로 있는 범위를 말한다. 정상 구조와 위험 경로가 함께 있으면 둘 다 캡션에 밝힌다.
5. 같은 결함이 다시 나오면 수정 후 모든 쪽을 다시 확인한다. 이전 판본의 검사 결과를 재사용하지 않는다.

## 정정 판본 대조

새 파일을 받았거나 생성했으면 직전 채택본과 대조한다. 실제 납품 파일에서 행위자·직책·기간·수치·학위·성과 범위와 문장을 확인한다. 조판만 고치면서 이전 정정이 되돌아가거나, 표제를 옮기면서 다른 회사·기간에 속한 활동처럼 보이지 않는지 확인한다. 묶음 문서는 같은 사실의 표기를 서로 대조한다. 최신 파일이라고 해서 이전 정정이 모두 들어 있다고 보지 않는다.

문구나 조판을 다시 수정했다면 그 판본을 렌더해 모든 쪽을 확인한다. 텍스트 추출 순서는 시각 검증과 별도로 대조한다. 초안 텍스트나 이전 PDF의 검사로 최종 파일 검증을 대신하지 않는다. 렌더링을 수행하지 못했으면 확인한 범위만 보고한다.
