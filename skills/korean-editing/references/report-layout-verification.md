# 보고서 조판과 판본 대조

문서 파일을 납품할 때 적용한다. 아래 절차는 E1 편집 절차이며 맞춤법 규칙이 아니다.

## 전 페이지 확인

1. 최종 원본으로 문서를 다시 렌더한 뒤 모든 쪽을 이미지로 본다. 텍스트 추출, 구조 검증, 일부 쪽 검사는 전체 조판 합격이 아니다.
2. 절 제목은 다음 내용과 같은 쪽에 둔다. 제목만 쪽 아래에 남으면 다음 쪽으로 함께 넘긴다.
3. 다음 쪽으로 이어지는 표는 머리행을 반복한다. 한 칸의 긴 내용은 의미 단위로 나누고, 단어 중간에서 줄을 바꾸지 않는다.
4. 도식의 라벨이 아이콘·테두리와 겹치거나 밖으로 나가지 않는지 본다. 캡션은 도식에 실제로 있는 범위를 말한다. 정상 구조와 위험 경로가 함께 있으면 둘 다 캡션에 밝힌다.
5. 같은 결함이 다시 나오면 수정 후 모든 쪽을 다시 확인한다. 이전 판본의 검사 결과를 재사용하지 않는다.

## 정정 판본 대조

새 파일을 받았으면 직전 채택본과 대조한다. 조판만 고친 파일이 이미 확정한 행위자·수치·문장을 되돌리지 않았는지 확인한다. 최신 파일이라고 해서 이전 정정이 모두 들어 있다고 보지 않는다.
