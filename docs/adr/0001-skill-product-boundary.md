# ADR-0001: 두 Agent Skill과 평가 증거를 제품 경계로 둔다

- Status: Proposed
- Date: 2026-10-01

## 문제

repository에는 한국어 퇴고, APA 7 원고 작성, 원문 조사, 합성 평가와 과거
실행 기록이 함께 있다. 실행 도구의 내부 상태까지 제품으로 취급하면 공개
표면에 로컬 경로와 임시 식별자가 섞이고, 제한된 평가가 과장될 수 있다.

## 제약

- 확인한 원문의 판본·절·쪽과 미확인 범위를 보존한다.
- 사용자 원문, 참여자 자료와 비밀정보는 저장하지 않는다.
- 개별 합성 사례는 전체 타당도나 APA 준수 인증이 아니다.
- 현재 repository에는 독립 서비스·DB·UI 운영 경계가 없다.

## 결정

제품 경계를 `Korean Editing Skill`, `APA 7 Manuscript Skill`, `Evaluation
Evidence` 세 Context로 제한한다. 외부 근거는 source ledger에 확인 범위와
접근 상태를 기록한 뒤 사용한다. 이는 현재 정책 경계이며 자동 ACL은 아니다.
로컬 실행 상태는 공개 계약에서 제외하고 공개 hygiene 검사를 repository
test로 유지한다.

## 검토한 대안

- **모든 작업 기록 보존**: 재현 정보와 runtime 상태를 구분하지 못해 기각했다.
- **평가 기록 전부 삭제**: 유효한 실패·수정·한계 증거를 잃으므로 기각했다.
- **DB 기반 평가 서비스 구축**: 현재 반복 운영 책임이 없어 과도하므로
  선택하지 않았다.

## 영향과 위험

공개 문서는 역할·상대 경로·hash 중심으로 재현 가능해진다. 운영 로그만으로
증명하던 세션 격리는 공개 기록에서 직접 입증할 수 없으므로 한계로 남긴다.
향후 사용자 자료 저장이나 자동 실행이 필요해지면 별도 보안·보존·삭제 계약과
새 ADR이 선행되어야 한다.
