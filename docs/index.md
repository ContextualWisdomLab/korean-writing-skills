# Korean Writing Skills

[![Ask DeepWiki](https://deepwiki.com/badge.svg)](https://deepwiki.com/ContextualWisdomLab/korean-writing-skills)

한국어 글을 쓰고 다듬는 스킬과 APA 7 학술 원고를 작성·점검하는 스킬을 제공합니다. 두 스킬의 설치와 사용 방법은 [사용 안내](usage.md)에 있습니다.

## 제공 범위

- [`korean-editing`](../skills/korean-editing/): 한국어 대화·문서 작성과 의미·수치·불확실성을 보존하는 퇴고 절차
- [`apa7-manuscript-writing`](../skills/apa7-manuscript-writing/): 확인된 APA 7·JARS 범위에 한정한 원고 작성·점검 절차
- [`evaluations`](../evaluations/): 입력·판본·출력·판정·한계를 기록한 합성 평가와 회귀 검증 자료

스킬 지침과 README를 다듬을 때는 [지침과 사용 안내 다듬기](../skills/korean-editing/references/instructions-and-guides.md)를 적용합니다. 규칙의 강도와 조건·예외를 보존하고, 실제 수정한 내용과 검증 결과를 기록합니다.

두 스킬은 초안이며, 개별 합성 사례 통과를 전체 타당화나 완전한 APA 준수로 해석하지 않습니다. 현재 검증 범위와 남은 작업은 [`TODO.md`](../TODO.md)에서 확인할 수 있습니다.
