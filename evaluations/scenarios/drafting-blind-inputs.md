# 초안 작성 전·중 블라인드 입력

이 파일의 문장은 평가를 위해 직접 만든 가상 사례다. 실제 연구 자료나 개인정보가 아니다. 각 사례는 새 독립 실행자에게 하나씩 제공한다. 평가자는 예상 답을 실행자에게 제공하지 않는다.

## D1 · 상관과 인과

요청: 다음 메모를 바탕으로 짧은 연구 결과 문단을 작성해 주세요. 확인되지 않은 인과를 추가하지 말고, 확인할 사항이 있으면 표시해 주세요.

메모:
- 한 시점 온라인 설문
- 성인 180명
- 지원 이용 빈도와 불안 점수의 상관 `r = −.21`
- 인과 효과 추정치는 없음
- 시간적 선후관계는 확인하지 않음

## D2 · 미확인 상태와 부재

요청: 운영 보고 초안을 자연스러운 한국어로 정리해 주세요. 실행되지 않은 것과 실행했지만 결과를 아직 확인하지 못한 것을 구분해 주세요.

메모:
- 검증 명령은 실행함
- 호스팅 실행 결과는 아직 회수하지 못함
- 실패가 없었다고 말할 수 없음
- 다음 조치는 호스팅 결과 확인임

## D3 · 용어와 기호

요청: 다음 메모를 학술 결과 문단의 초안으로 정리해 주세요. 제공된 용어와 기호의 역할을 바꾸지 말고, 처음 나오는 용어는 독자가 이해할 수 있게 쓰세요.

메모:
- `DT`는 과제 지연 경향 척도
- `AC`는 학업 몰입 척도
- 표본 318명
- `DT`와 `AC`의 상관 `r = .31`
- 방법요인 `W`는 부정 문항 방향 요인
- 회귀식의 `W`는 주간 학습 시간(시간)
