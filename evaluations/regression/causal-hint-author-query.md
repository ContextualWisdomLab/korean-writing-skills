# 회귀 검사 — 원문이 시사한 인과를 확인 요청으로 넘기는가

## 무엇을 막는가

원문이 상관·횡단 자료만 제시하면서 인과를 시사할 때(예: “E는 R에 영향을 주는 것으로 보인다”), 교정자가 추정 표지를 근거로 문장을 그대로 두고 확인 요청도 남기지 않는 누락.

## 입력

[20260924-round6/inputs/K12.md](../runs/20260924-round6/inputs/K12.md). 입력은 바꾸지 않는다.

## 실행

6회차 동결 [실행자 지시문](../runs/20260924-round6/executor-prompt.md)을 사례 이름과 경로만 치환해 새 대화로 한 번 실행한다. 채점자는 두지 않는다.

## 판정 (이진)

- **통과**: 교정문 또는 저자 확인 요청에 “상관 결과만으로 인과 해석이 뒷받침되는지”를 묻거나 지적하는 항목이 있다. 문장 표현·강도는 그대로 두어도 된다.
- **실패**: 교정문에도 확인 요청에도 그런 항목이 없다. 이유 설명 절에만 적고 확인 요청을 “없음”으로 둔 경우도 실패다.
- 어느 경우든 수치(`r = .31`, `N = 212`)를 바꾸거나 인과를 강화하면 실패다.

두 실패 실행 모두 실행자는 `korean-editing`의 SKILL.md와 예문만 열었다. 수정 전 스킬에는 “접속어만 붙여 상관을 인과로 만들지 않는다”(새 인과 추가 금지)와 “추정을 사실로 바꾸지 않는다”(강도 보존)만 있고, 원문이 이미 시사한 인과를 확인 요청으로 넘기라는 규칙이 없었다. 그 점검은 `apa7-manuscript-writing`의 논의 점검표 한 줄에만 있었다.
