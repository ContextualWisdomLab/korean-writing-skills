# K16 사전 채점 기준 (채점자 전용)

실행 전에 고정한다. 실행자에게 주지 않는다. 채점은 [three-axis.md](../../rubrics/three-axis.md)와 [analytic-korean-editing.md](../../rubrics/analytic-korean-editing.md)를 따른다. 모범 교정문은 두지 않으며 문구 일치는 채점하지 않는다. 입력은 합성 예문이다.

## 공통

- **접근 범위.** 실행자의 “열어본 파일” 목록에 아래 “실행자 허용 파일” 밖 경로가 하나라도 있으면 판정은 **보류**다. 접근 준수는 “자기보고상”이라고만 쓴다.
- 입력의 값과 위치(2-3, 3.2절, 표 2, 2.3절, 1989, 2002, Y)를 다른 값으로 바꾸면 중대 오류다.

## 실행자 허용 파일

K15와 같다(입력 1개, apa7 SKILL.md와 references 6개, korean-editing SKILL.md와 references 3개, 결과 파일 1개).

## 확인할 지점

| 지점 | 확인할 것 | 중대 오류 |
| --- | --- | --- |
| 제출하지 않는 문서 참조 | “내부 분석 노트 3.2절”이 제출 파일(원고·응답서) 밖이라는 점을 지적하고, 그 문서를 제출할지 응답서를 자기완결로 고칠지 저자 확인 사항으로 남겼는가 | 없는 원고 위치(예: 새 부록 번호)를 만들어 바꿔 넣음 |
| 참고문헌에서 풀리지 않는 인용 | Vuong (1989)이 원고 참고문헌에 없다는 점을 지적하고, 참고문헌 추가 여부를 저자 확인 사항으로 남겼는가 | 서지 정보를 지어내 참고문헌 항목을 만듦. 인용을 조용히 지움 |
| 풀리는 참조 | 원고 표 2, 방법 2.3절, Muthén (2002)을 그대로 두었는가 | 이들을 문제로 잘못 지적하거나 지움 |
| 척도 정식 명칭 | 응답서의 “수면 문제(Y)”를 확인된 정식 명칭 “수면 곤란 수준(Y)”으로 맞췄거나 불일치를 지적했는가 | 다른 이름을 새로 만듦. Y의 대응을 바꿈 |
| 다른 도구 이름 | “불면 선별 질문지”를 Y나 수면 곤란 척도로 바꾸지 않았는가 | 선별 질문지를 Y로 합침 |
| 문장 교정 | 응답서 문장을 의미를 바꾸지 않고 다듬었는가 | 없는 결과·검정을 만듦 |

두 지점(제출하지 않는 문서, 풀리지 않는 인용)을 모두 지적하지 않으면 의미 보존·과잉 교정 억제와 별도로 **실패**로 본다. 하나만 지적하면 해당 축을 2점 이하로 본다.

척도 정식 명칭을 맞추지도 지적하지도 않으면 의미 보존을 2점 이하로 본다. 선별 질문지를 Y로 바꾸면 중대 오류다.
