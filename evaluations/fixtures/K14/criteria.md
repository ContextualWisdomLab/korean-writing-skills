# K14 사전 채점 기준 (채점자 전용)

실행 전에 고정한다. 실행자에게 주지 않는다. 채점은 [three-axis.md](../../rubrics/three-axis.md)와 [analytic-korean-editing.md](../../rubrics/analytic-korean-editing.md)를 따르고, 이 문서는 확인할 지점과 중대 오류만 정한다. 모범 교정문은 두지 않는다. 정해진 문구와의 일치는 채점하지 않으며, 의미와 요청 범위가 맞는 편집 선택은 모두 인정한다. 근거 대응은 [apa7-basis.md](apa7-basis.md)에 있다.

## 공통

- **접근 범위.** 실행자의 “열어본 파일” 목록에 아래 “실행자 허용 파일” 밖 경로가 하나라도 있으면 내용과 관계없이 판정은 **보류**다. 접근 준수는 자기보고로만 알 수 있으므로 “자기보고상”이라고만 쓴다.
- 보존 앵커가 확인 요청·대안 문구에만 있고 교정문 본문에 없으면 보존되지 않은 것으로 본다.
- 입력의 값(0.42, 156, 6.8, 1.1, .18, .07, .29, 0.31, 0.08, 2021년 10월)을 다른 값으로 바꾸면 중대 오류다. 선행 0의 표기 형식을 고치는 것은 값 변경이 아니다.

## 실행자 허용 파일

- 해당 사례 입력 파일 1개(격리 디렉터리)
- `skills/apa7-manuscript-writing/SKILL.md`와 `skills/apa7-manuscript-writing/references/` 아래 파일 6개(document-format-checklist, jars-quant-table1, reporting-workflow, source-ledger, validation, verified-scope)
- `skills/korean-editing/SKILL.md`와 `skills/korean-editing/references/` 아래 파일 3개(examples, source-ledger, validation)
- 결과 파일 1개(쓰기 전용)

## A. 통계 표기 (APA 규정·공식 안내)

| 점검 지점 | 확인할 것 | 중대 오류 |
| --- | --- | --- |
| `r = 0.42` | 선행 0 생략 여부 | 값을 바꿈 |
| `p = 0.000` | 정확한 *p*를 지어내지 않고 `.001`보다 작다는 형식으로 바꾸었는지, 또는 원출력 확인을 요청했는지 | `p = .000`처럼 영 확률로 남기며 지적하지 않음은 감점. 임의의 정확한 *p* 값을 만들면 중대 오류 |
| `R² = .18` | 이미 규정에 맞는 표기를 바꾸지 않았는지 | — |
| `b = 0.31`, `SE = 0.08`, `M = 6.8`, `SD = 1.1` | 1을 넘을 수 있는 통계의 선행 0을 지우지 않았는지 | 0을 지우면 과잉 교정 감점 |
| `M`·`SD` 정의 문구 | 통계 기호 정의 문구를 없앴거나 없애도록 지적했는지 | — |
| `95% CI` | 첫 사용에서 CI를 정의했는지 | CI를 신용구간 등 다른 개념으로 바꾸면 중대 오류 |
| `위의 표와 같이` | 번호(`표 1`)로 지시했는지 | 없는 표 번호를 만들면 중대 오류(입력에 `표 1`이 있으므로 그 번호는 허용) |
| 표·본문 중복 | 중복을 지적하거나 줄이는 처리를 했는지. 표를 볼 수 없으므로 저자 확인 요청으로 남기는 것도 인정 | 계수 값을 바꿈 |

## B. 첫 투고 방법 문단 (저자 요구 — APA 규정 아님)

- 이 연구의 결정·분석을 현재형 자기 서술로 썼는지.
- `31–33쪽` 같은 학위논문 쪽수를 본문에 남기지 않았는지.
- 자료의 출처가 이전 연구라는 사실은 중립적으로 남겼는지, 또는 저자 확인 요청으로 두었는지(둘 다 인정). 새로 수집한 자료처럼 바꾸면 중대 오류.
- `2021년 10월에 … 수집되었다`의 과거 시제를 유지했는지. 끝난 수집을 현재형으로 바꾸면 중대 오류.
- 현재형 요구를 APA 규정이라고 설명하면 과잉 교정 감점(근거 종류 혼동).

## C. 공통 중대 오류

- 없는 결과·검정·수치를 만듦.
- 상관을 인과로 강화함.
- 입력에 없는 표본 특성·IRB·학술지 정보를 만듦.
