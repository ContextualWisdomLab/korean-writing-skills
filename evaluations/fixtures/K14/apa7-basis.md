# K14 근거 대응표

K14 입력의 각 점검 지점이 어느 근거에 기대는지, 그 근거가 규정인지 저자 요구인지 적는다. 근거의 원문 인용과 확인 범위는 [apa7 source-ledger](../../../skills/apa7-manuscript-writing/references/source-ledger.md)에 있다. 이 파일은 평가 답안이 아니다.

| 입력 지점 | 근거 | 종류 | 장부 위치 |
| --- | --- | --- | --- |
| `r = 0.42` | Manual 6.36: 1을 넘을 수 없는 통계(상관·비율·유의수준)는 소수점 앞 0을 쓰지 않는다 | APA 규정 | source-ledger 6.36 항목 |
| `p = 0.000` | Manual 6.36(선행 0) + A-NUM(정확한 *p*, .001보다 작으면 `< .001` 형식) | APA 규정 + APA 공식 안내 | 6.36, A-NUM |
| `R² = .18` | Manual 6.36: 1을 넘을 수 없는 값의 선행 0 생략 | APA 규정 | 6.36 |
| `b = 0.31`, `SE = 0.08`, `M = 6.8`, `SD = 1.1` | Manual 6.36: 1을 넘을 수 있는 통계는 1보다 작을 때 소수점 앞 0을 쓴다 | APA 규정 | 6.36 |
| `여기서 M은 평균, SD는 표준편차를 뜻한다` | Manual 6.44: *M*, *SD* 등 통계 기호는 정의하지 않는다 | APA 규정 | 6.44 |
| `95% CI` | A-NUM: 통계 기호가 아닌 약어(CI)는 첫 사용에서 정의한다 | APA 공식 안내 | A-NUM |
| `위의 표와 같이` | Manual 7.5: 표는 번호로 지시하고 “위 표/아래 표”로 쓰지 않는다 | APA 규정 | 7.5 |
| `표 1의 계수를 본문에 다시 나열하면` | A-NUM: 표와 본문에 같은 통계를 중복하지 않는다 | APA 공식 안내 | A-NUM |
| 방법 문단의 현재형 자기 서술 | 저자 요구(요청문). **APA 규정이 아니다.** 시제에 관한 Manual 절은 이 저장소에서 읽지 않았다 | 저자 요구 | apa7 SKILL.md 첫 투고 원고 지침(조건부) |
| `(2022, 31–33쪽)` 학위논문 쪽수 | 저자 요구(요청문). APA 규정이 아니다 | 저자 요구 | 같은 지침 |
| `2021년 10월에 … 수집되었다` | 실제로 끝난 절차의 시제는 바꾸지 않는다 | 편집 판단(스킬 지침) | apa7 SKILL.md 같은 문단 |

채점에서 쓰지 않는 것: 통계 기호의 이탤릭 여부(입력이 일반 텍스트라 판별할 수 없다), 표 번호·제목 서식(Manual 7.10–7.11 미독), 시제에 관한 APA 세칙.
