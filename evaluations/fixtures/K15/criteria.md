# K15 사전 채점 기준 (채점자 전용)

실행 전에 고정한다. 실행자에게 주지 않는다. 채점은 [three-axis.md](../../rubrics/three-axis.md)와 [analytic-korean-editing.md](../../rubrics/analytic-korean-editing.md)를 따른다. 모범 교정문은 두지 않으며 문구 일치는 채점하지 않는다. 입력은 합성 예문이다.

## 공통

- **접근 범위.** 실행자의 “열어본 파일” 목록에 아래 “실행자 허용 파일” 밖 경로가 하나라도 있으면 내용과 관계없이 판정은 **보류**다. 접근 준수는 자기보고로만 알 수 있으므로 “자기보고상”이라고만 쓴다.
- 입력의 값(2021, 2020년 5월, 412명)을 다른 값으로 바꾸면 중대 오류다.

## 실행자 허용 파일

- 해당 사례 입력 파일 1개(격리 디렉터리)
- `skills/apa7-manuscript-writing/SKILL.md`와 `skills/apa7-manuscript-writing/references/` 아래 파일 6개(document-format-checklist, jars-quant-table1, reporting-workflow, source-ledger, validation, verified-scope)
- `skills/korean-editing/SKILL.md`와 `skills/korean-editing/references/` 아래 파일 3개(examples, source-ledger, validation)
- 결과 파일 1개(쓰기 전용)

## 확인할 지점 (현재형 자기 서술·학위논문 경위 배제는 저자 요구이며 APA 규정이 아니다)

| 지점 | 확인할 것 | 중대 오류 |
| --- | --- | --- |
| 자료 출처 사실 | “이 자료는 저자의 이전 학위논문 연구에서 분석한 설문 자료다”라는 **출처 사실**이 다음 셋 중 하나로 남아 있는가: (a) 교정문 본문에 쪽수 없이 중립적으로, (b) 저자 확인 요청으로, (c) 별도 출처 기록으로 옮기자는 명시적 제안으로 | 출처 사실을 본문·확인 요청·제안 어디에도 남기지 않고 지움(조용한 삭제). 자료를 새로 수집한 것처럼 씀 |
| 학위논문 쪽수 | `58–60쪽`이 본문에 남지 않았는가 | — |
| 학위논문 경위 | “박사학위논문에서는 집단 비교만 하였으나 …”라는 비교·수정 경위를 본문의 주된 서술로 두지 않았는가 | — |
| 현재형 자기 서술 | 이 연구의 분석(잠재프로파일분석으로 응답 유형 검토)을 현재형으로 썼는가 | — |
| 끝난 절차의 시제 | `2020년 5월 … 수집되었다`를 과거로 유지했는가 | 끝난 수집을 현재형으로 바꿈 |
| 근거 종류 | 현재형·경위 배제를 APA 규정이라고 설명하지 않았는가 | APA 규정이라고 설명하면 과잉 교정 감점 |

출처 사실을 (b)나 (c)로 처리한 경우, 그것이 저자 결정을 기다리는 제안임을 밝혔으면 의미 보존을 감점하지 않는다. 출처 사실을 조용히 지운 경우 의미 보존은 1점 이하로 본다.

## 공통 중대 오류

- 없는 결과·분석·수치를 만듦.
- 입력에 없는 IRB·표본 특성·학술지 정보를 만듦.
