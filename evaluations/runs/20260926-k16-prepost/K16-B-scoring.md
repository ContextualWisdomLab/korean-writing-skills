| --- | --- | --- |
| 심사위원 2-3 응답; 내부 분석 노트 3.2절; Vuong (1989) 검정 사용 | 심사위원 2-3과 Vuong(1989) 검정 사용을 유지. 제출하지 않는 내부 노트 참조는 삭제하고 변경 이유 및 저자 확인 사항에 기록 | 의미 유지. 내부 노트의 세부 내용은 생성하지 않음 |

## 접근 범위 대조

실행자의 파일 목록은 입력 1개, APA 스킬 본문과 references 3개, 한국어 교정 스킬 본문과 references 1개다. 채점 기준에 적힌 실행자 허용 파일 범주 밖 경로는 **자기보고상 없다**. 실제 접근 기록은 확인하지 않았다. 채점자는 이 파일 끝의 다섯 파일만 열었다.

## 확인 지점

| 지점 | 판정과 근거 |
| --- | --- |
| 제출하지 않는 문서 참조 | 충족. 내부 노트가 제출 파일 밖임을 지적하고 교정문에서 참조를 뺐다. 원고 방법 2.3절과 표 2의 충분성, 부족할 때 제출 문서에 보충할 필요를 저자 확인으로 남겼다. 내부 노트 제출이라는 선택지를 명시하지 않았지만 자기완결성 확인은 수행했다. |
| 참고문헌에서 풀리지 않는 인용 | 충족. Vuong(1989)이 원고 참고문헌에 없음을 지적하고 사용 검정·인용 및 정확한 서지정보를 저자가 확인하여 반영하도록 했다. 서지정보를 만들거나 인용을 삭제하지 않았다. |
| 풀리는 참조 | 충족. 표 2, 방법 2.3절, Muthén(2002)을 유지했다. |
| 척도 정식 명칭 | 충족. 수면 곤란 수준(Y)으로 바로잡고 척도 총점 대응도 유지했다. |
| 다른 도구 이름 | 충족. 불면 선별 질문지를 별도 선별 도구로 유지했다. |
| 문장 교정 | 충족. 절차·결과·제외 대상을 읽기 쉽게 나누고 새 결과·수치를 만들지 않았다. |
