# 교정문

심사위원 2-3에 대한 응답: 측정 동일성 검토 절차는 원고의 방법 2.3절에 요약하였고(Muthén, 2002), 검토 결과는 표 2에 제시하였습니다. 모형 비교에는 Vuong (1989)의 검정을 사용하였습니다. 종속변수인 수면 곤란 수준(Y; 수면 곤란 척도 총점)은 집단 간 동일성이 유지되었습니다. 선별 목적으로만 사용한 불면 선별 질문지는 이 검토에 포함하지 않았습니다.

## 주요 변경과 근거

- 내부 분석 노트 3.2절을 응답의 근거 위치에서 뺐습니다. 실제로 노트에 상세 절차가 있다는 원문 사실은 부정하지 않지만, 이번 제출물에 노트가 없어 심사자가 열람할 수 없으므로 제출 원고의 방법 2.3절과 표 2를 앞세웠습니다. **편집 판단·저자 제공 제출 조건.**
- `수면 문제(Y)`를 원고에서 확인된 `수면 곤란 수준(Y; 수면 곤란 척도 총점)`으로 고쳤습니다. 변수의 지시 대상과 이름을 제출 원고에 맞췄습니다. **저자 제공 원고 정보·편집 판단.**
- 절차, 모형 비교, 결과, 선별 질문지의 제외 범위를 각각 읽히도록 문장을 나눴습니다. 수행 여부나 동일성 결과는 바꾸지 않았습니다. **편집 판단.**
- `Muthén (2002)`과 `Vuong (1989)` 인용은 유지했습니다. 출처 확인 없이 특정 인용을 삭제하거나 다른 문헌으로 바꾸지 않았습니다. **의미 보존·편집 판단.**
- `집단 간 동일성이 유지되었다`는 결과 진술과 불면 선별 질문지를 검토에 포함하지 않았다는 사실을 유지했습니다. 원자료 없이 동일성의 단계나 검정 수치를 덧붙일 수 없습니다. **의미 보존·편집 판단.**

## 제출 전 확인·수정

- 내부 노트에만 있는 필수 절차가 있다면 원고 방법 2.3절에 옮겨 심사자가 원고만으로 검토할 수 있게 하십시오. 현재 2.3절이 어디까지 설명하는지는 제공된 문장만으로 확인할 수 없습니다. **편집 판단·저자 제공 제출 조건.**
- Vuong 검정을 실제 모형 비교에 썼는지 분석 기록과 원고 방법 2.3절을 대조하십시오. 원고 본문에서 Vuong (1989)를 인용한다면, 현재 원고 참고문헌에 없는 해당 문헌의 정확한 서지를 확인하여 추가해야 합니다. APA 7판 8.4절은 원고 본문 인용과 참고문헌의 대응을 요구합니다. 응답서에만 있는 인용을 근거로 원고의 8.4절 위반이라고 단정하지 않습니다. **APA 규정·공식 근거 범위·편집 판단.**
- 방법 2.3절의 `Muthén (2002)`이 실제로 해당 절차를 뒷받침하는지 원문과 원고를 대조하십시오. 이미 원고 참고문헌에 있다는 사실만으로 인용의 적합성이 입증되지는 않습니다. **편집 판단.**
- 표 2와 원고 방법 2.3절이 집단 간 동일성 결과 및 불면 선별 질문지의 제외 범위를 교정문과 일치하게 설명하는지 확인하십시오. 빠진 내용이 있으면 원고에도 반영한 뒤 응답서의 절·표 위치를 다시 확인하십시오. **편집 판단.**
- 박서연 (2019)은 이 응답 문단에서 인용하지 않았다는 이유만으로 원고 참고문헌에서 삭제하지 않았습니다. 원고 본문에서 실제로 인용되는지는 원고 전체와 대조해야 합니다. **APA 7판 8.4절·과잉 교정 방지.**
