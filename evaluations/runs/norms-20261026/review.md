# 한국어 규정·퇴고 보강 평가

확인일: 2026-10-26. 한국어 스킬만 보강했으며 APA 스킬은 변경하지 않았다.

## 반영 내용과 근거

국립국어원 한글 맞춤법 제41–50항과 공식 해설, 문장 부호 선택 절을 직접 읽어 `orthography-decisions.md`에 판별 절차를 추가했다. 조사·의존 명사, 단위·수, 보조 용언 예외, 성명·고유 명사·전문용어, 문장 부호의 원칙과 허용을 구별한다.

서강대학교 글쓰기센터의 단락 쓰기·글의 구성과 장경희의 1999년 기고문 선택 절을 직접 읽어 `paragraph-revision.md`에 수정·유지·보류 사례를 추가했다. 대학 교육·저자 설명은 어문 규정과 구별했다. 원문 링크·직접 열람 범위·미확인 한계는 스킬의 출처 장부에 있다.

## 독립 실행·채점

설계자는 스킬 본문과 작성자 예문을 읽지 않고 입력 세 개와 고정 기준을 작성했다. 실행자는 사례마다 별도 문맥에서 지정 스킬과 해당 입력만 읽었다. 과거 예문·validation·채점 기준·다른 출력 열람을 금지했다. 채점자는 버전 대응표와 스킬을 받지 않고 입력·익명 출력·고정 기준을 대조했다. 별도 문맥과 지시 기반 제한이며 OS 수준 격리는 아니다. 역할 분리는 이질적 모델 구성이나 일반적 성능 향상의 증거가 아니다.

| 사례 | 기존판 | 보강 v1 | 최종 v2 |
| --- | --- | --- | --- |
| 안내문 C01 | P02 통과 | P05 통과 | F01 통과 |
| 연구보고 C02 | P01 통과 | P03 통과 | F02 통과 |
| 운영 메모 C03 | P04 실패 | P06 통과 | F03 통과 |

기존판 P04는 숫자 날짜 `2026. 9. 1~9. 14.`의 시작일 끝 점을 누락했다. 필수 점검 C03.O03 실패이며 날짜 값은 보존되어 중대 오류는 아니다. 실패 기록과 첫 채점은 그대로 보존했다.

최종 v2는 의미 앵커 55개·필수 점검 18개를 모두 충족했다. 세 출력 모두 의미 보존·한국어 자연스러움·과잉 교정 억제 각 3점, 중대 오류 0건이다. 부모가 항목 ID의 정확한 집합·중복 없음, 입력/출력 해시, 의미 앵커 인용의 실제 포함, 판정 논리와 수량을 코드로 대조했다. 세 사례 각 한 번의 결과이며 일반화·통계적 개선·채점자 일치도·실제 팀 사용 완료를 뜻하지 않는다.

입력과 기준은 `C01-input.md`–`C03-input.md`, `criteria.json`, 출력은 `P01-output.md`–`P06-output.md` 및 `F01-output.md`–`F03-output.md`, 채점은 `grading-v1.json`·`grading-v2.json`이다. 판본 해시는 `baseline-hashes.json`·`candidate-v1-hashes.json`·`candidate-v2-hashes.json`, 최초 익명화의 공개 후 대응표는 `execution-map.json`이다. 공개 전 비공개 작업 루트의 치환을 점검했으나 두 채점 JSON에는 해당 문자열이 없어 원본과 공개본의 바이트·SHA-256이 동일하다. 점수·판정·입출력도 수정하지 않았다.

## 내용 검토와 수정

첫 독립 내용 검토는 NONPASS였다.

- CRV1-01: 명사형 문장 마침표 생략 설명에 연속 문장 조건이 부족했다. 앞 문장 끝의 필수 점과 마지막 문장의 생략 허용을 명시했다.
- CRV1-02: 기존 운영 보고 예문이 테스트 통과 사실을 편집 방침 문장으로 바꾸고 있었다. 통과와 실패 진술을 둘 다 보존하고 교정문 밖에서 범위를 묻게 고쳤다.

재검토는 두 수정에 한정한 PASS다. 두 파일 각 한 행 교체와 나머지 네 파일의 바이트 동일성을 확인했다. 최초 전체 변경 검토와 후속 좁은 검토를 합쳐 기록하며, 새 전체 원문 인증으로 부르지 않는다. 수정 후 최종 v2도 세 사례를 새로 실행·채점했다.

## 검증과 잔여 범위

- 저장소 단위 시험 104건 통과. 구조·상대 링크, 출처 ID, 기존 추적 파일 공개 hygiene 검사 통과.
- 최종 스킬로 두 번 빌드한 패키지·manifest가 동일하다. ZIP 두 개의 13개 멤버를 manifest 및 원본 바이트와 대조했다. 한국어 패키지는 6파일이다.
- 기존 평가 파일 177개의 해시를 보존했다. 현재 스킬 6파일은 재검토한 v2 해시와 일치한다.
- 수치와 패키지 해시는 `verification.json`에 있다. 원문 전체·개별 사전 표제어·관보 연혁·장문 및 전문 분야 전반은 전수 검증하지 않았다.
- 이 평가를 마친 시점에는 로컬 보강·검증만 완료했고 커밋·푸시·공식 release·전역 설치는 수행하지 않았다. 이후 PR 게시·병합 상태는 GitHub의 해당 PR 기록에서 확인한다. 실제 팀 사용과 일반 타당화는 이 평가로 완료되지 않는다.
