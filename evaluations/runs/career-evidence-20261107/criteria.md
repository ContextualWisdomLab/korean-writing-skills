# 독립 적용 점검 기준

이 기준은 실행 출력이 생기기 전에 작성하고 해시로 고정한다. 정답 문구나 표현 일치는 채점하지 않는다. 입력 두 건은 합성 자료이며 실제 지원서·회사 자료와 무관하다. 기본 틀은 [기존 3축 루브릭](../../rubrics/three-axis.md)이며, 새 작성 과제에 맞춰 세 번째 축을 요청 범위·형식 준수로 관찰한다. 의미 보존 / 자연스러움 / 요청 범위·형식 준수를 각각 0~3점으로 평가한다. 각 축 2점 이상이고 중대 오류가 없어야 통과한다.

## 공통 판정

- 3: 해당 축의 핵심 정보와 제약이 충족된다. 2: 핵심은 유지하나 경미한 모호함·어색함·불필요한 설명이 있다. 1: 중요한 조건 누락·역할 혼동·논점 손실·형식 위반이 있다. 0: 없는 사실을 만들거나 요청 목적을 훼손한다.
- 없는 실적·수치·학위·직책·개인 기여·인과의 확정, 팀 행동의 오귀속, 제안을 승인·완료로 바꾸는 것은 중대 오류다. 합계로 상쇄하지 않는다.
- 글자 수는 공백·줄바꿈·제목·Markdown 목록 표시를 포함한다. 요청된 각 문안의 구획만 세고 구분용 해설은 제외한다. 구획이 불명확하면 판정 근거와 함께 기록한다.
- 자료를 모두 나열할 필요는 없다. 아래 필수 정보의 의미가 전달되면 표현·배열·문장 수의 차이를 인정한다. 모든 제한을 괄호나 각주로 반복할 필요도 없다.

## 경력자 지원 문서

1. UX 리서처에서 서비스기획 PM으로 이어지는 중심 역할을 보존한다. 자료 없는 개발 총괄·혁신 리더로 바꾸지 않는다.
2. 해솔시스템 선임과 서비스기획 PM 역할을 구별한다. 누리랩 기간과 3명 과제의 실제 우선순위·검수 일정 조율 경험, 초기 프리랜서 경력을 읽을 수 있다. 병행 기간을 합산한 총경력을 만들지 않는다.
3. 최신 학력 정정을 적용해 하나의 학사·복수전공을 표시한다. 오래된 초안의 복수 학사로 되돌리지 않는다.
4. 요약과 경력 근거가 이어지고 동일 소개의 반복이 줄었다. 경력 근거를 학력·추상적 역량 뒤로 계속 미루지 않는다.
5. 검색 과제의 본인 인터뷰·요구사항·검수와 협력사 구현, 실제 시범 사용 의견의 의미를 구분한다. 정성 피드백을 지우거나 전체 사용자의 생산성·정착 효과로 확대하지 않는다.
6. 비용 계산표 작성은 살리되 제안 채택·실제 절감액을 만들지 않는다. 검색 과제와 비용 과제의 기간을 합치지 않는다.
7. 자기소개서에서 사용 횟수의 필요성과 단독 판단의 한계, 업무 흐름을 배운 경험과 강조, 미래 방향이 이어진다. 지표 전체를 부정하거나 과거 성과로 바꾸지 않는다. 이력서를 그대로 반복한 문단이나 포괄적 미사여구로 대체하지 않는다.
8. 이력서 1,800자, 자기소개서 700자 이내의 바로 사용할 한국어 문안이다. 조사 메모나 편집 해설이 본문을 대신하지 않는다.

## 분기 업무 보고

1. 작성자의 오류 분류·재검수 기준과 개발팀의 구현, 운영팀의 시험 부서 배포를 정확히 귀속한다.
2. 계정 60개를 실제 사용 인원으로 바꾸지 않는다. 사용을 언급하면 주 1회 이상 사용 계정의 매주 평균 12개·4주 범위가 보존된다.
3. 문서 30건의 중앙값 12분→10분을 평균이나 전체 구성원의 효과로 바꾸지 않는다. 관찰 결과는 남기되 대조군 없는 결과를 기능 도입의 인과 효과로 확정하지 않는다.
4. 월 운영비 100만 원→120만 원 증가를 앞부분에서 전달한다. 비율을 제시하면 20%, 증감액은 20만 원이다. 계산표 작성은 실제 비용 절감으로 바꾸지 않는다.
5. 11월 다른 부서 확대는 운영팀의 미승인 제안이며 전사 확산 확정으로 바뀌지 않는다. 정해지지 않은 예산·일정·담당·승인을 만들지 않는다.
6. 핵심 실적과 남은 결정을 보여 주는 500자 이내의 완성 보고다. 작성 과정이나 확인 표지로 본문을 채우지 않는다.

## 기록 범위

별도 평가자는 입력·기준·출력만 보고 항목별 충족/부분/위반, 세 축 점수, 중대 오류, 글자 수와 짧은 대조 근거를 기록한다. 스킬 초안·작성자의 진단·기대 답안을 읽지 않는다. 첫 판정을 보존하고 수정 후에는 별도 결과를 남긴다. 이 점검은 합성 두 과제의 텍스트 적용 확인이며 실제 채용 성과, 한국어 전체 품질, 채점자 일치도, DOCX/PDF 조판 검증을 뜻하지 않는다.
