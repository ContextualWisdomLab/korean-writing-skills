# 온라인가나다 정기 보완의 첫 회차 검증

확인일: 2026-11-09. 기준 판본: `b9fac4c443311a390da22d837be95d47ad4a4626`.

## 변경 이유와 원문 대조

기존 장부의 N-Q13·N-Q14가 실제 게시물 제목과 달랐고, N-Q13에는 해당 답변에 없는 예문을 확인했다는 서술이 있었다. 원문 조사자와 편집자가 질문·답변을 각각 열어 대조하고 현재 장부에 정정 날짜·범위를 기록했다. 과거 평가 입력·출력은 다시 쓰지 않았다.

보조 용언의 조사 개입 설명은 명사형과 ‘직하다’의 기존 허용 설명과 함께 읽도록 좁혔다. N-Q15·N-Q16은 기존 원칙을 뒷받침하고 적용 조건을 구별하는 상담이며 새 어문 규정이 아니다. N-ON1의 게시판 공개 범위를 확인해 재열람 실패와 내용 정정을 구별하는 절차를 추가했다. 채택한 원문 URL·제목·날짜·한계는 [출처 장부](../../../skills/korean-editing/references/source-ledger.md), 반복 작업 절차는 [정기 보완 문서](../../../docs/online-ganada-maintenance.md)에 있다.

## 과제와 판본

- [입력](input.md)과 [사전 기준](criteria.md)을 지침 변경 전에 고정했다. 파일 해시는 [판본 기록](freeze.json)에 있다.
- 기존판과 보완판을 서로 다른 새 문맥의 실행자가 적용했다. 실행자는 입력과 해당 스킬 디렉터리만 읽었고, 평가 기준·다른 판본 출력·외부 검색은 제공받지 않았다.
- [기존판 출력](baseline-output.md)과 [보완판 출력](candidate-output.md)을 보존했다. 기존판의 로컬 스킬 링크 두 개는 공개 기록에서 기존판 커밋에 고정한 URL로 바꿨다. 문장은 그대로이며 원시 출력·공개 출력 해시를 각각 기록했다. 보완판 실행자에게는 로컬 경로를 출력하지 않도록 요청했다. 두 실행의 링크 형식 조건이 달랐으므로 형식 비교에는 쓰지 않는다.
- 두 판본의 교정문은 같았다. 기존판도 이 과제의 허용형과 불확실성을 보존했다. 기존판은 장부의 축약 제목을 반환하고 질문일·답변일이 없음을 밝혔으며, 보완판은 원문 제목과 서로 다른 날짜를 반환했다. 이는 출처 기록의 보완을 보여 주며 교정 성능 향상의 증거가 아니다.

## 독립 검토

스킬·출처·정기 절차·README·CHANGELOG·Gap 문서의 변경을 작성자와 다른 검토자가 독립적으로 읽었다. 평가 폴더나 실행 결과는 전달하지 않았다. 검토자는 상담 네 건의 제목·날짜·본문과 이용 안내를 직접 대조했으며, 수정이 필요한 결함을 찾지 못했다. 검토 시작·종료 시 파일 해시가 같았고 판본 기록에 해당 파일 해시를 보관했다.

한글 맞춤법 포털의 N-WEB URL은 이번 재열람에서 열리지 않았다. 검토자는 공식 상담에 실린 제47항 해설을 보조 대조했으나 포털 직접 재열람 성공으로 기록하지 않았다. 기존 N-WEB의 확인 날짜·범위를 유지했다.

입력·출력 두 개·사전 기준을 받은 별도 판정자는 공식 상담 세 건을 직접 대조했다. [독립 출력 검토](output-review.md)에 판정과 확인 한계를 그대로 보관했다. 두 교정문은 같은 수정 결과를 냈고 의미·허용 표기를 보존했다. 기존판의 제목은 공식 제목과 달랐으며, 보완판의 원문 제목·질문일·답변일은 일치했다.

판정자는 보완판의 설명 중 ‘확인·확정을 하지 않았다는 진술’이 미확정 상태를 확인 행위 자체의 부재로 넓힐 수 있다고 지적했다. 교정문 자체에는 이 문제가 없다. 최초 출력을 고치지 않고 [설명 정정 기록](followup.md)을 별도로 남겼으며, 같은 판정자가 정정 문단의 의미를 다시 대조해 문제가 해소되었다고 확인했다. 최초 출력의 이 결함을 지우거나 후속 편집을 독립 실행의 성과로 세지 않는다.

출력 판정자에게는 두 스킬 스냅샷과 실행 기록을 주지 않았으므로 제공 파일에 대한 충실성·열람 이력·외부 검색 준수 여부는 해당 검토에서 확인하지 못했다. 편집자가 고정 스냅샷을 별도로 대조한 결과, 기존 장부에는 축약 제목과 2026-11-02 확인일만 있었고 보완 장부에는 반환한 원문 제목·질문일·답변일·재열람일이 있었다. 이는 파일 기록에 대한 대조이며 독립 출력 판정자의 확인 범위에 포함시키지 않는다.

## 실행한 자동 검사

CPython 3.14.9, 잠긴 `markdown-it-py 4.2.0`·`PyYAML 6.0.3`으로 실행했다. 기존판 전체 테스트 152개가 19.040초, 보완판의 스킬 파일 변경 후 전체 테스트 152개가 19.378초에 통과했다. 스킬 구조·출처 연결·공개 파일 검사와 `git diff --check`도 통과했다. 배포용 ZIP 두 개도 만들고, 기록된 ZIP 해시와 파일별 해시를 실제 압축 내용과 대조했다. 이 시점의 패키지는 총 22개 항목이며 별도 PR의 조사 선택 변경은 포함하지 않는다. 평가 기록을 추가한 최종 후보와 원격 커밋의 검사 결과는 PR에 커밋을 명시해 기록한다. 검증 대상 스킬 파일 해시는 판본 기록에 고정했다.

소스 ID 존재 검사는 원문을 정확하게 읽었는지 증명하지 않는다. 이번 장부 정정도 자동 검사 통과와 별도로 원문 대조에서 발견했다. 한 합성 과제의 결과는 전체 규범 타당화, 실제 팀 사용, 일반적인 전후 성능 차이를 입증하지 않는다. GitHub의 실제 head·리뷰·병합 상태는 이 변경의 PR에서 확인한다.
