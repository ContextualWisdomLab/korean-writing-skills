# 교정·근거 조회 과제

> 제보 내용은 사실임직하지만 아직 확인된 사실은 아니다. 다른 담당자도 사실임 직하다는 의견만 냈다. 기록을 읽어는봤지만 사실로 확정하지 않았다. 관련 자료를 검토할만은하다.
