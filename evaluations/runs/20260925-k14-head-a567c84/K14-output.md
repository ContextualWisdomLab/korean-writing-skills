## 교정문

**방법**  이 연구는 저자의 2022년 석사학위논문에서 사용한 자료를 활용한다. 수면 시간과 과제 정확도의 관계를 위계적 회귀분석으로 검토한다. 자료는 2021년 10월 온라인 설문으로 수집되었다.

**결과**  수면 시간과 과제 정확도의 상관계수는 *r* = .42, *p* < .001이었다(*N* = 156). 평균 수면 시간은 *M* = 6.8시간(*SD* = 1.1)이었다. 표 1에 제시한 1단계 모형의 설명력은 *R*² = .18이었고, 95% 신뢰구간(CI)은 [.07, .29]였다. 표 1의 계수는 *b* = 0.31, *SE* = 0.08이다.

## 주요 변경과 근거

- 학위논문 쪽수 `31–33쪽`을 빼고 자료 출처와 2022년은 남겼다. 저자는 이전 논문의 쪽수를 본문 근거로 쓰지 않길 원한다. **근거: 저자 요구.**
- 연구 자체의 자료 활용과 분석 서술을 `활용한다`·`검토한다`로 썼다. **근거: 저자 요구와 편집 판단.**
- `r = 0.42`를 `*r* = .42`로, `R² = .18`의 기호를 `*R*²`로 표시했다. 1을 넘을 수 없는 통계량의 선행 0 생략은 APA 7판 Manual §6.36, 라틴 통계 기호 기울임은 APA 공식 *Number and Statistics Guide*(A-NUM)에 따른다. **근거: APA 규정·공식 안내.**
- `p = 0.000`을 영 확률로 해석하지 않고 `*p* < .001`로 표시했다. 원출력의 반올림 전 값을 확인해야 한다. **근거: APA 공식 안내 A-NUM과 편집 판단.**
- `M`·`SD`의 뜻풀이를 삭제하고, 처음 나온 `CI`는 `신뢰구간(CI)`으로 풀었다. 통계 기호를 따로 정의하지 않는 것은 Manual §6.44, CI 풀이 예는 A-NUM에 따른다. **근거: APA 규정·공식 안내.**
- `위의 표`를 `표 1`로 바꿨다. 본문에서 표를 번호로 가리키는 Manual §7.5에 따른다. **근거: APA 규정.**
- `표 1의 계수를 본문에 다시 나열하면`을 간결하게 고쳤다. 실제 표를 보지 못해 `*b* = 0.31`, `*SE* = 0.08`은 본문에 남겼다. **근거: 편집 판단.**

## 유지한 부분과 확인 요청

- 석사학위논문에서 사용한 자료라는 출처 사실, 2021년 10월 수집 시점, 온라인 설문, 위계적 회귀분석은 유지했다. 출처와 연구 사실을 지우거나 바꿀 근거가 없다. **근거: 저자 요구·편집 판단.**
- 수집 주체가 제시되지 않아 `수집되었다`를 유지했다. 실제로 끝난 자료 수집을 현재형으로 바꾸지 않았다. **근거: 의미 보존을 위한 편집 판단.**
- *N* = 156, *M* = 6.8시간, *SD* = 1.1, *R*² = .18, 신뢰구간 [.07, .29], *b* = 0.31, *SE* = 0.08의 수치와 귀속을 유지했다. 신뢰구간을 신용구간으로 바꾸거나 표준오차를 표준편차로 바꾸지 않았다. **근거: 저자 요구·편집 판단.**
- **저자 확인:** 반올림 전 *p* 값과 `95% CI`가 1단계 모형의 *R*²에 대응하는지 원 분석 출력으로 확인해 달라. 표 1에 *b*와 *SE*가 실제로 있고 본문과 일치하는지도 확인해 달라. 확인 전에는 수치를 삭제하거나 새 값을 만들지 않는다.
- **조건부 대안:** 표 1에 두 값이 정확히 실려 있다면 마지막 문장을 `회귀계수와 표준오차는 표 1에 제시하였다.`로 줄일 수 있다. 표와 본문에 통계를 중복하지 말라는 APA 공식 A-NUM 안내에 따른 제안이며, 현재 교정문에는 적용하지 않았다.
