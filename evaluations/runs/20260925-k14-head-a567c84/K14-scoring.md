## A·B·C 점검

| 지점 | 판정 근거 | 근거 종류 |
| --- | --- | --- |
| A `r = 0.42` | `*r* = .42`: 값 보존, 선행 0 생략 | APA 규정, Manual 6.36 |
| A `p = 0.000` | `*p* < .001`로 영 확률 표기를 피하고 반올림 전 값 확인 요청 | APA 규정 6.36·공식 안내 A-NUM |
| A `R² = .18` | `*R*² = .18`: 값과 선행 0 생략 유지 | APA 규정, Manual 6.36 |
| A `b`, `SE`, `M`, `SD` | 각각 0.31, 0.08, 6.8, 1.1 유지; 필요한 선행 0 보존 | APA 규정, Manual 6.36 |
| A `M`·`SD` 정의 | 정의 문구 삭제 | APA 규정, Manual 6.44 |
| A `95% CI` | `95% 신뢰구간(CI)`으로 첫 사용 풀이 | APA 공식 안내 A-NUM |
| A `위의 표와 같이` | `표 1에 제시한`으로 번호 지시 | APA 규정, Manual 7.5 |
| A 표·본문 중복 | 현재 본문에는 두 계수가 남았으나, 표 확인 후 줄이는 조건부 대안과 저자 확인 요청을 명시 | APA 공식 안내 A-NUM·편집 판단 |
| B 연구 결정·분석 | `활용한다`, `검토한다`로 현재형 자기 서술 | 저자 요구 |
| B 학위논문 쪽수·출처 | `31–33쪽` 삭제; 2022년 석사학위논문 자료라는 출처 유지 | 저자 요구·의미 보존 |
| B 수집 시제 | `2021년 10월 … 수집되었다` 유지 | 편집 판단 |
| B 근거 구분 | 현재형·쪽수 삭제를 저자 요구로 설명하며 APA 규정으로 주장하지 않음 | 저자 요구 |
| C 중대 오류 | 없는 결과·검정·수치·표본 특성·IRB·학술지 정보를 만들지 않았고, 상관을 인과로 바꾸지 않음 | 공통 평가 기준 |

APA 적용 범위는 제공된 `apa7-basis.md`의 근거 대응에 한정했다. 별도 APA 공식 원문을 열람해 조항을 재검증한 판정은 아니다.

## 세 축 점수와 근거

| 축 | 점수 | 원문–출력 대조 근거 |
| --- | ---: | --- |
| 의미 보존 | 3 | “위계적 회귀분석”, “2021년 10월 … 수집되었다”, `N = 156`, `R² = .18` 및 계수 값이 본문에 유지된다. `p = 0.000`의 반올림 불확실성은 확인 요청으로 분리했다. |
