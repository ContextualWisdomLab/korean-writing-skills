## 확인할 지점

| 지점 | 판정 근거 |
| --- | --- |
| 자료 출처 사실 | 본문에 “저자의 2021년 박사학위논문에서 분석한 설문 자료”가 남았다. 저자 확인은 서지정보와 재사용 고지 위치에 한정되며 본문의 출처 사실을 대체하지 않는다. |
| 학위논문 쪽수 | 58–60쪽은 본문에 없다. |
| 학위논문 경위 | “집단 비교만 하였으나”는 본문에 없고 변경 이유에서 삭제 이유로만 언급했다. |
| 현재형 자기 서술 | 현재 연구의 분석을 “잠재프로파일분석으로 응답 유형을 검토한다”로 썼다. |
| 끝난 절차의 시제 | 자료 수집은 “수집되었다”로 과거형을 유지했다. |
| 근거 종류 | 현재형과 경위 배제를 저자 요구로 설명했다. JARS-Quant는 자료 재사용·출처 점검에 관한 공식 안내로 한정해 소개했다. 그 세부 인용의 정확성은 허용된 원문 자료가 없어 검증하지 않았으며, 여기서 APA 규정 오류로 판정하지 않는다. |

## 세 축 점수와 근거

| 축 | 점수 | 원문과 출력의 짧은 대조 |
| --- | ---: | --- |
| 의미 보존 | 3 | 원문의 “2021년 박사학위논문에서 분석한 설문 자료”와 “잠재프로파일분석으로 응답 유형”, “2020년 5월 … 교사 412명 … 온라인”을 출력에 보존했다. 쪽수와 이전 분석 경위는 저자 요청대로 본문에서 뺐다. |
| 한국어 자연스러움 | 3 | 원문의 두 분석 설명을 “재분석하여 … 검토한다”로 이어 현재 연구의 방법을 한 흐름으로 읽게 했다. 자료 수집 문장은 어순이 자연스럽고 과거 시제가 맞는다. |
| 과잉 교정 억제 | 3 | 원문의 “수집되었다”와 “잠재프로파일분석”을 유지했다. 현재형·경위 배제는 저자 요구, 재사용 사실 표시는 편집 판단, JARS-Quant는 범위를 한정한 공식 안내로 구별했다. |

## 분석적 항목 판정

| 항목 | 판정 | 근거 |
| --- | --- | --- |
| M1 의미·증거 보존 | 충족 | 세 원문 문장의 출처·분석·수집 앵커가 대응표처럼 유지된다. |
| M2 행위자·생략 주어 | 충족 | 수집자를 새로 지정하지 않고 “수집되었다”를 유지했다. |
| D1 담화·구조 | 충족 | 분석 자료의 출처와 현재 분석을 먼저 제시하고 수집 사실을 이어 제시한다. |
| S1 문장·호응 | 충족 | “재분석하여 … 검토한다”의 주어와 서술어가 호응하며 수식 범위가 분명하다. |
| V1 능동·피동·사동 | 충족 | 행위자 불명의 자료 수집 피동을 유지해 책임을 추정하지 않았다. |
| T1 번역투·장르 | 충족 | 학술 방법 문단의 정보 밀도와 전문용어를 유지하면서 저자가 요청한 현재형 서술을 적용했다. |
| O1 과잉 교정 억제 | 충족 | 쪽수와 이전 분석 경위만 요청에 맞춰 본문에서 빼고, 필요 피동과 용어는 유지했다. |
| G1 표기 | 충족 | 교정문에 확인되는 맞춤법·띄어쓰기·문장 부호 오류가 없다. |
