허용된 파일은 아래 다섯 개뿐입니다. 이 목록 밖의 파일은 어떤 경로로도 열지 마세요. 파일은 Read 도구로만 여세요.

할 일:
1. 원문 문장마다 교정문 본문에 어떻게 대응되는지(보존·변경·삭제·확인 요청으로만 이동)를 표로 먼저 정리하세요.
2. criteria.md의 공통 절을 먼저 적용하세요. 실행자의 "열어본 파일" 목록을 criteria.md의 "실행자 허용 파일"과 한 줄씩 대조하고, 목록 밖 경로가 있으면 판정을 보류로 하세요.
3. 세 축(의미 보존, 한국어 자연스러움, 과잉 교정 억제)에 각각 0–3점을 주고 근거를 원문과 출력의 짧은 대조로 쓰세요.
4. analytic 루브릭 항목과 criteria.md {CASE} 절의 항목을 하나씩 확인하세요.
5. 루브릭 판정 규칙대로 통과·실패·보류를 정하세요. 합산·평균은 쓰지 마세요.
6. 점수 근거와 개선 권고를 섞지 말고 구분하세요. 한 항목을 두 곳에서 다르게 설명하지 마세요.
7. 접근 준수는 자기보고로만 알 수 있으므로 "자기보고상"이라고만 쓰세요.
