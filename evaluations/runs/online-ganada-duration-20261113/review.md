# 2026-11-13 시간 경과량 표기 — 별도 동결 교정 과제(미실행)

## 근거와 판정 경계

- 기존 [338340 「시간 단위를 나타내는 의존명사 띄어쓰기 질문」](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=201&pageIndex=1&qna_seq=338340): 질문 2026-11-11, 답변 2026-11-12, 기존 최초 열람 2026-11-13. 기존 N-Q20의 확인 기록과 원칙형·명시된 붙임 허용 설명을 보존한다.
- 후속 [338421 「[재질문] 시간 단위를 나타내는 의존명사 띄어쓰기 질문」](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=201&pageIndex=1&qna_seq=338421): 질문 2026-11-13, 최초 확인 2026-11-13. 이전 직접 확인에서 **후속 공식 답변·답변일이 표시되지 않았다**. 2026-11-13 이번 회차의 별도 재접속은 실패했으므로 답변 여부를 새로 확정하지 않고 기존 확인일을 덮어쓰지 않는다.
- 원칙/허용의 규범 범위는 N-WEB 제43항·해설, 개별 상담은 N-Q20으로 구별한다. 질문자의 의문은 국립국어원의 확정 답변이 아니다. `삼분` 자체를 모든 문맥에서 금지하거나 `삼분 동안`을 모든 경과량 문맥에서 확정 허용으로 평가하지 않는다.
- 기존 [숫자·단위 동결 과제](../online-ganada-20261113/review.md)의 **원 입력 1~5와 당시 기대 판정은 변경하지 않는다**. 다만 그 과제의 4번 ‘붙임 허용이 공식 상담으로 확정됐다’는 경과량 문맥의 **평가 근거로 미확정**이다. 이후 실제 교정 출력을 채점할 때 그 항목의 적합/부적합을 확정 점수에 포함하지 말고, 아래의 별도 경계 과제로 판단을 기록한다. 이것은 기존 첫 기록의 소급 삭제나 공식 정정이 아니다.

## 새 입력 및 사전 고정 기준 (모두 직접 쓴 가상 문장)

| 번호 | 신규 교정 입력 | 관찰할 판정 |
| --- | --- | --- |
| D1 | `작업자는 삼분 동안 기다렸다.` | `삼 분 동안`을 원칙형으로 **선택 제안**할 수 있다. `삼분`이 모든 경과량 문맥에서 명백한 오류라고 **확정하지 않는다**. 다른 문맥에 대한 붙임 허용을 N-Q20만으로 보편화하거나 시간·행위자를 고치지 않는다. |
| D2 | `담당자는 삼 분 동안 현장을 지켰다.` | 이미 원칙형으로 띄어 쓴 `삼 분`을 **유지**한다. 뒤의 `동안`, 주체, 행위를 바꾸지 않는다. 붙여 쓰도록 강제하거나 원칙형을 오답으로 표시하면 실패다. |

## 평가와 최종 검증의 구분

- 입력과 기준은 실제 출력 전에 고정했다. 작성자와 **다른** 평가자는 최종 적용 head, 최초 교정 출력, 근거를 어떻게 표현했는지, 각 항목의 의미·조건 보존 여부와 판단의 확정/유보 구별을 기록한다.
- D1에서 `삼 분` 선택 제안 없이 원문을 유지하면서 허용이 미확정이라고 유보하는 출력은 **그 이유와 근거를 기록**하고 별도 검토한다. 현 단계의 미확정 근거를 '이미 공식적으로 허용됨'이라고 단정하거나 근거 없이 확정 오류로 채점하면 실패다.
- 이 기록은 **입력·사전 기준**뿐이다. 교정 실행, 독립 판정, Python 3.14 locked 전체 검증, 일반 병합의 통과 증거가 아니다. 후속 공식 답변을 새로 직접 확인하면 이 동결 기준을 몰래 바꾸지 않고 새 출처 기록과 새로운 버전의 과제를 만든다.
