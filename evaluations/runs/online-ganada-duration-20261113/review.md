# 2026-11-13 시간 경과량 표기 — 별도 동결 교정 과제(미실행)

## 근거와 판정 경계

- 기존 [338340 「시간 단위를 나타내는 의존명사 띄어쓰기 질문」](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=201&pageIndex=1&qna_seq=338340): 질문 2026-11-11, 답변 2026-11-12, 기존 최초 열람 2026-11-13. 기존 N-Q20의 확인 기록과 원칙형·명시된 붙임 허용 설명을 보존한다.
- 후속 [338421 「[재질문] 시간 단위를 나타내는 의존명사 띄어쓰기 질문」](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=201&pageIndex=1&qna_seq=338421): 질문 2026-11-13, 최초 확인 2026-11-13. 이전 직접 확인에서 **후속 공식 답변·답변일이 표시되지 않았다**. 2026-11-13 이번 회차의 별도 재접속은 실패했으므로 답변 여부를 새로 확정하지 않고 기존 확인일을 덮어쓰지 않는다.
- 원칙/허용의 규범 범위는 N-WEB 제43항·해설, 개별 상담은 N-Q20으로 구별한다. 질문자의 의문은 국립국어원의 확정 답변이 아니다. `삼분` 자체를 모든 문맥에서 금지하거나 `삼분 동안`을 모든 경과량 문맥에서 확정 허용으로 평가하지 않는다.
- 기존 [숫자·단위 동결 과제](../online-ganada-20261113/review.md)의 **원 입력 1~5와 당시 기대 판정은 변경하지 않는다**. 다만 그 과제의 4번 ‘붙임 허용이 공식 상담으로 확정됐다’는 경과량 문맥의 **평가 근거로 미확정**이다. 이후 실제 교정 출력을 채점할 때 그 항목의 적합/부적합을 확정 점수에 포함하지 말고, 아래의 별도 경계 과제로 판단을 기록한다. 이것은 기존 첫 기록의 소급 삭제나 공식 정정이 아니다.

## 새 입력 및 사전 고정 기준 (모두 직접 쓴 가상 문장)

| 번호 | 신규 교정 입력 | 관찰할 판정 |
| --- | --- | --- |
| D1 | `작업자는 삼분 동안 기다렸다.` | `삼 분 동안`을 원칙형으로 **선택 제안**할 수 있다. `삼분`이 모든 경과량 문맥에서 명백한 오류라고 **확정하지 않는다**. 다른 문맥에 대한 붙임 허용을 N-Q20만으로 보편화하거나 시간·행위자를 고치지 않는다. |
| D2 | `담당자는 삼 분 동안 현장을 지켰다.` | 이미 원칙형으로 띄어 쓴 `삼 분`을 **유지**한다. 뒤의 `동안`, 주체, 행위를 바꾸지 않는다. 붙여 쓰도록 강제하거나 원칙형을 오답으로 표시하면 실패다. |

## 평가와 최종 검증의 구분

- 입력과 기준은 실제 출력 전에 고정했다. 작성자와 **다른** 평가자는 최종 적용 head, 최초 교정 출력, 근거를 어떻게 표현했는지, 각 항목의 의미·조건 보존 여부와 판단의 확정/유보 구별을 기록한다.
- D1에서 `삼 분` 선택 제안 없이 원문을 유지하면서 허용이 미확정이라고 유보하는 출력은 **그 이유와 근거를 기록**하고 별도 검토한다. 현 단계의 미확정 근거를 '이미 공식적으로 허용됨'이라고 단정하거나 근거 없이 확정 오류로 채점하면 실패다.
- 이 기록은 **입력·사전 기준**뿐이다. 교정 실행, 독립 판정, Python 3.14 locked 전체 검증, 일반 병합의 통과 증거가 아니다. 후속 공식 답변을 새로 직접 확인하면 이 동결 기준을 몰래 바꾸지 않고 새 출처 기록과 새로운 버전의 과제를 만든다.

## 2026-11-15 리뷰에 따른 D1 중복과 새로운 경과량 입력

[PR #31의 독립 제출 리뷰](https://github.com/ContextualWisdomLab/korean-writing-skills/pull/31)는 D1의 표현과 기대 판단이 실행자가 받는 지침의 예와 겹친다고 지적했다. 최초 동결된 D1과 당시 기준은 그대로 두지만 **D1을 독립 행동 평가 성공 증거로 사용하지 않는다**. 후속 상담 338421의 답변이 아직 확인되지 않았다는 판단도 유지한다.

[blind-inputs.md](../../scenarios/blind-inputs.md)에 추가한 **D3·D4**를 별도 새 문맥의 사전 평가 후보로 삼는다. D3의 사분 동안은 사 분 동안으로 원칙형을 **선택 제안**할 수 있으나 모든 경과량 붙임을 오류라고 확정하지 않는다. 시점·주체·관찰 행위를 보존한다. D4의 오 분 동안은 이미 원칙형이므로 그대로 유지하고 붙임을 강제하지 않는다. 미확정 문제의 근거 없는 단정과 의미 변경은 실패로 다루되, 원문을 유지하며 판단을 유보했다면 근거와 함께 별도 검토한다.

입력과 기준만 미리 기록했으며 실제 독립 실행·채점은 없다. 실행 전에 head와 전달 파일 SHA-256, 정확한 문장 중복 여부를 확인하고 결과와 별도로 보존한다.

## 2026-11-16 후속 답변에 따른 새 차수 D5/D6 (실행 전 고정)

[338421 후속 답변](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=201&pageIndex=1&qna_seq=338421)은 질문 **2026-11-13**, 실제 공식 답변 **2026-11-16**이다. 국립국어원은 시간의 길이·기간인 `삼 분/삼 년`을 띄는 것이 적절하며, 아라비아 숫자 `3분/3년`의 붙임은 허용한다고 설명했다. 2026-11-12 원답변의 한글 수 붙임 설명과 2026-11-13~15의 ‘후속 답변 미확인’은 당시의 기록으로 보존하되, **현재 경과량 판단으로 승계하지 않는다**. 새로운 규정 발표로 소개하지 않는다.

앞서 동결된 D1~D4와 [2026-11-13 평가의 입력 4](../online-ganada-20261113/review.md)를 소급 수정하거나 과거 기준으로 최신 평가 점수를 매기지 않는다. **새 차수**의 직접 쓴 가상 입력 D5/D6는 [blind-inputs.md](../../scenarios/blind-inputs.md)에 등록했고, 실행자에게 아래 기대 판정은 제공하지 않는다.

| 새 차수 | 독립 실행 전에 고정한 판단 | 지킬 조건과 실패 기준 |
| --- | --- | --- |
| D5 | 경과 시간의 한글 수 `일곱분을`을 `일곱 분을`로 띄도록 **제안** | 원문의 대기 행위·수량을 보존한다. 교정만 요구하는 입력이므로 `일곱 분을`로 고친 문장만 반환해도 수정 요건을 충족한다. 설명을 덧붙인 경우에만 제43항 해설과 338421의 시간 길이 구별을 적용한 편집 판단임을 정확히 설명했는지 평가한다. 이 예 자체를 기관이 직접 판정한 표현이라고 주장하면 실패다. |
| D6 | 아라비아 숫자 `7분 동안`은 붙임 허용의 범위이므로 **유지** | `7분`을 확정 오류로 취급하거나 7을 다른 값으로 바꾸면 실패다. 원문 행위자·기록 행위를 보존한다. |

현재는 **사전 입력과 기준만 확정했고 독립 실행·채점은 하지 않았다**. 실행 전에 정확한 최종 head, 전달 파일 목록 및 각 파일 SHA-256, 기존 지침 예와의 정답 중복 여부를 기록하고, 작성자와 다른 평가자가 첫 출력의 의미 보존·과잉 교정 여부를 판정한다. 이전 freeze.json이나 과거 성공 점수를 최신 차수에 승계하지 않는다.
