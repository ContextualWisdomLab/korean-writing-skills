# 표준 발음과 방언 판정 분리 진단 설계 (미실행)

- **근거 상담**: N-Q40, [국립국어원 온라인가나다 338872 「[재질문] 콩나물 밥과 양념장의 발음이 궁금해요」](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=201&pageIndex=1&qna_seq=338872). 질문 2026-11-23, 화면 등록 2026-11-25, 답변 2026-11-24. 답변 아래 후속 질문의 날짜·답변은 미표시.
- **범위**: `evaluations/scenarios/blind-inputs.md`의 N-20261125-dialect(DQ1–DQ4). 입력과 이 기준은 별도 파일에 고정한다. 실행 전 최종 head, 전달 스킬·참고 파일, 시나리오, 기준의 SHA-256을 기록한다.
- **근거 한계**: 답변이 전한 표준국어대사전 발음은 `[콩나물밥]`, `[양념장]`이다. 표준국어대사전 상세 항목과 우리말샘 검색 결과는 이번 실행에서 독립 열람하지 못했다. 이 과제는 상담 답변의 범위를 보존하는지 점검하며 사전 원문을 직접 확인한 과제가 아니다.

## 사전 판정 기준

| 입력 | 기대 행동 | 실패 조건 |
| --- | --- | --- |
| DQ1 | 표준 발음 안내를 `[콩나물밥]`, `[양념장]`으로 바로잡음 | 답변이 제시한 표준 발음을 바꾸거나, 별도 근거 없이 다른 발음을 표준형으로 확정 |
| DQ2 | 실제 발화 인용 `[콩나물빱]`을 보존하고 표준 발음으로 몰래 치환하지 않음 | 인용을 표준형으로 바꾸거나 근거 없이 방언이라고 단정 |
| DQ3 | 우리말샘 미등재만으로 비방언 결론을 내리지 않고 별도 근거 확인 또는 판단 유보를 제안 | 미등재를 방언이 아니라는 증거로 취급 |
| DQ4 | 지역·자료가 제시되지 않은 방언 주장을 확인 필요로 표시 | 지역·방언 사실이나 출처를 만들어 확정 |

## 동결 식별자

- 시나리오 블록 SHA-256: `b9f957bc6f8003e9d152343d633d32752226ed033c278a6549f77894b96d85b1`
- 판정표 SHA-256: `cb3e9a1a9282437323f020067eef53c508cdc0780adbf44a62b417e42b319526`
- 해시는 위 입력 블록과 판정표를 대상으로 하며, 실제 실행 전에 최종 head·전달 파일의 해시를 별도로 다시 기록한다.

## 실행 계약과 한계

- 실행자는 사례마다 새 context에서 요청·입력·최종 스킬 및 필요한 참고 파일만 받는다. 이 기준과 기대 행동은 제공하지 않는다. 별도 채점자는 원문과 실제 출력만 대조한다.
- 이 과제의 핵심 판단은 `scope-routing.md`와 N-Q40에 노출되므로 **진단용**이다. 독립 성공 점수나 일반 성능 향상 증거로 사용하지 않는다.
- **현재 상태: 설계만 완료. 독립 실행 0건, 채점 0건, 통과 판정 없음.** 독립 실행·채점과 Python 3.14 전체 검사는 최신 head에서 별도로 수행해야 한다.
