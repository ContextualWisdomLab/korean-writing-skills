# 온라인가나다 ‘높이 뛰다’ 교정 과제 H1–H2 — 2026-11-17 설계·동결

## 범위와 근거

- 공식 상담: [338487 「높이뛰다」](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=201&pageIndex=1&qna_seq=338487&searchCondition=&searchKeyword=), 2026-11-14 질문, 2026-11-16 답변, **답변 최초 직접 확인 2026-11-17**. 출처 장부 N-Q23과 교정 지침의 일반 동작 표현에 한정한다.
- 이번 기록은 **평가 설계와 입력·사전 기준의 동결**이다. 스킬 실행 출력, 독립 채점, 테스트 통과, 이전판 대비 효과에 대한 증거가 **없다**.
- 입력의 핵심 띄어쓰기 판단이 이미 전달할 `orthography-decisions.md`와 `source-ledger.md`에 노출되므로 **H1·H2는 진단용 관찰**로만 사용하고, 독립적인 성공 점수·전체 통과 기준으로 세지 않는다. 새 독립 평가를 수행하려면 전달 자료와 과제 입력 사이의 핵심 교정 경계·판정 중복을 별도로 점검하고, 독립 설계·실행·채점 및 판본·파일 해시·원시 출력·판정 결과를 남긴다.

## 동결 입력·판정 기준

| ID | 동결 입력(직접 쓴 가상 문장) | 사전 기대 행동·채점 경계 |
| --- | --- | --- |
| H1 | `훈련을 마치고 참가자는 매트 앞에서 높이뛰었다.` | 일반 동작의 `높이뛰었다`를 `높이 뛰었다`로 띄우고, 행위자·행동·시점은 보존한다. 다른 내용은 보태지 않는다. |
| H2 | `훈련을 마치고 참가자는 매트 앞에서 높이 뛰었다.` | 이미 바른 `높이 뛰었다`를 유지하며 조사·시점·행위자를 바꾸지 않는다. |

## 시나리오 등록·실행 전 무결성 조건

- H1·H2는 [등록 시나리오](../../scenarios/blind-inputs.md#n-20261117-high-jump--일반-동작-높이-뛰다-진단-입력)의 `N-20261117-high-jump` 절에도 같은 문장으로 등록했다(시나리오 추가 커밋 `35a8c1e6ad72a303ddc64d9267c550070495fc85`). 이 파일의 기대 행동·채점 기준은 실행자에게 제공하지 않는다.
- **아직 실행하지 않았다.** 실제 진단 실행 **전** 시나리오와 전달할 스킬·근거 파일의 SHA-256, 최종 커밋 SHA, 별도 실행자·채점자에게 제공할 파일 목록을 먼저 고정해 기록한다. 진단 사례는 전달 자료의 핵심 띄어쓰기 판단과 중복될 수 있으므로 실행 결과가 나오더라도 독립 성공 점수로 계산하지 않는다.
