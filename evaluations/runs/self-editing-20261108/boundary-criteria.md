# 다섯 문장 경계 과제의 관찰 기준

실행 전에 기준을 정했다. 입력은 두 문단, 다섯 문장으로 구성되어 있으며 새 합성 사례다. 정답 문장은 정하지 않는다.

1. 입력 문단의 순서와 내용을 보존한다. 첫 문단은 배포 가능 여부의 추후 검토와 전체 결과 미확인, 둘째 문단은 민서가 수행한 관련 테스트의 결과다. 테스트 결과를 앞세우기 위해 문단을 바꾸지 않는다.
2. 내일의 검토를 완료·승인·배포 약속으로 바꾸지 않는다. 전체 테스트 결과를 확인하지 못했다는 사실에서 전체 실행의 존재·부재·완료·성공을 추론하지 않는다.
3. 담당자와 민서의 역할, 관련 테스트 18건 중 17건 통과·1건 실행 중이라는 범위를 보존한다. 새 담당자·원인·시한을 추가하지 않는다.
4. 뜻이 분명한 군더더기나 호응은 자연스럽게 고치며, 불필요한 확인 질문으로 교정을 미루지 않는다. 수정본만 제시한다.

한 사례의 관찰 결과로 일반 성능이나 다른 문장 수·장르의 품질을 주장하지 않는다. 출력만으로 내부 절차를 실제 생략했는지 입증할 수 없으므로, 문단 순서와 의미 보존을 관찰한다.
