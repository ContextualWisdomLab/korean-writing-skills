# 독립 내용 검토와 수정

## 범위

기준 커밋은 `f00ab66634d6b0d1496b7ff4d724e0dc0168927b`다. 새 문맥의 검토자가 한국어 스킬 진입점, 이력서·보고서·문장 지침, 새 출처 장부 항목, 테스트 탐색 변경, README·사용 안내를 읽었다. 평가 입력·기준·출력과 작성자의 기대 답안은 읽지 않았다. Gap 기준선의 후속 13줄은 이 검토 범위에 포함하지 않았다.

검토자는 출처 원문을 다시 열거나 자동 검사를 독립 실행하지 않았다. 출처 원문의 직접 확인은 작성 담당자가 수행했으며, 이 검토는 장부에 기록된 근거·열람 범위와 안내 문장의 부합성에 한정된다. 공식 GitHub 승인과 구별한다.

## 발견과 조치

| 수준 | 발견 | 조치 |
| --- | --- | --- |
| P2 | 이력서 합성 원자료는 인터뷰와 분류 기준 작성을 각각 제시했으나 예문은 `인터뷰를 바탕으로`라는 근거 관계를 추가했다. | `현업 15명을 인터뷰하고 문의 분류 기준 30개를 정리했으며, 3명 팀의 검수 회의 2회를 조율했습니다.`로 수정했다. 원자료를 사후에 바꾸어 관계를 정당화하지 않았다. |
| 선택적 표현 개선 | `개인 기여율이나 인과관계가 없으면`은 관계의 부재와 확인의 부재를 혼동할 수 있다. | `개인 기여율이나 인과관계가 확인되지 않으면`으로 명확히 했다. |

그 밖의 출처 해석·한국어·패키지 범위·함수형 테스트 수집 변경에서는 차단할 문제를 발견하지 않았다는 검토 결과를 받았다. 작성 담당자가 두 수정의 적용과 새 파일 해시를 확인했다. 같은 독립 검토자가 이력서 파일의 두 변경을 다시 읽고, 수량을 보존하면서 두 지적을 해결했다고 확인했다. 후속 검토도 평가 자료는 읽지 않았다.

## 판본 보존

이력서 지침의 SHA-256은 다음과 같다.

```text
검토판: c7bcde870ac40fa62747b13d47c18ddfec9ba7a9bb40bbc8148c81dc2849fd33
수정판: e6e9748245ad728b0b9001df43bf96e2f46e47b3505bee7d09e9ba634ec68dd8
```

나머지 스킬 파일의 해시는 `comparison-freeze.json`과 `comparison-v2-freeze.json`에 기록한다. 이미 시작한 수정 전 이력서 실행은 스냅샷을 바꾸지 않고 끝낸 뒤 `candidate-v1-resume.md`로 보존했다. 최종 비교에는 수정판으로 새로 실행한 이력서 출력을 사용한다.

## GitHub 검토 후 보고서 예문 보완

[PR #25의 자동 검토](https://github.com/ContextualWisdomLab/korean-writing-skills/pull/25#discussion_r4493287368)는 보고서 예문이 예산 승인만으로 파일럿을 진행할 수 있다고 연결한 점을 지적했다. 원자료에는 예산·요청 기한·담당만 있으므로 이 지적을 수용했다. 예문을 `7월 파일럿 예산 300만 원의 승인을 6월 30일까지 요청합니다. 파일럿은 운영팀이 담당합니다.`로 바꾸고, 확인된 실행 조건만 연결하도록 명시했다.

독립 검토자가 이 파일만 다시 읽고 주어진 사실을 보존하면서 문제가 해결되었다고 확인했다. 보고서 지침의 최종 SHA-256은 `e0cf80d90b1c98f3d83e578f08bea85cede01509e35ef5947cab1a41201a8276`이다. 수정 내용은 원격 커밋 `621298d6c1cb06b14b410ce2e39bceae84ed4a8d`에서도 확인한 뒤 해당 스레드를 해결 처리했다.

함께 제시된 docstring coverage 경고에 따라 이번 diff에서 추가·수정한 테스트 함수 3개의 목적을 docstring으로 기록했다. AST에서 세 함수 모두 docstring이 있음을 확인했으며, 이 확인을 CodeRabbit의 재검토 결과로 표시하지 않는다.

보고서 참고 파일만 바뀐 v3는 `regression-v3-freeze.json`으로 동결하고 동일 입력·동일 기준으로 보고서만 새 실행·별도 독립 채점한다. v2의 여섯 출력과 최초 채점 결과는 보존한다. 이력서·문장 실행자가 읽은 파일들은 v2와 v3에서 동일하다.
