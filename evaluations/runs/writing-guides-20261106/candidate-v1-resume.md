## 상단 요약

현업 인터뷰와 검색 성과 평가 경험을 갖춘 데이터 분석 담당자입니다. 내부 검색 프로젝트에서 평가셋 구성과 검색 성공률 지표 정의를 맡고, 개발팀과 현업팀의 평가 기준 협의를 진행했습니다.

## 핵심 경험

**내부 검색 프로젝트 | 데이터 분석 담당 | 2024년 4월~2025년 3월 | 4명 팀**

- **현업 인터뷰:** 현업 담당자 8명을 인터뷰하며 내부 검색 프로젝트의 현업 의견 수집을 담당했습니다.
- **성과 평가:** 평가셋 120건을 구성하고 검색 성공률 지표를 정의했습니다. 동일한 평가셋과 평가 기준으로 측정한 팀의 검색 성공률은 62%에서 74%로 높아졌습니다. 통제집단 비교와 개인 기여율 산정은 수행하지 않았습니다.
- **부서 간 조율:** 개발팀과 현업팀의 평가 기준 협의를 진행했습니다. 현재 검색 서비스는 1개 부서에서 사용 중이며, 전사 배포 전 단계입니다.
