# 익명 한국어 작성 출력 평가

## 서론: 범위와 판정 방법

`blind-packet`의 `criteria.md`, `three-axis.md`, `analytic-korean-editing.md`, 세 입력과 여섯 익명 출력만 읽었다. 스킬 초안, 저장소, 버전 매핑, 다른 실행 출력과 외부 문헌은 열람하지 않았다. 사전에 고정된 기준을 적용했으며 새로운 요구나 정답 문구를 추가하지 않았다. 아래 점수는 최초 확정 판정이다.

세 축은 **의미 보존 / 자연스러움 / 작성 범위·형식 준수** 순서다. 각 축이 2점 이상이고 중대 오류가 없을 때 통과하며, 점수 평균으로 결함을 상쇄하지 않는다. 파일별 확인 사항의 상태와 근거는 `blind-grading.json`에 함께 기록했다.

### 이력서

**A와 B 모두 네 확인 사항을 충족한다.** 상단 요약 2문장과 핵심 경험 3개가 현업 요구 파악, 성과 평가, 부서 간 조율 경험을 전달한다. `resume-input.md`의 인터뷰 8명, 평가셋 120건, 지표 정의와 기준 협의를 개인 업무로 쓰고, 62%→74%·12%p를 동일 평가셋·기준에서 얻은 팀 결과로 구분한다. 기간과 4인 팀, 통제집단 부재, 개인 기여율 미산출, 1개 부서 사용·전사 배포 전이라는 범위도 유지한다.

두 출력 모두 모델 개발·총괄이나 경제적 효과를 만들지 않는다. 문장과 항목 구조가 채용 문안으로 기능하며, 요약과 경험 항목에 같은 역량이 등장하는 것은 용도에 맞는 반복이다. **쌍 선호는 동률**이다.

### 의사결정 보고서

**A와 B 모두 여섯 확인 사항을 충족한다.** 첫 본문 문단에서 B의 추가 검증 후 도입 권고와 비용 영향을 알 수 있다. 현행 유지·A 도입·B 추가 검증 후 도입을 비교하고, 추가 시험 승인과 B 도입비 검토를 요청한다. 월 운영비와 일회성 도입비를 구분하며 동일 사용량·서비스 범위·세금 기준을 명시한다. A의 미시험 기대 효과, B의 2일·300건 파일럿 관찰, 장기·성수기 미검증도 보존한다.

| 검산 항목 | 계산과 결과 | 출력 대조 |
| --- | --- | --- |
| 월 운영비 상한 | 900×1.15=1,035만원 | B 정확; A는 선택적 파생 수치 생략 |
| A 증가액 | 1,080−900=180; 1,170−900=270만원 | 둘 다 정확 |
| A 증가율 | 180/900×100=20%; 270/900×100=30% | 둘 다 정확, 15% 초과 |
| B 증가액·비율 | 990−900=90만원; 90/900×100=10% | 둘 다 정확, 15% 이내 |
| 일회성 도입비 | A 1,800만원; B 700만원 | 둘 다 입력과 일치 |

분량은 **A 563자, B 566자**다. 전체 문자열의 CRLF/CR을 LF로 바꾼 뒤 유니코드 코드 포인트를 셌다. 공백·줄바꿈·문장 부호·마크다운과 마지막 LF를 포함했으며 앞뒤 공백 제거와 추가 정규화는 하지 않았다. 둘 다 700자 이내다. 제공되지 않은 현행 과거 도입비를 0원으로 만들거나 절감액·ROI를 주장한 출력은 없다.

A의 “도입 여부를 결정합니다”는 권고·다음 조치 문맥의 후속 방침으로 읽히며 완료된 시험이나 승인을 주장하지 않는다. B는 “승인되면”과 “제안합니다”로 조건과 제안 상태를 더 명확히 한다. **쌍 선호는 B**지만, 특정 단어의 부재를 A의 오류로 처리하지 않았다.

### 지출 앱 문구

**A는 세 확인 사항을 모두 충족한다.** 세 안 각각이 제목·설명 1문장이고, 질문·확인 권유·연결 권유로 접근을 달리한다. 각 쌍 안에서 금융계좌 연결, 연결 계좌의 지난주 지출, 월요일 반복 제공이 전달된다. 두 번째 안은 제목의 “월요일엔 지난주”와 설명의 연결 조건을 함께 읽어 충족으로 판단했다.

**B는 형식·용도와 효과·표현을 충족하지만 기능·조건을 위반한다.** 첫째와 셋째 안은 기간·대상·주기를 전달한다. 둘째 안의 “이번 월요일엔”과 “한 주 동안…매주 월요일”은 집계 대상이 지난주인지 분명히 하지 않는다. 독립 사용해야 하는 문구이므로 다른 안의 “지난주”로 보충할 수 없다. 필수 집계 기간의 누락·모호함을 의미 보존 1점으로 반영했다. 문장 자체는 자연스럽고 형식도 충족하므로 나머지 축은 3점이다.

“어디에 얼마”는 지출 내역 확인이라는 통상적 독해도 가능하므로 별도 분석 기능 날조로 단정하지 않았다. 중대 오류는 없으며, 실패 근거는 두 번째 안의 기간 조건이다. **쌍 선호는 A**다.

## 결론: 해석 한계

여섯 출력 중 통과 5개, 실패 1개, 보류 0개다. 이는 가상 사례 세 쌍의 문안과 고정 기준을 대조한 단일 평가자의 텍스트 점검이다. 버전의 모집단 성능, 통계적 우열, 평가 타당도나 채점자 신뢰도를 검증한 결과로 일반화할 수 없다.
