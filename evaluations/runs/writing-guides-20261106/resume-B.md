현업 인터뷰와 검색 품질 평가, 부서 간 평가 기준 조율 경험을 갖춘 데이터 분석가입니다. 2024년 4월~2025년 3월 4인 내부 검색 프로젝트에서 현업 담당자 인터뷰, 평가셋 구성, 검색 성공률 지표 정의와 개발팀·현업팀 간 협의를 담당했습니다.

### 핵심 경험

- **현업 인터뷰 수행:** 내부 검색 프로젝트에서 현업 담당자 8명을 인터뷰했습니다.
- **검색 성과 평가 설계:** 평가셋 120건을 구성하고 검색 성공률 지표를 정의했습니다. 동일한 평가셋과 평가 기준에서 팀의 검색 성공률은 62%에서 74%로 12%p 상승했습니다. 통제집단 없이 측정한 팀 결과이며, 개인 기여율은 산출하지 않았습니다.
- **부서 간 평가 기준 조율:** 개발팀과 현업팀의 평가 기준 협의를 진행했습니다. 내부 검색 서비스는 현재 1개 부서에서 사용 중이며, 전사 배포 전 단계입니다.
