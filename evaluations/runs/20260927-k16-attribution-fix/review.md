# K16 인용 귀속 보강 후 독립 재평가

[앞선 실패](../20260927-k16-scope-recheck/review.md)는 Muthén (2002)을 다른 주장 뒤로 옮겨 출처 귀속을 바꾼 사례다. 두 스킬에 문장 분리·순서 변경 뒤에도 인용이 뒷받침하는 주장을 보존하는 절차를 추가했다. 수정 스킬 커밋 `62a7025`의 입력·기준·루브릭·스킬 사본 해시는 실행 전 [freeze.json](freeze.json)에 고정해 커밋했다.

별도 실행자는 기준과 과거 출력을 보지 않고 K16을 1회 교정했다. 별도 채점자는 입력·출력·K16 기준·두 루브릭만 받아 원문 각 주장과 교정문을 대조했다. [독립 채점](K16-scoring.md)은 의미 보존 3/3, 한국어 자연스러움 2/3, 과잉 교정 억제 3/3으로 **통과**했다. Muthén 인용은 방법 2.3절의 절차 요약 뒤에 남았다. 다만 제출되지 않는 내부 노트 참조를 교정문 본문에도 남겨 자연스러움은 2점이다. 실제 제출 전 저자가 원고의 설명을 확인하고 응답서 참조를 고쳐야 한다.

[manifest.json](manifest.json)은 원본·공개본 해시를 분리한다. 공개본에서는 격리 절대경로만 역할 경로로 치환했고, 원본은 저장소 밖에 보존했다. 접근 준수는 실행자의 파일 목록에 따른 **자기보고상** 판단이다. 한 번의 통과는 이 사례에서 관찰된 오류가 재현되지 않았다는 뜻이며, 일반적 효과·타당화나 첫 실패의 소급 취소를 뜻하지 않는다.

담당: 스킬 작성 리드. 다음 조치: 정확한 원격 head의 필수 CI·보안·비작성자 검토를 확인한다. 완료 기준: 원격 커밋, 검사 결과와 검토 증거를 확인한다. 의존성: GitHub Actions 실행 대기열.
