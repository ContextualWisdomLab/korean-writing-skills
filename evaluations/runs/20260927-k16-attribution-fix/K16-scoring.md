# K16 독립 채점

## 원문 주장과 교정문 대응

| 원문 주장·정보 | 교정문 본문 대응 | 판정 |
| --- | --- | --- |
| 심사위원 2-3에 대한 응답 | 같은 표제 | 유지 |
| 측정 동일성 절차는 내부 분석 노트 3.2절에 자세히 정리 | 같은 문서·절을 유지 | 의미는 유지했으나 제출되지 않는 문서를 교정문 본문에서도 계속 참조함 |
| 모형 비교에 Vuong (1989)의 검정 사용 | 같은 검정·인용 | 유지. 원고 참고문헌에서 풀리지 않는 문제를 별도로 지적함 |
| 결과는 원고 표 2에 보고 | 같은 표 | 유지 |
| 절차는 원고 방법 2.3절에 요약, 뒤에 (Muthén, 2002) | 같은 위치·인용, `절차는`으로 문장 호응 정리 | 유지. 인용이 어느 주장에 귀속되는지는 여전히 모호하여 확인 사항으로 남김 |
| 종속변수 `수면 문제(Y)`의 집단 간 동일성 유지 | `수면 곤란 수준(Y)`의 동일성 유지 | 제공된 원고 정식 변수명에 맞춤. 결과 자체는 유지 |
| 선별 목적으로만 쓴 불면 선별 질문지는 검토에서 제외 | `사용한`으로 바꾸고 제외 범위 유지 | 다른 도구를 Y에 합치지 않음 |

## 사전 기준 확인

| 확인 지점 | 판정과 근거 |
| --- | --- |
| 제출하지 않는 문서 참조 | **부분 충족.** 제출 파일 밖의 내부 분석 노트를 지적했다. 원고 방법 2.3절의 충분성을 점검하고 부족하면 설명을 보강해 응답서 참조를 수정하라고 했다. 다만 내부 노트를 제출할지 응답서를 자기완결로 고칠지라는 저자 선택지를 명시하지 않았고, 제시한 교정문에는 접근할 수 없는 노트 참조가 그대로 남았다. |
| 참고문헌에서 풀리지 않는 인용 | **충족.** Vuong (1989)이 원고 참고문헌에 없음을 지적하고 실제 검정·출처를 확인해 인용과 참고문헌을 일치시키라고 했다. 서지를 만들거나 인용을 삭제하지 않았다. |
| 풀리는 참조 | **충족.** 원고 표 2, 방법 2.3절, Muthén (2002)을 유지했다. Muthén 인용의 근거 귀속은 확정하지 않고 원고와 출처 확인 사항으로 남겼다. |
| 척도 정식 명칭 | **충족.** `수면 문제(Y)`를 제공된 `수면 곤란 수준(Y)`으로 맞췄다. |
| 다른 도구 이름 | **충족.** 불면 선별 질문지의 이름과 별도 역할을 유지했다. |
| 문장 교정 | **충족.** 첫 문장을 나누고 목적어를 명확히 했다. 새로운 결과·검정은 만들지 않았다. |
| 숫자·위치 앵커 | **충족.** 2-3, 3.2절, 표 2, 2.3절, 1989, 2002, Y를 바꾸지 않았다. |

## 분석적 항목

| 항목 | 판정과 수정 이유 |
| --- | --- |
| M1 의미·증거 보존 | **양호.** 표의 명제·인용·변수 대응을 유지했다. 다만 제출되지 않는 노트 참조를 교정문에도 남겨 독자가 확인할 수 없는 근거 위치가 본문에 지속된다. |
| M2 행위자·생략 주어 | **양호.** 검정 사용·결과 보고의 행위자를 새로 만들지 않았다. |
| D1 담화·구조 | **보통.** 검정 문장을 분리해 읽기 쉽다. 내부 노트와 원고 방법 절의 역할 관계는 제출 문서만 읽는 심사위원에게 불명확하다. |
| S1 문장·호응 | **양호.** `절차는 방법 2.3절에 요약`으로 호응이 분명해졌다. |
| V1 능동·피동·사동 | **양호.** 필요한 피동을 일괄 변경하지 않았다. |
| T1 번역투·장르 | **양호.** 학술 심사 응답의 어조를 유지했다. |
| O1 과잉 교정 억제 | **양호.** 불확실한 인용 귀속과 결과를 임의로 바꾸지 않았고, 수정 이유를 편집 판단·저자 요구 등으로 나눴다. 다만 `쓴`→`사용한`은 필수 교정은 아니다. |
| G1 표기 | **양호.** 확인 가능한 맞춤법·띄어쓰기 오류는 보이지 않는다. |

## 점수와 판정

| 축 | 점수 | 근거 |
| --- | ---: | --- |
| 의미 보존 | **3/3** | 주장, 범위, 검정, 인용, 숫자, 변수 대응을 보존하고 자료 부족을 명시했다. |
| 한국어 자연스러움 | **2/3** | 문장 흐름은 개선됐으나 접근할 수 없는 내부 노트 참조가 교정문에 남아 심사 응답의 독립적 이해를 방해한다. |
| 과잉 교정 억제 | **3/3** | 불확실한 귀속·결과를 지어내지 않았고 필요한 명칭만 맞췄다. |

**중대 오류:** 없음. **최종 판정: 통과.** 두 제출 전 문제를 모두 지적했고 세 축 모두 내부 경계인 2점 이상이다. 교정문을 실제 제출할 때는 내부 노트 참조를 원고에서 검증 가능한 설명으로 바꾸거나 해당 문서의 제출 여부를 저자와 결정해야 한다.

**접근 범위:** 출력에 적힌 실제 열어본 파일 목록만을 근거로 하면, **자기보고상** 허용된 입력·스킬 계열 파일만 열었다. 기록의 완전성이나 실제 접근 내역은 검증하지 않았다.
