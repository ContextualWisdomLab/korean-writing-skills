## 자동 검사

- 새 정적 지침 계약 4건은 구현 전에 실패하고 구현 후 통과했다. 문구 계약이며 실제 작성 행동을 자동 입증하지 않는다.
- 최종 전체 unittest 112건, skill structure, source traceability, public hygiene, preview 패키징(두 ZIP과 manifest), skill-creator 기본 검증, `git diff --check` 통과.
- 실행 환경: Python 3.12.14, PyYAML 6.0.3, markdown-it-py 4.2.0, mdurl 0.1.2. 의존성 버전은 `uv.lock`과 대조했다. 읽기 전용 기본 홈 대신 쓰기 가능한 임시 홈에서 패키징 테스트를 실행했다.
- Python 3.14는 설치되어 있지 않아 `CLAUDE.md`의 3.14 환경 검증은 실행하지 못했다. 오프라인 `uv sync --locked`는 필요한 캐시가 없어 완료하지 못했고, 이미 설치된 동일 버전 의존성으로 검증했다. hosted CI는 이 기록으로 대체하지 않는다.

## 독립 검토와 후속 회귀

서로 다른 검토자가 두 가지 충돌을 지적했다.

1. 기준값이 0이라는 이유만으로 `신규 발생 사실`을 쓰면 0→0과 0→예상 비용의 의미를 바꿀 수 있었다. 전후 값·차이를 쓰고, 변동 없음·실제·예상을 구별하도록 고쳤다.
2. 음수 기준값과 비교 범위 불일치를 한 분기로 묶어, 환산 근거가 없는 월/연 값도 차이를 계산할 여지가 있었다. 둘을 분리해 비교 기준이 다르고 환산 근거가 없으면 차이도 계산하지 않도록 고쳤다.

각 지적은 새 정적 계약의 RED→GREEN으로 확인했다. 추가 합성 3사례는 사례마다 새 실행자에게 스킬·관련 references와 입력만 제공했다. 예상 답·이슈·diff·테스트는 제공하지 않았다. 실행 산출물과 입력은 [후속 회귀](focused-regression.md)에 보존했다. 결과 판정은 구현 담당자이며 정식 별도 블라인드 채점으로 확대하지 않는다.

- ZERO: 지난해·올해 실제 비용 0원 → 같은 0원이며 변동 없음을 보존. 0 기준 수정판 `guidance-zero-baseline.md` 사용.
- PROJECTED: 승인 미정, 승인 시 0→예상 연 500만 원 → 조건·미정·예상을 보존하고 비율 미산출. 같은 0 기준 수정판 사용.
- UNMATCHED: 대표성 불명인 4월 비용 100만 원과 내년 연 견적 1,500만 원 → 각각 제시하고 차이·비율·증가 방향 미산출. 최종 보고서 지침 사용.

최종 지침은 두 지적 해결 후 별도 검토자가 재확인했으며 다른 중대한 지적이 없었다. 최종 전체 unittest 112건, 구조·출처·공개 위생·diff 검사도 그 검토자가 직접 재실행해 통과했다. 자동 검사와 합성 회귀는 실제 업무 효과나 정식 배포를 입증하지 않는다.
