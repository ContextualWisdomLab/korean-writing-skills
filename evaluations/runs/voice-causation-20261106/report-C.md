## 수정문

1. 데이터운영팀은 11월 4일 중복 레코드 24건을 직접 제거했다.
2. 접근 기록 3건이 삭제되었다.
3. 백업은 보안팀에 의해 복구되었다.
4. 팀장은 외부 점검업체에 재점검을 요청했고, 업체가 재점검했다.
5. 담당자는 항목 10개를 직접 검토했다.
6. 다음 날 오류율은 2.4%에서 1.8%로 낮아졌다.
7. 보안팀의 복구 확인은 끝났지만, 데이터운영팀의 누락 항목 점검은 진행 중이다.

## 주요 수정·유지 이유

| 문장 | 구분 | 이유 |
|---|---|---|
| 1 | 편집상 선택 | 원문의 피동문도 문법적으로 가능합니다. 직접 작업한 팀이 확인되어 있으므로 능동문으로 행위자를 드러내고, 확인된 작업일을 넣었습니다. |
| 2 | 유지 | 삭제 주체와 경로가 확인되지 않았으므로 피동문을 유지했습니다. 행위자가 생략되어 있어도 문법적으로 성립하며, 기록에 일어난 일을 전달하는 데 적합합니다. |
| 3 | 사실 정정·편집상 선택 | 근거가 없는 ‘정상’ 평가를 삭제했습니다. 복구 대상과 결과가 중심인 보고서이므로 백업을 문장의 화제로 두는 피동문은 유지했습니다. ‘보안팀에 의해’도 문법 오류는 아닙니다. |
| 4 | 편집상 선택 | 확인된 두 행위인 팀장의 요청과 업체의 재점검을 각각 서술했습니다. ‘실시되게 했다’라는 사동 표현 자체가 문법적으로 틀려서 고친 것은 아닙니다. |
| 5 | 의미 관계 수정 | ‘검토시켰다’는 사동 표현으로, 다른 사람에게 검토하게 했다는 뜻이 됩니다. 담당자가 직접 검토했다는 사실에 맞춰 ‘검토했다’로 고쳤습니다. 원래 표현이 언제나 비문인 것은 아니지만, 이 문맥에서는 행위 관계를 잘못 전달합니다. |
| 6 | 유지 | ‘낮아졌다’는 오류율의 변화를 나타내는 적절한 표현입니다. 수치와 시간 순서를 그대로 유지했으며, 이 문장만으로 중복 제거와 오류율 변화의 인과관계가 확인되는 것은 아닙니다. |
| 7 | 편집상 선택 | 원문도 문법적으로 성립합니다. 각 업무를 맡은 팀을 밝히고, 끝난 작업과 진행 중인 작업을 ‘하지만’으로 연결해 완료 범위를 분명하게 했습니다. |
