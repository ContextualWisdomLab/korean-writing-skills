# 실행·채점의 분리

## 평가 설계

별도 설계자가 기존 3축·분석적 루브릭만 읽고 두 입력과 적용 기준을 만들었다. 작성 대상 스킬, 작성자의 예상 답안과 실제 출력은 읽지 않았다. 문법 판단에 필요한 공식 원문의 확인 결과는 원문을 읽은 조사 담당자가 전달했으며, 설계자가 그 원문을 독립적으로 다시 읽었다고 기록하지 않는다. 이 전달 범위는 `criteria.md`에 있다.

입력·기준·루브릭 사본의 해시는 실행 전에 고정했다. 각 사례에는 여러 올바른 수정안과 문장 유지가 가능하며 특정 문구와의 문자열 일치로 채점하지 않는다.

## 실행자에게 준 지시

판본별·입력별로 새 독립 문맥의 실행자를 두고 다음 지시를 동일하게 적용했다. 파일 위치만 담당 판본과 입력에 맞췄다.

> 지정된 스킬 스냅샷의 `SKILL.md`를 먼저 읽고 필요한 근거 파일만 읽어 적용한다. 담당 입력 하나의 요청을 수행하고 사용자에게 줄 최종 답만 출력 파일에 저장한다. 읽을 수 있는 자료는 지정 스킬과 해당 입력뿐이다. 다른 입력·스냅샷·평가 기준·루브릭·동결 장부·다른 출력·실제 저장소·검증 이력은 읽지 않는다. 외부 검색을 하지 않는다. 완료 보고에는 읽은 상대 경로와 접근 범위 준수 여부를 적고, 출력 파일에는 실행 메타데이터나 자체 점수를 넣지 않는다.

기존 스킬의 `references/validation.md`는 과거 평가 자료를 담고 있으므로 양쪽 실행 스냅샷에서 제외했다. 새 평가 문서는 원래부터 스킬 폴더 밖에 있다. 실행자에게 판본 우열, 작성자의 예상 답안이나 평가 기준을 전달하지 않았다. 스냅샷의 중립적인 구분명은 보였으므로 실행자까지 완전히 판본을 가린 실험으로 부르지는 않는다.

보강판의 두 번째 입력 실행은 장시간 진행되어 상태 확인을 위해 한 번 중단한 뒤 같은 문맥에서 재개했다. 재개 지시는 이미 허용된 자료로 답을 마무리하라는 내용이었으며, 정답·채점 기준·다른 출력·수정 방향을 전달하지 않았다. 실행 시간과 중단 조건을 통제한 성능 비교는 아니다.

## 채점

실행과 작성에 참여하지 않은 새 평가자는 동결 기준·루브릭·입력 두 개와 익명으로 이름 붙인 출력 네 개만 읽는다. 스킬, 작성자의 설명, 판본 매핑, GitHub 변경분과 다른 평가를 읽지 않는다. 각 출력의 의미 보존·한국어 자연스러움·과잉 교정 회피를 0–3점으로 판정하고 실제 문장을 근거로 남긴다. 세 축 모두 2점 이상이고 중대 오류가 없어야 통과한다.

완료된 보고서 출력 두 개를 먼저 전달하고 문법 판단 출력 두 개를 이어 전달했다. 한 평가자가 동일한 동결 기준으로 두 쌍을 채점하며, 마지막 쌍의 판정까지 끝나기 전에 판본 매핑을 공개하지 않는다.

평가 후에만 판본 매핑을 공개한다. 수용 판정은 아래에 명시한 독립 평가자가 합성 두 사례에 적용한 결과이며, 반복 실행 안정성·채점자 일치도·실제 문서 사용 효과는 검증하지 않는다. 접근 경계는 지시와 자기보고에 근거하며 운영체제 수준의 접근 차단 실험은 아니다.

## 최초 채점의 절차상 보류와 재평가

첫 평가자는 문법 응답의 인과 강화 여부를 별도 문언 검토에 맡겼다. 그 진행 상태를 확인하는 전체 협업 목록 조회에서 다른 작성자의 완료 메타데이터와 읽은 스냅샷 경로 목록이 노출되었다. 스킬 본문이나 판본 매핑을 열람했다는 보고는 없지만, 허용 자료 밖 메타데이터 노출 자체가 경계 이탈이다. [최초 채점](blind-grading.json)은 내용 판정을 보존하되 `protocol_verdict: hold`, `eligible_for_final_acceptance: false`로 두고 최종 수용 근거에서 제외한다. 먼저 완료한 [보고서 부분 채점](partial-report-grading.json)도 원본 그대로 보존한다.

별도의 새 평가자에게 동결 입력·기준·루브릭과 익명 출력 네 개만 전달했다. 이전 판정·문언 검토 결과·이탈 경위·판본 매핑은 전달하지 않았다. 허용 파일의 직접 읽기 외에 추가 평가자 생성, 전체 협업 목록·파일 목록·다른 메타데이터 조회를 금지했다. 이 재채점은 최초 기록을 덮어쓰지 않고 별도 파일에 남긴다.

재평가가 장시간 진행되어 상태 확인을 위해 한 번 중단한 뒤 같은 문맥에서 마무리하도록 재개했다. 그때 새 자료·점수·판정 방향은 전달하지 않았다. 실행 속도나 시간 조건을 통제한 비교가 아니다.

작성자는 최초 문법 응답의 시간적 선후를 인과로 강화한 설명을 확인하고, 의미 보존 원칙이 수정 이유와 선택 편집안에도 적용되도록 지침을 보강했다. 평가 기준과 입력은 바꾸지 않는다. 보강 후 스냅샷은 새 판본으로 고정하며, 입력별 새 문맥에서 재실행한다. 같은 입력에서 확인된 문제를 고친 회귀 점검이므로 독립 미사용 입력의 성능이나 일반 개선 효과로 해석하지 않는다.

후속 보강 응답 두 개는 또 다른 새 평가자에게 별도로 맡겼다. 이 평가자는 두 입력·동결 기준·루브릭과 담당 익명 출력 두 개만 읽고 이전 출력·채점·판본 매핑·스킬은 읽지 않는다. 앞선 네 출력의 재채점과 후속 두 출력의 채점 담당자가 다르므로, 판본별 수용 결과는 개별 출력의 기준 충족 여부로만 기록한다. 동일 평가자가 판본 효과를 비교한 실험이나 평가자 간 신뢰도 측정으로 제시하지 않는다.

## 실행 중 반영된 main과의 통합

후속 보강판 R의 실행을 시작한 뒤, 별도 [PR #27](https://github.com/ContextualWisdomLab/korean-writing-skills/pull/27)이 main에 병합되었음을 확인했다. R 스냅샷과 진행 중인 실행은 바꾸지 않았다. 해당 main을 별도 통합 커밋으로 병합하고 변경 이력의 충돌 한 곳은 양쪽 항목을 모두 보존해 해결했다.

[통합 판본](integrated-freeze.json)은 R과 다른 스킬 파일 7개를 명시한다. 새 능동·피동·사동 참고 문서는 R과 바이트가 같지만, 전체 스킬 스냅샷은 같지 않다. R의 응답 점수는 R에만 귀속한다. 통합 판본에는 별도 구조·출처·자동 검사·패키지 대조와 병합 내용 검토를 적용하며, R의 점수를 통합 판본 전체의 블라인드 실행 결과로 표시하지 않는다.
