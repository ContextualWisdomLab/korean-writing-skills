# 평가 기준: 능동·피동·사동

상태: **동결**. 출력·기대 답안·수정 대상 스킬·저장소 변경 내역을 보지 않고 작성했다. 공식 설명 확인과 입력 검토를 마쳤다. 동결 시각·해시는 [freeze.json](freeze.json)에 기록한다. 출력 관찰 뒤 기준을 바꾸지 않는다.

## 공통 판정

[three-axis.md](three-axis.md)의 0–3점 기술과 [analytic-korean-editing.md](analytic-korean-editing.md)의 M1·M2·S1·V1·O1을 적용한다. 각 입력의 의미 보존·한국어 자연스러움·과잉 교정 회피가 모두 2점 이상이고 중대 오류가 없어야 통과한다. 두 입력 모두 통과해야 실행 통과다. 점수 평균으로 실패를 상쇄하지 않는다. 미실행·빈 응답·접근 경계 위반은 보류다.

문장 유지·주어 생략·문장 결합을 포함한 복수 대안을 허용한다. 능동문 비율·수정량·문자열 일치는 평가하지 않는다. 문법 오류·의미 불일치·편집 선호를 구분하고 입력과 출력의 대조를 근거로 남긴다. 사실 보존을 자연스러움보다 우선한다. 통과 기준은 프로젝트 잠정 기준이며 타당화된 시험 절단점이 아니다.

## 입력 1

- 24건·3건·10개·오류율 수치와 변화 방향을 보존한다. 날짜를 쓰면 11월 4일 제거와 다음 날 변화를 구별한다.
- 미확인 삭제 주체를 만들지 않는다. 삭제 문장의 피동 유지 자체는 감점하지 않는다.
- 중복 제거·복구의 행위자를 바꾸지 않는다. 결과 중심 피동 유지와 적절한 능동화를 모두 허용한다.
- 재점검 요청자와 수행자를 구별한다. 요청을 직접 수행이나 확인되지 않은 강제로 바꾸지 않는다.
- 직접 검토 사실에 타인에게 맡기는 의미를 보태지 않는다. ‘검토시키다’의 형태 자체를 보편적 비문으로 판정하지 않는다.
- 오류율 변화의 인과 효과·유의성·확실성을 보태지 않는다.
- 복구 확인 완료와 누락 점검 진행 중을 구별한다. ‘정상’은 삭제하거나 미확인 평가임을 명시한다.

## 입력 2

예문 속 인용도 교정 대상이다. 표현 수정 자체를 인용 훼손으로 판정하지 않는다.

- A: 능동–피동과 주동–사동을 구별하고 참여자 역할을 설명한다. 능동과 사동을 단순한 반대말로 처리하지 않는다.
- B: 상태 변화 의미를 보존한다. 형태만으로 피동을 단정하거나 확인되지 않은 행위자·원인을 보태지 않는다. 학설별 범주 차이는 허용한다.
- C: 가시성과 의도적 제시를 구별한다. 공개 범위를 확대하지 않는다. 같은 수정안도 제시 행위가 별도로 보존되면 허용한다. 무조건 금지·무조건 유지를 요구하지 않는다.
- D: 교장→교사→학생의 두 단계와 첫째 문장의 참여자 차이를 보존한다. 중첩 형태만으로 금지하지 않는다.
- E: 직접 검토와 외부 전문가에게 맡긴 검토를 구별한다. 직접 행위 문맥의 의미 불일치를 판단하며 모든 ‘시키다’를 일괄 삭제하거나 유지하지 않는다.

## 출처와 적용 범위

원문을 확인한 별도 조사 결과를 제공받아 다음 범위에 적용했다. 설계자가 원문을 재열람한 것으로 기록하지 않는다. 아래 자료는 교정문 하나를 정답으로 지정하는 근거가 아니다.

- [국립국어원 상담 사례 8237](https://www.korean.go.kr/front/mcfaq/mcfaqView.do?mcfaq_seq=8237)(2020-01-16): 능동–피동, 주동–사동의 대립 관계. A에 적용한다.
- [온라인가나다 324057](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=57&pageIndex=1&qna_seq=324057)(2025-11-24): ‘따뜻해지다’의 사전상 상태 변화 용법과 피동 범주의 학설 차이. B에 특정 이론만 강제하지 않는다.
- [온라인가나다 332949](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=57&pageIndex=1&qna_seq=332949)(2026-06-29): ‘알려지다’는 사동 ‘알리다’와 피동 ‘-어지다’가 굳어진 합성동사이며 이중 피동이 아니라는 설명. 다른 단어에 일반화하지 않는다.
- [온라인가나다 332561](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=57&pageIndex=1&qna_seq=332561)(2026-06-20): ‘보이다’의 사동·피동 해석에 따른 문맥 판단. C의 가시성 표현을 줄이는 것은 제시 행위가 없고 뜻이 같을 때의 편집 선택이다.
- [온라인가나다 315645](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=57&pageIndex=1&qna_seq=315645)(2025-06-02): 엄마→큰아들→동생의 서로 다른 주체가 있는 두 단계 사동 예시. D의 단계 구별에 적용한다.
- [온라인가나다 331639](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=57&pageIndex=1&qna_seq=331639)(2026-05-29)는 직접 교육과 교육받게 하는 행위, 현실 용법과 엄격한 규범 관점을 구별한다. [310082](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=57&pageIndex=1&qna_seq=310082)(2025-02-12)는 ‘환기하다/환기시키다’의 의미와 사동 조건을 설명한다. ‘검토시키다’는 이 원칙을 적용한 가상 예문이며 원문의 직접 판정 사례가 아니다.
- 김중수(2015), [DOI](https://doi.org/10.20880/kler.2015.50.2.173), [PDF](https://www.koredu.net/uploads/papers/ART002004885.pdf): p.195 예(17)의 사동 후 사동과 주13의 교육용 논리적 예시라는 한정만 확인했다. 모든 중첩 표현의 자연스러움으로 일반화하지 않는다.

변경 기록: 확인 대기였던 문맥별 ‘보여지다’, 두 단계 사동, ‘하다/시키다’ 판단을 위 출처의 확인 범위로 한정해 확정했다. 미해결 항목 없음.
