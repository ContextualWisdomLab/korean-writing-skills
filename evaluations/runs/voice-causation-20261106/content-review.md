# 능동·피동·사동 지침의 독립 내용 검토

검토 대상은 [내용 커밋](https://github.com/ContextualWisdomLab/korean-writing-skills/commit/0c2e6958961d73c2e78ce011fe564b9da0a00ff8)의 변경 파일 10개다. 한국어 스킬 작성자와 다른 새 문맥의 검토자가 `AGENTS.md`, staged 변경분, 새 참고 문서 전체와 새 출처 장부 항목을 읽었다. 평가 기준·입력·출력은 읽지 않았다.

## 관찰

읽은 문서에서 필수 수정이 필요한 문법·의미·출처 표시 문제를 발견하지 못했다. 다음을 확인했다.

- 능동–피동과 주동–사동의 두 대립을 구별하고, 조건별 적극 권장 패턴 여섯 가지를 제시한다.
- 직접 수행과 사동 관계가 있는 경우를 구별한다. 행위자·인과를 추가하거나 실제 사동 단계를 줄이는 수정을 막는다.
- 상태 변화, `보여지다`의 문맥, 사동과 피동의 결합, `향상시키다`의 문법성과 간결성을 구분한다.
- 진입점·실전 예문·문장 작성 경로·사용 안내 사이에서 이 기준과 충돌하는 지침을 발견하지 못했다.
- 출처의 지위와 실제 열람 범위를 표시하며 학술적 분석을 공적 금지 규정으로 확대하지 않는다.

## 독립적으로 원문을 다시 읽은 범위

| 출처 | 직접 확인한 범위 | 대조 결과 |
| --- | --- | --- |
| 국립국어원 「시키다」, 2026-05-29, qna331639 | 답변 본문 | 직접 수행·실제 사동과 엄격한 규범 관점의 구분이 지침과 부합 |
| Ahn·Yap, DOI 10.1075/dia.16037.ahn | 출판사 공개 초록·서지·목차 | 상태 변화·중간태·피동의 통시적 분석 및 열람 범위 표시가 부합 |
| 김중수, DOI 10.20880/kler.2015.50.2.173 | PDF 인쇄 pp.175–177 | 학교 문법과 이론적 분석의 차이를 인정하는 설명이 부합 |

검토자는 나머지 원문을 모두 재대조하지 않았다. 특히 `향상시키다` 상담은 출력이 잘려 독립 재대조를 마치지 못했다. 이 원문은 작성 담당자가 답변 1을 직접 읽었으며, 그 확인 범위는 스킬 출처 장부에 별도로 기록했다. 김중수 논문의 p.195·p.199도 작성 담당자의 열람 범위이며 이 독립 검토의 범위로 합치지 않는다.

별도 파일 수정이나 검사는 수행하지 않았다. 이번 기록은 한 검토자의 제한된 내용 검토이며 전체 출처 감사, 평가 성능 검증, GitHub의 정식 승인 리뷰 또는 최종 커밋 동일성 검증을 뜻하지 않는다. 스킬 실행 스냅샷은 이 검토가 진행 중일 때 고정되었으며, 검토 결과에 따른 스킬 변경은 없었다.
