# 능동·피동과 주동·사동: 보강과 평가 기록

## 목적과 변경 범위

한국어의 능동–피동과 주동–사동을 구별하고, 실제 행위자·사동 관계·상태 변화·담화 초점에 따라 권장·수정·유지할 표현을 제시한다. 피동·사동의 표면형을 일괄 금지하지 않으며, 문법 오류·의미 불일치·간결성 선택을 구별한다. 공식 사전·상담과 학술 분석의 확인 범위는 [출처 장부](../../../skills/korean-editing/references/source-ledger.md)에, 적용 절차는 [능동·피동·사동 지침](../../../skills/korean-editing/references/voice-and-causation.md)에 있다.

자료 조사·지침 작성, 입력·기준 설계, 독립 내용 검토, 판본별 실행, 익명 채점을 나누어 진행했다. [동결 기준](criteria.md)과 [입력·기준 해시](freeze.json)는 첫 실행 전에 확정했으며, 관찰한 출력에 맞춰 수용 기준을 바꾸지 않았다.

## 판본과 공개 출력

| 판본 | 원격 내용 커밋 | 입력 1: 보고서 | 입력 2: 문법 판단 |
| --- | --- | --- | --- |
| 기존판 P | `0cd3281e075a5644498cf25f85d5563a2ea5ee67` | [report-B.md](report-B.md) | [grammar-A.md](grammar-A.md) |
| 초기 보강판 Q | `0c2e6958961d73c2e78ce011fe564b9da0a00ff8` | [report-A.md](report-A.md) | [grammar-B.md](grammar-B.md) |
| 후속 보강판 R | `9bed9a94a390fb7d545ccfe73b72f4372944748c` | [report-C.md](report-C.md) | [grammar-C.md](grammar-C.md) |

각 입력·판본은 새 문맥에서 실행했다. 원본 출력은 내용 수정 없이 익명 파일명으로 복사했다. 실제 읽은 파일과 입력·출력 해시는 [실행 장부](execution-manifest.json)에 있다. 출력 생성에는 이전 출력·평가 기준·루브릭·저장소 변경분을 제공하지 않았다. 상세 접근 경계와 진행 중 중단·재개의 범위는 [실행 절차](execution-protocol.md)를 따른다.

## 초기 판정과 후속 수정

[새 평가자의 재채점](clean-grading.md)은 기존판 P **2/2 통과**, 초기 보강판 Q **1/2 통과**다. 세 축은 의미 보존·한국어 자연스러움·과잉 교정 회피이며, 각 축 2점 이상이고 중대 오류가 없어야 사례를 통과한다. 합산이나 평균으로 실패를 상쇄하지 않는다.

| 판본·사례 | 의미 보존 | 자연스러움 | 과잉 교정 회피 | 중대 오류 | 판정 |
| --- | ---: | ---: | ---: | --- | --- |
| P 보고서 | 3 | 3 | 3 | 없음 | 통과 |
| Q 보고서 | 3 | 3 | 3 | 없음 | 통과 |
| P 문법 | 3 | 3 | 3 | 없음 | 통과 |
| Q 문법 | 0 | 3 | 3 | 있음 | 실패 |

Q의 문법 응답은 입력의 `가림막 제거 뒤의 가시성 변화`를 선택안 설명에서 `가림막 제거가 변화의 원인임`으로 강화했다. 본문에 명시할 필요가 있는지를 조건으로 달았지만, 원인으로 확인된 경우라는 조건은 없었다. 선택안의 설명도 의미 보존 평가 대상이므로, 다른 문법 설명의 적합성으로 이 오류를 상쇄하지 않았다.

이 실패를 확인한 뒤 기존 E1 의미 보존 원칙을 구체화했다. 시간적 선후를 인과로 바꾸지 않는 조건을 수정문·이유·선택안에 모두 적용하고, 인과 표현을 제안할 때는 실제로 원인 관계가 확인된 경우라는 조건을 명시하도록 했다. 원문이 이미 주장한 인과를 임의로 약화하지 않는 기존 정책은 유지한다. [별도 내용 검토](causality-patch-review.md)에서 필수 수정이 없었고, [R 스냅샷](final-freeze.json)을 고정한 뒤 같은 입력으로 다시 실행했다.

## 후속 보강판의 채점

후속 보강판 R은 **2/2 통과**다. [독립 채점](final-grading.md)과 [원본 JSON](final-grading.json)에 실제 문장 근거와 접근 범위를 남겼다.

| 사례 | 의미 보존 | 자연스러움 | 과잉 교정 회피 | 중대 오류 | 판정 |
| --- | ---: | ---: | ---: | --- | --- |
| R 보고서 | 3 | 3 | 3 | 없음 | 통과 |
| R 문법 | 3 | 3 | 3 | 없음 | 통과 |

보고서에서는 요청자·수행자, 직접 검토, 복구 확인 완료와 누락 점검 진행 중을 구별했다. 문법 메모에서는 가시성과 실제 제시, 비공개 영상의 참가자 범위, 두 단계 사동, 직접 검토와 전문가 위탁을 보존했다. 문제였던 가림막 사례도 시간 관계를 명시적인 인과로 바꾸려면 별도 확인이 필요하다고 설명했다. 평가자는 지정된 일곱 파일만 읽었고 외부 자료·다른 출력·이전 판정·판본 매핑·협업 메타데이터에 접근하지 않았다고 보고했다.

P·Q를 채점한 평가자와 R의 평가자는 다르다. 위 결과는 각 출력의 동결 기준 충족 여부이며, 동일 평가자가 판본 효과를 비교한 성능 향상 추정치가 아니다.

## 평가 절차 이탈의 보존

최초 평가자는 문언 검토의 진행 상태를 확인하면서 전체 협업 목록을 조회했고, 허용 범위 밖 작성자 완료 메타데이터가 노출되었다. [최초 채점](blind-grading.json)은 내용 판정을 그대로 보존하되 절차상 **보류**, 최종 수용 근거에서는 **제외**한다. [먼저 끝난 보고서 부분 채점](partial-report-grading.json)도 덮어쓰지 않았다.

그 뒤 별도의 새 평가자가 허용된 아홉 파일만 읽어 P·Q 네 출력을 재채점했다. 이전 판정·문언 검토·판본 매핑·스킬을 보지 않았으며, 접근 범위 준수는 자기보고로 기록했다. R의 두 출력은 또 다른 독립 평가자에게 배정했다. 수용 결과를 제시할 때 평가자가 다르다는 점을 함께 밝히며, 평가자 간 신뢰도나 동일 평가자의 판본 효과 비교로 취급하지 않는다.

## 최신 main 통합과 검증 범위

R 실행 중 [PR #27](https://github.com/ContextualWisdomLab/korean-writing-skills/pull/27)의 경력 문서 보강이 main에 합쳐졌다. 동시 변경을 보존해 통합한 커밋은 `4439a2183fe564494278d7ee809d06375f2cb79a`다. 변경 이력의 충돌 한 곳은 양쪽 항목을 모두 남겨 해결했다.

[통합 판본 기록](integrated-freeze.json)은 R과 다른 스킬 파일 7개를 열거한다. 새 능동·피동·사동 문서는 R과 바이트가 같지만 전체 스킬 스냅샷은 다르므로, R 점수를 통합본 전체의 블라인드 결과로 승계하지 않는다. 통합본의 119개 자동 검사·구조·출처 연결·패키지 파일 21개 대조와 원격 확인 범위는 [검증 기록](verification.md)에 있다.

[독립 통합 검토](integration-review.md)는 자동 병합된 지침의 변경 구간·주변 문맥과 양쪽 부모의 변경 보존을 확인해 필수 수정 없음으로 판정했다. 문법 출처 전체의 재조사나 통합본의 새 블라인드 실행은 아니다.

원격 Checks·리뷰·최종 head와 병합 상태는 [PR #26](https://github.com/ContextualWisdomLab/korean-writing-skills/pull/26)의 실제 상태로 확인한다. 처음 내용 커밋의 CodeRabbit 성공을 후속 커밋에 승계하지 않는다. 후속 내용 커밋의 `neutral / Review rate limited`도 자동 내용 검토 통과로 표시하지 않는다.

## 해석의 한계

이 결과는 고정된 합성 입력 두 개의 사례 점검이다. 동일 입력에서 관찰한 문제를 수정한 회귀 점검이 포함되며, 미사용 입력의 성능·반복 실행 안정성·실제 팀 문서 효과·문법 이론 전체의 타당성을 검증하지 않는다. 평가자별 자료 경계는 지시와 자기보고에 근거하며 운영체제 수준의 차단이나 독립 접근 로그 감사가 아니다. 외부 출처의 확인 범위는 각 장부에 한정하며, 익명 응답에 든 참고자료 전체를 평가자가 새로 검증한 것으로 표시하지 않는다.
