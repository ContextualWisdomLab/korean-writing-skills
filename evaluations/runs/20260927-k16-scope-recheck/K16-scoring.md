# K16 독립 채점

## 원문 주장과 교정문 본문 대응

| 원문 명제·앵커 | 교정문 본문 | 판정 |
| --- | --- | --- |
| 심사위원 2-3에 대한 응답 | 동일한 표제 유지 | 보존 |
| 측정 동일성 검토 절차가 내부 분석 노트 3.2절에 자세히 정리됨 | 내부 노트 언급 삭제, 원고 방법 2.3절 요약만 제시 | 제출하지 않는 문서 인용 제거는 적절한 편집 선택. 상세 절차가 내부 노트에 있다는 사실은 본문에서 빠짐. 제출 전 확인 사항에서 원고 반영 여부를 점검하도록 함 |
| 모형 비교에 Vuong (1989)의 검정 사용 | 같은 검정과 인용 유지 | 보존. 원고 참고문헌에 없는 인용임을 별도 지적 |
| 검토 결과를 원고 표 2에 보고 | 결과를 표 2에 보고 | 보존 |
| 방법 2.3절에 절차 요약, 뒤에 (Muthén, 2002) | 방법 2.3절 요약은 유지하나 인용을 마지막 선별 질문지 제외 문장 뒤로 이동 | **출처 귀속 변경.** 원문의 인용 범위도 확정할 수 없지만, 새 위치는 선별 질문지 제외의 근거로 읽히므로 보존으로 볼 수 없음. 설명의 “현재 인용 위치를 유지”와도 모순 |
| 종속변수 수면 문제(Y)의 집단 간 동일성 유지 | 원고에서 확인된 이름인 수면 곤란 수준(Y)의 집단 간 동일성 유지 | 정식 명칭으로 교정하고 결과 강도 보존 |
| 선별 목적으로만 사용한 불면 선별 질문지는 검토에서 제외 | 같은 도구와 제외 범위 유지 | 전문용어·도구 구별 보존. 다만 이동한 Muthén 인용이 이 문장의 근거처럼 붙음 |

## K16 확인 지점

| 지점 | 판정·근거 |
| --- | --- |
| 제출하지 않는 문서 참조 | 충족. 내부 분석 노트 3.2절을 제출하지 않는 자료로 지적하고, 원고에 필수 설명이 반영됐는지 확인하라고 함. 제출 문서로 새 위치를 꾸며내지 않음 |
| 참고문헌에서 풀리지 않는 인용 | 충족. Vuong (1989)이 원고 참고문헌에 없다고 지적하고, 사용·출처를 확인한 뒤 맞으면 항목을 추가하라고 함. 서지정보를 만들거나 인용을 지우지 않음 |
| 풀리는 참조 | 부분 충족. 표 2, 방법 2.3절, Muthén (2002)을 남겼으나 Muthén 인용 위치를 바꿔 귀속을 변경함 |
| 척도 정식 명칭 | 충족. 수면 문제(Y)를 확인된 수면 곤란 수준(Y)으로 고침 |
| 다른 도구 이름 | 충족. 불면 선별 질문지를 Y와 구별함 |
| 문장 교정 | 부분 충족. 문장 분리와 제출 자료 중심 배치는 읽기 좋고 없는 결과·검정을 만들지 않았으나, 인용 이동은 의미 보존에 실패함 |
| 값·위치 보존 | 2-3, 3.2절, 표 2, 2.3절, 1989, 2002, Y의 값은 바꾸지 않음. 3.2절은 본문에서 생략하고 설명·확인 사항에 남김 |

## 분석적 루브릭

| 항목 | 판정과 수정 이유 |
| --- | --- |
| M1 의미·증거 보존 | **미흡.** 결과·검정·변수·도구 구별은 유지했으나 Muthén (2002)을 절차 요약 문장 뒤에서 질문지 제외 문장 뒤로 옮겨 출처의 적용 대상을 달리 읽히게 함. 원문 인용 범위의 불확실성을 본문에서도 유지해야 함 |
| M2 행위자·생략 주어 | 충족. 검정 사용과 보고의 행위자를 새로 만들거나 피동을 부적절하게 바꾸지 않음 |
| D1 담화·구조 | 충족. 제출 원고의 절차·결과 위치를 앞세우고 검정·변수·제외 범위를 분리함. 인용 위치 때문에 주장과 근거 연결은 손상됨 |
| S1 문장·호응 | 충족. 문장별 호응과 병렬이 대체로 자연스러움 |
| V1 능동·피동·사동 | 충족. ‘유지되었다’, ‘포함하지 않았다’를 문맥에 맞게 사용하고 일괄 전환하지 않음 |
| T1 번역투·장르 | 충족. 심사 응답서의 정중하고 간결한 문체를 유지함 |
| O1 과잉 교정 억제 | 부분 충족. 정식 명칭 수정과 비제출 자료 참조 정리는 근거가 있으나, 확인하지 못한 Muthén 인용의 새 귀속을 본문에 확정해 버림. 설명에서 이를 ‘위치 유지’로 잘못 기술함 |
| G1 표기 | 충족. 눈에 띄는 맞춤법·띄어쓰기·문장 부호 문제 없음 |

## 세 축 및 결론

| 축 | 점수 | 근거 |
| --- | ---: | --- |
| 의미 보존 | **1/3** | 전문용어와 결과는 보존했으나 인용 귀속이라는 중요한 논리 연결을 변경함 |
| 한국어 자연스러움 | **3/3** | 문장 분리, 제출 원고 중심의 흐름, 응답서 문체가 자연스러움 |
| 과잉 교정 억제 | **2/3** | 변경 대부분은 필요하지만 근거가 불확실한 인용 이동은 불필요하고 영향이 있음 |

**중대 오류:** Muthén (2002)의 인용 위치 이동으로 출처 귀속이 변조됨. 원문 자체의 인용 범위가 불명확하므로 어느 주장이 실제로 해당 출처에 근거하는지는 판정하지 않는다. 다만 교정문이 이를 선별 질문지 제외 문장의 근거로 읽히게 한 것은 확인 가능하다. 없는 서지정보·수치·검정은 만들지 않았다.

**판정: 실패.** 의미 보존 1점으로 내부 통과 경계인 축별 2점에 못 미치며, 인용 귀속 변경은 중대 오류다.

**접근 범위:** 출력의 ‘실제 열어본 파일’ 목록에 적힌 여섯 경로는 K16 기준에 적힌 실행자 허용 범위의 입력·두 스킬·근거 파일에 해당한다. **자기보고상 접근 준수**로만 판단하며 실제 접근 기록을 검증한 결론은 아니다.
