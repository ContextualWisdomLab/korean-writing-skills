# 교정문

심사위원 2-3에 대한 응답: 측정 동일성 검토 절차는 원고의 방법 2.3절에 요약하고, 검토 결과는 표 2에 보고했습니다. 모형 비교에는 Vuong (1989)의 검정을 사용했습니다. 종속변수인 수면 곤란 수준(Y)은 집단 간 동일성이 유지되었습니다. 선별 목적으로만 사용한 불면 선별 질문지는 측정 동일성 검토에 포함하지 않았습니다(Muthén, 2002).

# 주요 변경과 근거 종류

- **저자 요구·편집 판단:** 원고에서 확인된 변수 이름인 `수면 곤란 수준(Y)`으로 통일했습니다. `수면 문제`는 확인된 정식 명칭과 달라 그대로 두지 않았습니다. 이 변경은 APA의 특정 어휘 규칙이 아닙니다.
- **편집 판단:** 제출하지 않는 내부 분석 노트 3.2절을 응답서의 근거 위치에서 빼고, 제출 원고의 방법 2.3절과 표 2를 앞에 제시했습니다. 내부 노트에 상세 절차가 있다는 원문의 사실을 부정하지 않으며, 해당 내용이 원고에 충분히 반영됐는지는 제출 전 확인이 필요합니다. 한국어 글 고치기 스킬의 ‘원고·심사 응답 교차’ 절과 APA 7 학술 논문 작성 스킬의 ‘심사 응답과 인계’ 절에 따른 편집 판단입니다.
- **편집 판단:** 절차·결과·모형 비교·변수 범위를 문장별로 나눠 읽기 쉽게 했습니다. 검정 수행, 동일성 유지, 선별 질문지 제외라는 원문의 주장은 유지했습니다.
- **공식 안내를 참고한 확인 사항:** 본문 인용과 참고문헌의 대응은 APA 7 학술 논문 작성 스킬의 ‘양적 연구 보고와 표시를 점검한다’ 절에서 요구합니다. 다만 제공된 자료만으로 Vuong (1989)의 정확한 서지정보나 Muthén (2002)이 이 문장을 뒷받침하는지 확인할 수 없어, 인용의 적합성이나 참고문헌 항목을 새로 확정하지 않았습니다.

# 고치지 않은 부분의 이유

- `Vuong (1989)`과 `Muthén (2002)` 인용은 원문의 출처 귀속을 보존하려고 남겼습니다. 어느 문장에 Muthén (2002)이 적용되는지 원문만으로 분명하지 않아 현재 인용 위치를 유지했으며, 저자 확인이 필요합니다.
- ‘집단 간 동일성이 유지되었다’는 결과의 강도를 임의로 높이거나 낮추지 않았습니다. 검토 대상과 판단 기준도 제공되지 않아 추가하지 않았습니다.
- ‘불면 선별 질문지’는 `수면 곤란 수준(Y)`과 다른 도구이므로 이름을 통일한다며 바꾸지 않았습니다.

# 제출 전 확인 사항

1. 원고의 방법 2.3절과 표 2에 응답서가 주장하는 검토 절차·결과가 실제로 있는지, 내부 분석 노트 3.2절에만 있는 필수 설명은 없는지 확인하세요. 필요하면 원고를 보완한 뒤 응답서의 위치를 최종 절·쪽·줄에 맞춰 적으세요.
2. Vuong (1989)의 검정을 실제로 사용했고 그 출처를 직접 확인했는지 확인하세요. 맞다면 원고 참고문헌에 정확한 서지 항목을 추가해야 합니다. 현재 참고문헌에는 없다는 정보만 주어졌으므로 항목을 만들어 넣지 않았습니다.
3. Muthén (2002)이 측정 동일성 검토 절차, 선별 질문지 제외 중 무엇의 근거인지 확인하고 인용을 해당 문장에 붙이세요. 원고 참고문헌의 항목·본문 인용과도 대조하세요.
4. 종속변수의 명칭과 `Y = 수면 곤란 수준` 대응을 원고·표 2·응답서 전체에서 대조하세요. 이 문안의 `집단 간 동일성 유지`와 `불면 선별 질문지 제외`가 원고의 실제 분석 범위와 일치하는지도 확인하세요.
