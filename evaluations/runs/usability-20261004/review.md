# 제한 범위 실사용판의 새 합성 평가

확인일: 2026-10-04. 스킬 작성·실행·채점은 별도 context로 분리했다. 사례 설계자는 스킬 본문이나 정답을 읽지 않고 합성 입력과 프로젝트 기준을 작성했다. 실행자에게 기준·이전 출력·검증 이력을 주지 않았고, 채점자는 스킬 본문·신구 판본 매핑 없이 입력·기준·익명 출력 A/B만 읽었다. 운영체제 수준 접근 격리는 아니며 접근 보고는 자기보고다.

## 실제 실행·검증

- 입력 3개와 기준은 `../../fixtures/usability-20261004/freeze.json`에 실행 전 동결했다. 부모가 실제 파일 바이트를 재계산하여 4/4 일치를 확인했다.
- 새 스킬 11개 파일은 `skill-freeze.json`으로 동결했다. 실행 후에도 11/11 일치했다. 기존 판본은 `d7cade69f30ffc580cdb468152ed82dc21c2c4ef`의 Git blob이다.
- 사례·판본별 별도 실행 6건을 확보했다. 부모가 출력 해시 6/6을 재대조했다. `execution-manifest.json`에 판본·출력·접근·기간·익명 라벨 대응을 기록했다.
- 독립 채점 3개 파일의 해시와 대상 출력 6개 해시를 부모가 대조했다. 축별 점수·중대 오류·조건별 근거·판정은 각 사례의 `grading.json`에 있다. Python으로 사례 수와 판정 조건을 집계했으며 실패를 평균으로 상쇄하지 않았다.

## 결과

점수 순서는 의미·사실 보존 / 한국어 자연스러움 / 과잉 교정 억제다. 각 축은 프로젝트 기준의 0–3점이며 검증된 절단점이나 공적 채점표가 아니다.

| 사례 | 새 판본 | 기존 판본 | 중대 오류 | 맹검 비교 |

| K17 검토 메모 | 3 / 2 / 3, PASS | 3 / 2 / 3, PASS | 양쪽 없음 | 동률 |

새 판본 3/3과 기존 판본 3/3이 이 제한 사례에서 통과했다. 수치·추정·인용 귀속, 미확인과 부재, 행위자, 연구윤리·설계·통계의 미제공 사실 보존을 확인했다. K17에는 중첩된 추정 표현과 확인 설명의 장황함이 남아 자연스러움 2점이었다. 이를 통과 기준에 맞추려고 출력이나 동결 기준을 바꾸지 않았다.

세 비교 모두 동률이므로 이번 변경이 일반 편집 성능을 향상했다고 주장하지 않는다. 새 상담 분류·`보여지다` 문맥 판단·재인용·편견 없는 언어 보강의 각 효과를 직접 식별하는 시나리오도 아니다. 그 효과는 별도 표적 평가가 필요하다. 이번 결과는 보강 후 기존 의미·사실 보존 경로의 제한적 회귀 증거다.

## 사용자가 볼 수 있는 결과

설치된 `skill-creator`의 `eval-viewer/generate_review.py`로 정적 비교 화면을 만들었다. 새 출력과 기존 출력, 독립 조건별 채점이 함께 들어간다. 사용자가 아직 피드백을 주지 않았으므로 사용자 승인으로 기록하지 않는다. token 수는 완료 알림에 없었고 기간은 보고된 실행 시간일 뿐 순수 추론시간·사용자 체감 지연이 아니다.

## 남은 Gate

패키저 독립 검토에서 발견한 참조 링크 우회와 그 수정·재검증은 별도다. 스킬 내용의 합성 통과가 패키저 결함을 지우지 않는다. 공식 release·전체 APA 준수·일반 타당화·실제 팀 dogfood·hosted CI·GitHub 비작성자 승인·기본 브랜치 통합은 이 평가로 입증하지 않는다. Issue #2는 계속 미완료다.
