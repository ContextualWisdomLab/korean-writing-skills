# K5

## 교정문

이번 검사가 건너뛰어졌다. 로그가 삭제되었다. 연구팀이 응답을 분류했고, 그다음에 통계 분석으로 p값이 계산되었다. 결과가 보여졌다.

## 이유와 확인 사항

- **편집 판단:** ‘통계 분석에 의해’를 ‘통계 분석으로’로 다듬었다. 응답 분류 뒤에 p값이 계산되었다는 순서와 분석 방법을 유지했다. p값을 계산한 주체를 연구팀으로 단정하지 않았다.
- 검사를 건너뛴 주체와 로그를 삭제한 주체는 원문에 없다. 두 피동문을 유지했다.
- ‘결과가 보여졌다’는 확인이 필요해 그대로 두었다. 결과가 눈에 보였다는 뜻이면 ‘결과가 보였다’, 결과를 제시했다는 뜻이면 ‘결과가 제시되었다’로 다듬을 수 있다. 원문만으로는 어느 뜻인지 확정할 수 없어 둘 중 하나를 적용하지 않았다.
- 위 판단은 제공된 스킬의 의미 보존·문장 수정·채택 조건에 따른 편집 판단이다. 외부 규정 원문은 확인하지 않았으므로 규범 위반으로 단정하지 않았다.

# K6

## 교정문

| 작업 | 보고된 상태 | 수행자 |
| --- | --- | --- |
| PR 확인 | 확인했습니다. | 원문에 명시되지 않음 — 확인 필요 |
| JARS Table 1 추가 | 추가했습니다. | 원문에 명시되지 않음 — 확인 필요 |
| validator 실행 | 실행했습니다. | 원문에 명시되지 않음 — 확인 필요 |
| Publication Manual 읽기 | 아직 읽지 못했습니다. | 원문에 명시되지 않음 — 확인 필요 |

## 이유와 확인 사항

- **편집 판단:** 여러 worker의 보고이므로 작업별로 수행자 칸을 두었다. 원문에는 작업과 worker의 대응 정보가 없어 실제 이름을 채울 수 없다. 각 작업의 수행자를 확인해 마지막 열에 적어야 누가 무엇을 했는지 분명한 보고가 완성된다.
- 생략된 주어를 코디네이터나 특정 worker로 복원하지 않았다. 행마다 서로 다른 worker가 수행했다고도 가정하지 않았다.
- 확인·추가·실행이라는 보고와 ‘아직 읽지 못했다’는 상태를 유지했다. validator 실행을 검증 통과로 확대하지 않았다.
- 제공된 스킬의 ‘주어 생략·행위자’와 ‘의미’ 채택 조건을 적용했다. 담당자 명시는 이 운영 보고의 편집 요구이며 한국어 문장 일반의 주어 생략 금지 규칙이 아니다.
