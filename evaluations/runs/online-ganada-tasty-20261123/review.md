# ‘먹음직하다’와 ‘-ㅁ/음 직하다’: 평가 전 고정 진단 설계

- 근거: N-Q30, 국립국어원 [338740 「먹음직하다」](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=201&pageIndex=1&qna_seq=338740&searchCondition=&searchKeyword=)(질문 2026-11-21, 답변 2026-11-23, 직접 확인 2026-11-23). 제47항 해설·사전 인용의 지위를 구별한다.
- 목적: 한 단어인 형용사와 명사형+보조 용언의 **문맥 구별**, 띄어쓰기 **원칙/허용 보존**, 원문 뜻·인용 보존만 진단한다. 전문 사전 대조나 전체 교정 타당화를 의미하지 않는다.
- **상태: 설계만 고정, 미실행.** 독립 실행 결과·출력 해시·채점·비교 개선율 없음. 기존 동결 평가 입력은 변경하지 않는다.

## 입력(모두 스킬 작성자가 직접 만든 가상 문장)

각 T1–T4의 **개별 실행**에는 아래 동일한 요청과 해당 ID의 문장 한 개를 쌍으로 전달한다. `blind-inputs.md`와 같은 **요청 → 원문** 형식이다. 나머지 세 문장은 함께 제공하지 않는다.

> 요청: 아래 가상 문장을 한국어 표기와 문맥에 맞게 검토하세요. 고칠 부분이 있다면 수정하고 이미 적절한 표현은 유지하세요. 교정문과 주요 판단 이유를 짧게 제시하세요.

이 요청에는 기대 교정문이나 채점 기준을 포함하지 않는다.

| ID | 독립 실행자에게 제공할 교정 입력 |
| --- | --- |
| T1 | 갓 구운 빵이 먹음 직하다. |
| T2 | 그가 벌써 점심을 먹었음 직하다. |
| T3 | 그가 벌써 점심을 먹었음직하다. |
| T4 | 원문에 ‘먹음직하다’라고 인용되어 있다. |

## 별도 채점자용 사전 기준

- T1: 빵이 맛있어 보인다는 맥락에서 등재 형용사 `먹음직하다`로 붙여 고친다. 의미를 '먹을 확률'이나 '먹을 만함'으로 바꾸지 않는다.
- T2: 발생 가능성의 명사형+보조 용언 `먹었음 직하다`는 **원칙형**이므로 유지한다.
- T3: 같은 구성의 `먹었음직하다`는 **허용형**이므로 오류로 표시하거나 강제로 띄우지 않는다.
- T4: 인용의 표기·의미를 보존하고 본문 인용을 무단 변경하지 않는다.
- 모든 항목: 출처가 인용한 사전 표제어를 독립 확인했다고 주장하지 않고, 제47항 해설과 개별 상담의 범위를 분리한다. 수정하지 않은 올바른 형태를 오답으로 채점하지 않는다. 독립 평가의 세 축 점수·중대 오류 판단은 `evaluations/protocol.md`를 따른다.

## 실행·기록 조건

실행 전에 대상 PR head SHA, 실제 제공한 SKILL/참조 파일 목록과 해시, 시나리오·루브릭 해시를 동결한다. 실행자에게 각 ID별 **공통 요청과 해당 원문 한 문장만** 제공하고 기대 답·이 평가 파일·작성자 판단은 숨긴다. 서로 다른 담당자가 최초 원출력과 수정/유지·보류를 독립 채점한다. 그러나 **근거 장부/지침에 판단이 노출돼 있으므로 이 네 사례는 본래부터 진단 전용**이며 외부 블라인드 성공 근거나 성능 향상률로 쓰지 않는다. 실제 실행은 아직 하지 않았다.
