# 교정문

## 방법

이 연구는 저자의 2022년 석사학위논문에서 사용한 자료를 사용한다. 수면 시간과 과제 정확도의 관계를 위계적 회귀분석으로 검토한다. 자료는 2021년 10월에 온라인 설문으로 수집되었다.

## 결과

수면 시간과 과제 정확도의 상관계수는 *r* = .42였다(*p* < .001, *N* = 156). 평균 수면 시간은 *M* = 6.8시간(*SD* = 1.1시간)이었다. 표 1에 제시한 1단계 모형의 설명력은 *R*² = .18(95% 신뢰구간[.07, .29])이었다. 표 1의 계수는 *b* = 0.31, *SE* = 0.08이다.

# 주요 변경과 근거

- **저자 요구:** 학위논문의 31–33쪽은 본문 근거로 쓰지 않았다. 같은 자료를 사용한다는 출처 사실과 논문의 연도는 남겼다.
- **저자 요구·편집 판단:** 이 연구가 자료를 사용하고 관계를 검토한다는 서술을 현재형으로 바꿨다. 실제로 끝난 2021년 자료 수집의 과거형은 유지했다.
- **APA 규정(Manual 6.36):** 1을 넘을 수 없는 *r*과 *R*²의 선행 0만 없앴다. *M*, *SD*, *b*, *SE*의 값과 단위는 유지했다.
- **APA 공식 안내(A-NUM):** 원문의 *p* = 0.000은 영 확률로 해석하지 않고 *p* < .001로 표시했다. 정확한 *p*는 반올림 전 분석 출력으로 확인해야 한다.
- **APA 규정(Manual 6.44)·공식 안내(A-NUM):** *M*·*SD*의 뜻풀이를 삭제하고 통계 기호를 기울임꼴로 표시했다. 신뢰구간은 뜻을 풀어 적되 구간의 종류·수준·끝값은 유지했다.
- **APA 규정(Manual 7.5):** 위치가 바뀌면 모호해지는 ‘위의 표’를 ‘표 1’로 바꿨다.
- **편집 판단:** ‘표 1의 계수를 본문에 다시 나열하면’이라는 작성 과정 설명을 결과 진술로 바꿨다. 표 원문이 없어 *b*와 *SE*가 완전히 중복되는지 확인할 수 없으므로 두 수치는 본문에 남겼다.

# 확인 요청과 대안

- **확인 요청:** 반올림 전 *p* 값과 표 1의 수치를 분석 출력과 대조해 주세요. 원출력이 `0.000`으로 표시된 것인지 확인해야 *p* < .001 표기를 확정할 수 있습니다.
- **편집 판단에 따른 대안:** 표 1에 *b*와 *SE*가 같은 값으로 제시되어 본문 중복이 확인되면, 마지막 문장을 ‘표 1에 1단계 모형의 계수를 제시한다.’로 줄일 수 있습니다. 이때 표의 *b* = 0.31과 *SE* = 0.08은 유지해야 합니다.
