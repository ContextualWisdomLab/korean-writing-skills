## 원문 문장별 교정문 본문 대응

| 원문 | 교정문 본문 대응 | 판정 |
| --- | --- | --- |
| “본 연구는 저자의 석사학위논문(2022, 31–33쪽)에서 사용한 자료를 활용하였다.” | “이 연구는 저자의 2022년 석사학위논문에서 사용한 자료를 사용한다.” | 변경·보존. 이전 논문의 자료라는 출처와 연도는 남기고, 저자 요구에 따라 쪽수를 빼고 현재형으로 바꿨다. |
| “본 연구에서는 수면 시간과 과제 정확도의 관계를 위계적 회귀분석으로 검토하였다.” | “수면 시간과 과제 정확도의 관계를 위계적 회귀분석으로 검토한다.” | 변경·보존. 대상, 관계, 분석법을 유지하고 현재형으로 바꿨다. |
| “자료는 2021년 10월에 온라인 설문으로 수집되었다.” | 동일한 문장 | 보존. 시점·방법·과거 시제를 유지했다. |
| “수면 시간과 과제 정확도의 상관은 r = 0.42, p = 0.000이었다(N = 156).” | “수면 시간과 과제 정확도의 상관계수는 *r* = .42였다(*p* < .001, *N* = 156).” | 변경·보존. 상관, 수치, 표본 수를 유지했다. *p*의 정확한 값은 본문에서 확정하지 않고 확인 요청에도 남겼다. |
| “평균 수면 시간은 M = 6.8시간(SD = 1.1)이었으며, 여기서 M은 평균, SD는 표준편차를 뜻한다.” | “평균 수면 시간은 *M* = 6.8시간(*SD* = 1.1시간)이었다.” | 변경·보존. 평균과 표준편차 값은 유지하고 통계 기호 정의를 삭제했다. *SD*에 시간 단위를 명시했다. |
| “위의 표와 같이 1단계 모형의 설명력은 R² = .18이었고 95% CI [.07, .29]였다.” | “표 1에 제시한 1단계 모형의 설명력은 *R*² = .18(95% 신뢰구간[.07, .29])이었다.” | 변경·보존. 입력에 있는 표 1을 지시하고 모형 단계·설명력·구간 수준·끝값을 유지했다. CI를 첫 사용에서 풀었다. |
| “표 1의 계수를 본문에 다시 나열하면 b = 0.31, SE = 0.08이다.” | “표 1의 계수는 *b* = 0.31, *SE* = 0.08이다.” | 변경·보존. 계수와 값은 본문에 남겼다. 표의 실제 중복 여부는 확인 요청과 대안으로만 이동했으므로 그 대안은 본문 보존 근거로 세지 않는다. |

위 표의 상대경로는 모두 출력에 적힌 `` 이하의 경로다. 자기보고상 목록 밖 경로는 없다. 출력 파일은 열람 목록에 없고, 허용 목록에서도 쓰기 전용이다. 본문에는 0.42, 156, 6.8, 1.1, .18, .07, .29, 0.31, 0.08, 2021년 10월이 값 변경 없이 남았다. 확인 요청·대안만으로 보존을 인정한 앵커는 없다.

## A. 통계 표기

| 점검 지점 | 출력 확인 | 근거 종류 |
| --- | --- | --- |
| `r = 0.42` | `*r* = .42`: 선행 0만 생략 | APA 규정, Manual 6.36 |
| `p = 0.000` | `*p* < .001`로 쓰고 반올림 전 출력 확인을 요청함. 정확한 *p*를 만들지 않음 | APA 규정 6.36·공식 안내 A-NUM |
| `R² = .18` | `.18` 유지 | APA 규정, Manual 6.36 |
| `b = 0.31`, `SE = 0.08`, `M = 6.8`, `SD = 1.1` | 값과 필요한 선행 0 유지. *SD*의 단위는 시간으로 명시 | APA 규정, Manual 6.36 |
| *M*·*SD* 정의 문구 | 본문에서 삭제 | APA 규정, Manual 6.44 |
| `95% CI` | `95% 신뢰구간`으로 첫 사용을 풀고 끝값 유지 | APA 공식 안내, A-NUM |
| `위의 표와 같이` | 입력에 이미 있는 `표 1`로 지시 | APA 규정, Manual 7.5 |
| 표·본문 중복 | 본문에 계수를 유지하고, 표 원문이 없어 중복 여부를 확인 요청함 | APA 공식 안내, A-NUM; 중복 여부는 미확인 |

통계 기호의 기울임꼴과 표 서식은 사전 기준에서 채점 제외로 정한 항목이다.

## B. 첫 투고 방법 문단

| 점검 지점 | 출력 확인 | 근거 종류 |
| --- | --- | --- |
| 연구의 결정·분석을 현재형 자기 서술로 | `자료를 사용한다`, `관계를 … 검토한다` | 저자 요구 |
| 학위논문 쪽수 제외 | `31–33쪽`을 교정문 본문에서 삭제 | 저자 요구 |
| 이전 자료의 출처 | `저자의 2022년 석사학위논문에서 사용한 자료` 유지 | 저자 요구에 따른 편집 판단 |
| 완료된 수집의 과거형 | `2021년 10월에 … 수집되었다` 유지 | 편집 판단 |
| 근거 범위 | 출력의 변경 이유에서 현재형과 쪽수 처리를 저자 요구로 분류 | 저자 요구. APA 규정으로 주장하지 않음 |

## C. 공통 중대 오류

없는 결과·검정·수치, 표본 특성·IRB·학술지 정보가 추가되지 않았다. “상관”을 인과로 강화하지 않았고, 입력의 계수·구간·표본 수를 바꾸지 않았다. 확인된 중대 오류는 없다.

## 세 축 점수와 근거

| 축 | 점수 | 원문과 출력의 짧은 대조 |
| --- | --- | --- |
| 의미 보존 | **3/3** | “2021년 10월에 … 수집되었다”를 그대로 두고, “위계적 회귀분석”과 `*b* = 0.31, *SE* = 0.08`도 유지했다. `p = 0.000`의 정확한 확률을 만들어 넣지 않았다. |
| 한국어 자연스러움 | **3/3** | “위의 표와 같이”를 “표 1에 제시한”으로 바꿔 지시 대상을 분명히 했다. “여기서 M은 …”의 불필요한 정의를 덜어 두 문단이 읽기 쉽게 이어진다. |
| 과잉 교정 억제 | **3/3** | 완료된 수집의 “수집되었다”와 분석명은 유지했다. 현재형·쪽수 처리를 저자 요구로, 표 중복 가능성은 편집 판단과 확인 요청으로 분리했다. |

| 항목 | 판정과 이유 |

| M1 의미·증거 보존 | 적합. 문장 대응표의 출처, 시점, 분석, 통계 앵커가 본문에 남았고 정확한 *p*는 미확정으로 처리했다. |

| G1 표기 | 적합. 판독을 방해하는 맞춤법·띄어쓰기·문장 부호 오류는 확인되지 않았다. |

## 판정

**통과.** 세 축이 각각 2점 이상이고 중대 오류가 없다. 실행자 접근 범위도 자기보고상 허용 목록 안이다. 합산·평균은 적용하지 않았다.

## 개선 권고
