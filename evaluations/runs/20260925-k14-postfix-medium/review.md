# K14 같은 사례·같은 추론 강도 재현 (2026-09-25)

## 해석과 한계

- 같은 사례·같은 모델·같은 추론 강도에서 수정 전 실패와 수정 후 통과가 나왔다. 남은 설정 차이는 CLI 판과 실행 호스트다(설치 금지라 맞추지 않았다).
- 판본마다 실행 수가 적다(수정 전 1회, 수정 후 2회). 수정 전 판본의 실패율도, 수정 후 판본의 통과율도 추정하지 못한다. K15에서는 수정 전 판본도 통과했다.
- 배정자·입력·판정표 작성자가 같은 리드다. 접근 준수는 자기보고와 세션 기록의 명령으로 확인했다.

## 평가 뒤 스킬 변경
