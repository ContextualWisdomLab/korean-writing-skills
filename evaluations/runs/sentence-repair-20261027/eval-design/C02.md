# C02

의미와 문체를 보존하며 필요한 만큼만 다듬어 주세요. 각 항목은 독립적이며, 문맥은 해석 참고용이고 교정 대상은 대상문 하나입니다. 항목 번호별로 처리 결과를 먼저 제시하고, 필요하면 짧은 이유나 확인 사항을 덧붙이세요. 뜻이 분명한 비문은 실제로 고친 문장을 제시하고, 정상적인 표현은 유지하세요. 뜻이 실제로 갈리거나 정보가 부족하면 그 부분을 보류하고 확인할 점을 밝혀 주세요.

## C02-01
- 문맥: 완료된 두 업무 = 장비 상태 점검 / 이용자 문의 응답; 두 업무의 담당 = 시설팀
> 대상문: 시설팀은 장비 상태와 이용자 문의에 답했다.

## C02-02
- 문맥: 완결된 서술문을 쓰는 작업일지; 작업 내용 = 안내판의 로비 벽 고정; 작업 상태 = 완료
> 대상문: 보수팀은 안내판을 나사 세 개로 로비 벽에.

## C02-03
- 문맥: 시연 발언을 전달하는 기사; 따옴표 안 = 시연자의 직접 인용
> 대상문: 시연자의 설명은 “센서를 바꾸면 오차가 절반으로 줄 수도 있다”라고 말했다.

## C02-04
- 문맥: 시설 관리 보고; 보관 행위자 = 기재되지 않음
> 대상문: 반납된 출입증은 점검 뒤 보안실에 보관되었다.
