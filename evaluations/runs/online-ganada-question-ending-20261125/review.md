# 대화의 생략 의문 표현 진단 설계 (미실행)

- **근거 상담**: N-Q41, [국립국어원 온라인가나다 338882 「[재질문] ~건? ~는? 라고 끝내는 게 지양해야되는 표현인가요?」](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=201&pageIndex=1&qna_seq=338882). 원질문일 2026-11-22, 상세 화면의 재질문 등록일 2026-11-25, 원질문 답변일 2026-11-23. 재질문 자체의 별도 작성일·답변일은 미표시.
- **직접 확인 범위**: 질문·원답변·재질문 전체(상세 174–185행). 최초 직접 확인일·이번 확인일 2026-11-25 17:09 KST.
- **답변 범위와 한계**: 답변은 2006년 자료집과 ‘다듬은 말 정보’를 살펴봤으나 관련 근거를 찾지 못했다고 밝히며, 제시된 대화 예를 일본어투에서 비롯됐다고 단정하기 어렵고 반드시 ‘어때?’를 덧붙일 필요도 없다고 설명한다. 이 회차에서 답변이 언급한 두 자료의 원문은 별도로 읽지 않았다. 개별 상담을 보편적인 문법 규칙으로 확대하지 않는다.
- **입력**: evaluations/scenarios/blind-inputs.md의 N-20261125-question-ending(QE1). 직접 작성한 진단 입력이며 질문 전문을 복제하지 않는다.

## 실행 계약과 한계

- 실행자는 사례마다 새 context에서 요청·입력·최종 스킬 및 필요한 참고 파일만 받는다. 이 기준과 기대 행동은 제공하지 않는다.
- 별도 채점자는 원문과 실제 출력만 대조해 기대 행동·실패 조건을 판정한다. 작성자의 자체 점검이나 CodeRabbit의 문서 리뷰를 독립 행동 평가로 대체하지 않는다.
- 지침·출처 장부에 핵심 판단이 노출되므로 이 과제는 **진단용**이다. 독립 성공 점수·일반 성능 향상·전체 타당화 증거로 사용하지 않는다.
