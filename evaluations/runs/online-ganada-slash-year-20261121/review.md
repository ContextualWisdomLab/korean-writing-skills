# N-Q25 ‘/연’·‘/년’ 적용 범위 — 진단 과제 설계 (미실행)

- 근거: [온라인가나다 338682 「빗금(/) 뒤 연, 년의 사용」](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=201&pageIndex=1&qna_seq=338682). 질문 2026-11-19, 답변 2026-11-20, 최초·이번 직접 확인 2026-11-21. 질문·답변 본문 전체를 읽었다. 사전·규범에 명시된 보편 규정이 없다는 점, ‘한 해당’이라는 문맥에서 ‘/연’이 **좀 더 적절해 보인다**는 답변의 강도, 분야별 별도 표기 기준 확인을 모두 보존한다.
- 담당 입력: [평가용 시나리오](../../scenarios/blind-inputs.md)의 `N-20261121-slash-year` Y1~Y3. 이 문서는 **평가자·기록용 기준**이며 입력 전달자에게 제공하지 않는다. 세 문장 모두 작성자가 직접 만든 가상 문장이다.
- 동결 판정 기준: **Y1** 분야별 단위 표기 기준을 확인하지 못했으므로 **본문의 `/년`을 그대로 유지**하고 기준을 확인할 사항으로 남긴다. 기준이 없다는 사실을 확인하기 전에 본문을 `/연`으로 바꾸면, 변경 사실을 명시하거나 확인 필요성을 함께 설명하더라도 **실패**로 판정한다. ‘한 해당’의 의미를 확인하고 해당 분야 기준이 없다는 점까지 확인된 경우에만, **본문 수정과 분리된 조건부 제안**으로 `/연`을 제시할 수 있다. `/년` 자체를 보편적인 맞춤법 오류로 단정하지 않는다. **Y2** 계약서에서 이미 승인된 단위 표기를 임의 수정하지 않는다. **Y3** 문맥과 숫자·금액을 보존하고 `/연`을 확정 오류로 고치지 않는다. 다른 허용 여부를 추정하지 않는다.
- 별도 평가자가 확인할 항목: 뜻·숫자·계약조건·불확실성 보존, 상담의 조건부 강도를 유지했는지, 일괄 교정과 의미 변조가 있는지. 기존 고정 과제나 기존 점수를 소급 수정하지 않는다.
- 현재 상태: **평가 설계만 작성**, 실행 결과·채점·평가자 승인·품질 향상 증거 없음. 실제 실행 전에 시나리오·스킬·제공 문서·본 기준의 파일별 SHA-256을 기록한 다음 입력 제공자를 분리하고 출력·독립 채점 기록을 추가한다. 새 head 전체 Python 3.14 uv locked 검사와 실제 제출 리뷰도 별도로 필요하다.
