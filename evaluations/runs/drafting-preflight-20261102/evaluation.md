# Drafting preflight evaluation

## Scope

This is a five-case drafting-prevention evaluation of the Korean editing skill. It is separate from the earlier repair cases and does not establish whole-skill validity, general effectiveness, or real-team performance.

The cases test five application limits:

- D1: correlation versus causation and uncertainty
- D2: completed execution versus unretrieved result versus absence of failure
- D3: terminology, symbols, and deliberate role collisions
- D4: register and list parallelism without changing status or counts
- D5: meaning-based common-error correction and contextual ambiguity

## Blind execution boundary

Each executor received one case only and the current Korean editing skill with references as needed. The executor did not receive this rubric, expected answers, or another case. The parent recorded the returned text after all five executions completed. This record does not provide OS-level isolation or prove that an executor never accessed other context; it records the instructed scope and returned artifacts.

## Overall observation

- 4 cases pass within the stated case limits.
- D3 exposes a real remaining failure mode: a fluent academic draft can add statistical significance not present in the notes.
- This evaluation does not justify claiming full normative coverage or real-world effectiveness.
- The next improvement should add a “do not add statistical significance” guard to the drafting checklist and a regression contract for omitted p values, confidence intervals, and test decisions.
