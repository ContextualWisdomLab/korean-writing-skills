# 7회차 — K11·K12 blind 재평가 (2026-09-25)

## 왜 다시 했나

[6회차](../20260924-round6/review.md)는 같은 리드가 스킬과 판정표를 고친 직후, 리드와 같은 모델을 상속한 에이전트로 실행·채점했다. 코디네이터는 이를 독립 수용 근거로 보지 않았다. 7회차는 6회차의 동결 파일과 지시문을 그대로 둔 채 실행자·채점자만 바꿔 한 번 더 실행했다.

## 6회차와 같은 것

- 동결 20개 파일(두 스킬, 프로토콜, 시나리오, 루브릭 2개, [판정표](../20260924-round6/criteria.md), [실행자 지시문](../20260924-round6/executor-prompt.md), [채점자 지시문](../20260924-round6/scorer-prompt.md), 입력 2개). 동결 커밋 직전과 두 사례를 마친 뒤에 모두 다시 계산해 20개 모두 일치했다.
- 지시문은 사례 이름과 경로만 치환해 그대로 전달했다. 문장을 더하거나 빼지 않았다.

## 6회차와 다른 것

- 실행자·채점자 모델: Agent 도구의 모델 재정의로 sonnet을 썼다. 5·6회차는 리드 세션 모델(opus 계열)을 상속했다.
- 격리 디렉터리: 이전 회차 산출물이 없는 새 디렉터리에 입력 2개만 두었다.
- 에이전트에게 이전 회차의 존재·점수·스킬 수정 이력을 알리지 않았다.
- 동결 커밋 `61de212110415c194dca0865f47948737e65d87b`(push 2026-09-24T17:22:19Z) 뒤에 실행했고, 이 기록 전까지 다른 커밋은 없었다. 동결 내용은 [freeze.json](freeze.json)에 있다.

### K12 — 의미 보존 2점

원문 셋째 문장(“E는 R에 영향을 주는 것으로 보인다”)의 인과 시사를 교정문에서 그대로 두었고, 저자 확인 사항으로도 명시적으로 넘기지 않았다. 판정표는 이 처리를 중대 오류가 아닌 감점 사유로 정해 두었으므로 통과는 유지된다. 6회차 K12(3점)와 결과가 다른 지점이다.

### 비교에서 관찰한 것

- 두 실행자 모두 `apa7-manuscript-writing` 스킬을 열지 않았다. K11의 첫 투고 원고 지침과 K12의 척도 이름 지침은 두 스킬에 모두 있으므로 판단 근거는 `korean-editing` 쪽 문장이었다.
- K12에서 인과 시사 문장을 다루는 방식이 모델에 따라 달랐다. 현재 스킬은 인과 시사 문장을 어떻게 처리하라고 직접 말하지 않는다. 사례 한 건의 차이이므로 이번에는 스킬 문구를 바꾸지 않고 후보로만 남긴다.

## 한계

- **배정자는 여전히 같은 리드다.** 실행자·채점자는 바뀌었지만 이들을 배정하고 지시문을 전달한 사람은 5·6회차와 같다. 다른 사람이 배정한 독립 평가가 아니다.
- **완전한 blind가 아니다.** 허용 목록의 스킬 파일(`validation.md`·`source-ledger.md`)에 과거 평가 서술이 있다. 이번 실행자들은 자기보고상 그 파일을 열지 않았다.
- **접근 이행은 자기보고 기반이다.** 강제 격리나 감사 로그가 없다.
- 사례마다 한 번씩 실행했다. 채점자 간 일치도와 재현성은 측정하지 않았다. 6·7회차 점수 차이(K12)는 모델 차이인지 한 번 실행의 변동인지 구분할 수 없다.
- 입력은 리드가 만든 가상 예문이고 판정표도 리드가 썼다. 특정 연구의 기호 매핑이나 참여자 자료를 쓰지 않았다.
- 실행자·채점자 식별자와 격리 경로는 비공개 운영 기록에 두었다. 출력·채점 파일의 로컬 절대경로는 “(격리 임시 디렉터리)”로 바꾸었고, 산출 당시 해시와 커밋된 파일 해시는 [output-hashes.json](output-hashes.json)에 있다.
