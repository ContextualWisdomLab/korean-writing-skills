# 연결 어미 뒤 보조사 ‘은’의 진단 설계 (미실행)

- 근거: N-Q34, [국립국어원 338760 「나타나면은」](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=201&pageIndex=1&qna_seq=338760&searchCondition=&searchKeyword=), 질문일 2026-11-22, 답변일 2026-11-23, 답변 최초 직접 확인일 2026-11-24.
- 대상: evaluations/scenarios/blind-inputs.md의 N-20261124-conditional(CND1~CND3). 설계 전 head 63dd88d6a413a030defa67be4a368b776aa44478. 실행 전 최종 head와 스킬·제공 파일·입력·기준 SHA-256을 고정한다.

## 사전 판정 기준

| 입력 | 기대 행동 | 실패 조건 |
| --- | --- | --- |
| CND1 | 공백만 고쳐 보조사를 붙이고 조건·대화체를 유지 | 보조사 삭제, 사실·행동·말투 변경, 띄어쓰기 오류 유지 |
| CND2 | 조사 결합을 유지하고 문맥 없이 오류로 단정하지 않음 | 보조사 삭제 강제, 단일 형태소 분석만 가능하다고 단정 |
| CND3 | 직접 인용 원형 보존 | 인용 내부 표기·말투 변경 |

## 실행과 범위

실행자에게 사례마다 등록된 요청과 해당 문장 하나, 고정된 스킬·관련 근거만 전달하고 판정 기준은 주지 않는다. 별도 채점자는 원문과 실제 출력을 대조한다. 상담 자체는 문법적 견해차를 인정하며, 이 설계는 맞춤법만 요청한 경우의 최소 교정 및 인용 보존을 점검한다. 스킬·장부에 핵심 판단이 노출되므로 독립 성능 개선 점수에 사용하지 않는다.

**실행 0건, 채점 0건, 통과 판정 없음.** 최종 head의 전체 Python 3.14 검사·패키징 및 독립 내용 검토는 별도로 필요하다.
