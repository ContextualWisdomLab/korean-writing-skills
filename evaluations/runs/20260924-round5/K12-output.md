# K12 교정 결과

적용 스킬: `apa7-manuscript-writing`(학술 결과 문단, 척도 이름·통계 표기·관련성과 인과 구분)과 `korean-editing`(의미 앵커, 문장 호응, 추정 표지 보존). 결과 문단 하나의 문장만 다듬어 달라는 요청이라 문단 구조는 바꾸지 않았다.

## 교정문

정서 반응성 척도(E) 점수가 높을수록 반추 척도(R) 점수도 높았다(*r* = .31, *N* = 212). E는 R에 영향을 주는 것으로 보인다.

## 의미 앵커 대조

| 항목 | 원문 | 교정문 |
| --- | --- | --- |
| 대상 | E, R | 정서 반응성 척도(E), 반추 척도(R). 요청에 적힌 정식 이름 |
| 방향 | E가 높을수록 R도 높음 | 같음 |
| 수치 | r = .31, N = 212 | *r* = .31, *N* = 212 (값 그대로) |
| 추정 표지 | ~것으로 보인다 | 같음 |
| 인과 주장 | E → R 영향(추정) | 같음(아래 확인 요청 참고) |

## 주요 변경과 이유

1. `E가` → `정서 반응성 척도(E) 점수가`, `R도` → `반추 척도(R) 점수도`: 척도는 처음 나올 때 확인된 이름과 기호를 함께 정의한다는 스킬 지침을 따랐다. 요청이 정식 이름을 알려 주었다. 척도가 높아지는 것이 아니라 점수가 높은 것이므로 주어·서술어가 맞도록 `점수`를 넣었다.
2. 두 문장(방향 진술과 상관 진술)을 한 문장으로 합치고 수치를 괄호에 넣음: 두 문장이 같은 관련성을 두 번 말하고 있어서 방향 진술 뒤에 근거 수치를 붙였다. `r = .31`과 `N = 212`의 값과 대응(전체 표본 N)은 바꾸지 않았다.
3. `r`, `N`을 기울임으로 표기: 통계 기호 라틴 문자는 기울인다(A-NUM). `.31`의 선행 0 생략은 1을 넘을 수 없는 통계량이라 그대로 두었다(Manual 6.36). *r*·*N*은 정의하지 않는 통계 기호라 풀이를 붙이지 않았다(Manual 6.44).
4. 두 번째 문장부터는 기호 `E`·`R`만 썼다. 바로 앞에서 정의했으므로 짧은 문단에서는 독자가 이름을 알 수 있다고 판단했다.

## 고치지 않은 부분과 이유

- `E는 R에 영향을 주는 것으로 보인다.`: 원문 그대로 두었다. 저자의 해석이고 `~것으로 보인다`라는 추정 표지가 있다. 편집자가 이 주장을 지우거나 약화하면 저자의 주장 강도가 바뀌고, 확정형으로 바꾸면 추정이 사실이 된다. 다만 인과 해석 문제가 있어 아래 확인 요청 1로 남기고 대안을 제안했다.
- `높을수록 … 높았다`: 원문의 방향 진술을 유지했다. `정적 상관을 보였다`로 바꾸는 것도 가능하지만 뜻이 같아 바꿀 이유가 없다.

## 제안만 하는 대안(적용하지 않음)

- 인과 문장 대안(결과 절에 둘 경우): `이 상관 결과만으로는 E가 R에 영향을 준다고 판단할 수 없다.`
- 인과 문장 대안(해석을 유지하되 논의 절로 옮길 경우): `이 관련성은 정서 반응성이 반추에 영향을 줄 가능성과 부합하지만, 상관 자료로 인과 방향을 확인할 수는 없다.`

## 저자 확인 요청

1. **인과 해석**: 제시된 근거는 상관(*r* = .31)뿐이다. 관찰된 관련성을 인과 효과로 쓰지 않는다는 점검(apa7 스킬의 논의 점검표)에 걸린다. 연구 설계(횡단·종단·실험 여부)를 알려 주면 이 문장을 유지할지, 위 대안 가운데 하나로 바꿀지, 논의 절로 옮길지 정할 수 있다. 결과 절에 해석 문장을 두는 것이 투고 학술지 관행에 맞는지도 확인이 필요하다.
2. **점수 방향**: `점수가 높을수록`은 점수가 높을수록 정서 반응성·반추가 강하다는 채점 방향을 전제한다. 역채점 여부와 점수 방향을 채점표에서 확인해 달라.
3. **상관의 종류와 불확실성**: 피어슨 상관인지, *p* 값이나 신뢰구간을 보고했는지 원문에 없다. 교정문에 추가하지 않았다. 보고한다면 분석 산출물의 값을 알려 달라. [확인 필요: 상관 종류, *p*, 95% CI]
4. **분석 표본**: *N* = 212가 이 상관 분석에 실제로 들어간 사례 수인지(결측 제외 뒤의 수인지) 확인해 달라.
5. **기호 사용**: 원고 다른 곳에서 척도 이름을 이미 정의했다면 첫 정의 위치에 맞추어 이 문단의 괄호 정의를 뺄 수 있다. 영문 약어(예: 원척도 약어)를 쓰는지도 알려 달라. 편집자가 임의로 만들지 않았다.
