# K9 교정 결과

적용 스킬: `korean-editing` (짧은 운영 보고 + 표·목록 보고 경로). 학술 원고가 아닌 주간 상태 보고이므로 `apa7-manuscript-writing`은 적용하지 않았다.

## 교정문

이번 주 점검 결과입니다. 자세한 값은 아래 표 1에 정리했습니다.

표 1

부서별 점검 결과

| 구분 | 오류 | 담당 |
| --- | --- | --- |
| 로그인 | 2 건 | 미지정 |
| 결제 | 0 | 김 |
| 알림 | 확인 못 함 | 미지정 |

## 주요 변경과 이유

- `아래 표에` → `아래 표 1에`: 본문과 표 번호를 이어 독자가 어느 표를 보면 되는지 분명히 했다(편집 판단).
- `두었습니다` → `정리했습니다`: 표 제목 줄에서 뺀 서술어 `정리하였다`의 내용을 이 문장으로 옮겨 정보가 빠지지 않게 했다. 행위자·시점은 바꾸지 않았다(편집 판단).
- 표 제목 `부서별 점검 결과를 정리하였다.` → `부서별 점검 결과`: 표 제목 자리에 서술문이 들어가 본문의 `-습니다`체와 `-하였다`체가 섞였다. 제목을 명사구로 줄여 문체 충돌을 없앴다. `부서별`이라는 범위 표현은 그대로 두었다(편집 판단).

## 고치지 않은 부분과 이유

- 표의 모든 셀(`2 건`, `0`, `확인 못 함`, `미지정`, `김`): 요청에 따라 값과 담당 표기를 바꾸지 않았다.
  - `2 건`: 단위 명사를 띄운 형태로, 한글 맞춤법 제43항의 원칙에 맞다(`2건`으로 붙이는 것도 허용되지만 고칠 필요는 없다, N43).
  - `0`: `2 건`과 달리 단위가 없지만, 값 셀이라 단위를 붙이지 않았다.
  - `확인 못 함`: 오류 0건과 뜻이 다르다(점검 결과를 확인하지 못함). `0`이나 `없음`으로 바꾸면 사실이 달라지므로 그대로 두었다.
  - `김`, `미지정`: 원문에 없는 전체 이름이나 담당자를 만들지 않았다.
- `이번 주 점검 결과입니다.`: 호응과 표기에 문제가 없어 그대로 두었다.
- 표 아래 요약 문장(예: 알림 미확인, 담당 미지정 2행)은 원문에 없어 추가하지 않았다.

## 확인 필요

- 표 제목의 `부서별`과 `구분` 열의 값(로그인·결제·알림)이 맞는지 확인이 필요하다. 행의 값은 부서명보다 기능·서비스 이름으로 읽힌다. 실제 기준을 원문에서 알 수 없어 `기능별` 등으로 바꾸지 않고 원문 표현을 유지했다.
- `오류` 열의 `0`에 `건`을 붙여 `2 건`과 맞출지는 작성자가 정할 사항이다(요청상 값 변경 금지).
