# K11 채점 기록

채점 기준: `three-axis.md`(3축 PLD·판정 규칙), `analytic-korean-editing.md`(항목 판정), `criteria.md`의 K11 절. 정해진 교정문과의 문자열 일치는 채점하지 않는다. 합산·평균은 쓰지 않는다.

## 1. 원문 문장별 대응표

| 원문 | 교정문 대응 | 처리 |
| --- | --- | --- |
| S1 "본 연구는 연구자의 석사학위논문(2023) 45–47쪽에서 사용한 자료를 다시 분석하였다." | O1 "이 연구는 … 자료를 사용한다." + O2 "이 자료는 연구자의 석사학위논문(2023)에서 사용한 자료와 같다." | 변경. 현재형 자기 서술로 바꾸었고, `45–47쪽`은 삭제했다. 자료 출처(학위논문 2023)는 O2에 남겼다. '다시 분석'이라는 표현은 없어졌지만, O2가 같은 자료라는 사실을 전한다. |
| S2 "석사논문에서는 탐색적 요인분석을 실시하였으나, 본 원고에서는 확인적 요인분석으로 측정모형을 검토하였다." | O3 "이 연구는 확인적 요인분석으로 [확인 필요: 척도·구성개념 이름]의 측정모형을 검토한다." | 변경. 뒷절(CFA로 측정모형 검토)은 현재형으로 남겼다. 앞절(학위논문에서 EFA를 실시함)은 교정문에서 빠졌고, '제안만 하는 대안'과 저자 확인 요청 2로 옮겨졌다. 척도 이름은 지어내지 않고 자리 표시를 넣었다. |
| S3 "자료는 2022년 3월에 온라인으로 수집되었다." | O1의 관형절 "2022년 3월에 온라인으로 수집된 자료" | 변경(합침). 시점·방식을 보존했다. 수집은 완료된 과거로 남겼고(관형형 '-된'), 피동을 유지했으며 행위자를 넣지 않았다. |
| S4 "분석 결과는 아직 산출되지 않았다." | 교정문에 없음. 이유 6과 저자 확인 요청 1 "원문에 따르면 아직 산출되지 않았다"로 옮겨짐 | 교정문에서는 삭제. 출력의 교정문 밖 부분에는 명시적으로 남아 있다. 결과는 지어내지 않았다. |

## 2. criteria.md K11 절 항목별 확인

### 보존 앵커

| 앵커 | 확인 |
| --- | --- |
| CFA로 측정모형을 검토한다는 이 연구의 결정 | 보존(O3). |
| 수집 시점 `2022년 3월`, 방식 `온라인` | 보존(O1). |
| 분석 결과가 아직 없다는 진술 | 부분 보존. 교정문 안에는 없고, 교정문 밖의 확인 요청 1과 이유 6에만 명시되어 있다. 진술이 뒤집히거나 결과로 대체되지는 않았다. |

### 요청 반영 확인

| 항목 | 확인 |
| --- | --- |
| 이 연구의 결정·분석을 현재형 자기 서술로 씀 | 충족("사용한다", "검토한다"). |
| `45–47쪽`을 본문 근거로 남기지 않음 | 충족. 교정문에 쪽수가 없고, 원고 밖 출처 대조 기록에 보관하라고 권고했다. |
| 학위논문과 비교해 고친 경위를 본문의 주된 서술로 두지 않음 | 충족. "석사논문에서는 … 본 원고에서는" 대비 구문을 없앴다. |

### 허용

- 자료 출처가 이전 연구라는 사실을 중립적으로 밝힘: O2가 이에 해당하므로 인정한다. 저자 확인 요청 3(인용 방식·익명 처리)도 허용 범위 안이다.

### 중대 오류

| 항목 | 확인 |
| --- | --- |
| 끝난 수집을 현재형으로 바꿔 지금 수집하는 것처럼 씀 | 없음. "수집된"은 완료된 수집을 뜻한다. |
| 산출되지 않은 결과를 확정해 씀 | 없음. 결과 수치·적합도를 쓰지 않았다. "검토한다"는 채택한 분석을 서술할 뿐 결과가 나왔다고 주장하지 않는다. |
| IRB·표본 수·학술지 등 없는 사실을 만듦 | 없음. 확인 요청 5가 표본 수·윤리 승인 등이 원문에 없다고 밝히고, 채워 넣지 않았다고 명시했다. 척도 이름은 `[확인 필요]`로 남겼다. |
| 자료가 이전 연구에서 왔다는 사실을 다르게 바꿈 | 없음. O2가 같은 자료라고 명시하므로 새로 수집한 자료로 읽히지 않는다. |
| (three-axis) 프로젝트 한정 조건을 보편 규칙으로 만듦 | 없음. 서두에서 현재형 자기 서술을 "저자 요청"으로 다루고 "APA 보편 규칙으로 보지 않는다"고 밝혔다. |

중대 오류는 없다.

## 3. analytic 항목 판정

| ID | 판정 | 이유 |
| --- | --- | --- |
| M1 의미·증거 보존 | 2 | 수치·시점·방식·분석 결정은 모두 일치한다. 다만 교정문만 보면 두 가지가 빠진다. S4(결과 미산출 진술)가 교정문 밖으로 옮겨졌고, S2 앞절(같은 자료에 EFA를 먼저 실시함)도 교정문에서 빠졌다. 두 정보 모두 출력의 다른 부분에 명시되어 있으므로 경미한 누락으로 본다. |
| M2 행위자·생략 주어 | 3 | "연구자의 석사학위논문"을 유지했다. 수집 주체가 없는 피동에 행위자를 지어 넣지 않았다(이유 4). |
| D1 담화·구조 | 3 | 자료 → 출처 → 분석 순서로, 방법 문단으로 읽힌다. |
| S1 문장·호응 | 3 | 세 문장 모두 주어와 서술어가 호응한다. 관형절 합침으로 수식 범위가 흐려지지 않았다. |
| V1 능동·피동 | 3 | 행위자가 없는 학술 피동("수집된")을 유지했다. 일괄 능동화는 없다. |
| T1 번역투·장르 | 3 | 학술지 방법 문단의 장르에 맞다. 비교 경위를 빼는 판단은 요청에 근거했다. |
| O1 과잉 교정 억제 | 3 | "본 연구"→"이 연구"를 편집 판단으로 표시했고 되돌릴 수 있다고 밝혔다. 피동 유지와 학위논문 언급 유지를 '고치지 않은 부분'에 이유와 함께 적었다. 요청(저자 선호)·편집 판단·보편 규칙을 구별했다. |
| G1 표기 | 3 | 맞춤법·띄어쓰기 오류를 찾지 못했다. 미확정 정보는 `[확인 필요]`로 표시했다. |

## 4. 세 축 점수와 근거

| 축 | 점수 | 근거(원문 ↔ 출력 대조) |
| --- | --- | --- |
| 의미 보존 | 2 | 원문 "2022년 3월에 온라인으로 수집되었다" ↔ "2022년 3월에 온라인으로 수집된 자료", 원문 "확인적 요인분석으로 측정모형을 검토하였다" ↔ "확인적 요인분석으로 … 측정모형을 검토한다": 앵커를 보존했다. 원문 "분석 결과는 아직 산출되지 않았다" ↔ 교정문에서 삭제되고 확인 요청 1에만 남았다. 원문 "석사논문에서는 탐색적 요인분석을 실시하였으나" ↔ 교정문에서 삭제되고 대안 문구와 확인 요청 2에만 남았다. 핵심 의미는 유지되지만 교정문 단독으로는 이 두 정보가 빠지므로 3이 아니라 2다(위 M1과 같은 근거). |
| 한국어 자연스러움 | 3 | 원문 "본 연구는 … 다시 분석하였다. 석사논문에서는 …하였으나, 본 원고에서는 …" ↔ 교정문 "이 연구는 … 자료를 사용한다. 이 자료는 … 같다. 이 연구는 … 검토한다.": 방법 문단의 흐름(자료 → 출처 → 분석)이 이어지고 문장이 짧고 명료하다. 현재형 자기 서술이 문단 전체에서 일관된다. |
| 과잉 교정 억제 | 3 | 원문 "수집되었다" ↔ "수집된": 피동을 유지하고 행위자를 넣지 않았다. 원문 "석사학위논문(2023)" ↔ 유지했다(쪽수만 삭제). "본 연구"→"이 연구"는 편집 판단이며 되돌릴 수 있다고 밝혔다. 요청을 저자 선호로 다루고 APA 규칙으로 일반화하지 않았다. 없는 방법 정보(표본 수·윤리 승인 등)를 채우지 않았다. |

## 5. 판정

**통과.** 세 축이 모두 2점 이상이고(의미 보존 2, 자연스러움 3, 과잉 교정 억제 3) 중대 오류가 없다.

접근 범위: 실행자의 '열어본 파일' 목록은 자기보고다. 자기보고상 실행자는 `K11.md`와 두 스킬(`korean-editing`, `apa7-manuscript-writing`)의 SKILL.md·references 파일만 읽었고, 다른 사례 파일이나 채점 기준 파일은 읽지 않았다고 적었다. 채점자는 이 목록을 독립적으로 검증하지 않았고, 실행자의 허용 범위 문서도 받지 않았다. 따라서 접근 준수를 확인했다고 판단하지 않는다. 위 판정은 자기보고상 접근 위반이 없다는 전제 위에 있다.

## 6. 개선 권고 (점수 근거로 쓰지 않음)

- 교정문에서 "이 연구는"이 두 번, "자료"가 세 번 되풀이된다. O2의 주어를 생략하거나 O1과 O2를 한 문장으로 묶는 방법도 있다. 이것은 선택 사항이고 감점하지 않았다.
- 익명 심사용 대안 문구의 "[심사용 익명 처리]" 표기는 학술지마다 방식이 다르다. 확인 요청 3과 연결해 두면 저자가 찾기 쉽다.
