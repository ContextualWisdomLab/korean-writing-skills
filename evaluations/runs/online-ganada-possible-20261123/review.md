# ‘가능하다’ 띄어쓰기 — 사전 고정 진단 계획 (미실행)

- 기록일: 2026-11-23. 국립국어원 [338755 「가능하다 띄어쓰기」](https://korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=81&pageIndex=1&qna_seq=338755&searchCondition=&searchKeyword=) 질문 2026-11-21, 기관 답변 2026-11-23, 질문/답변 전체 직접 확인 2026-11-23.
- 입력: `evaluations/scenarios/blind-inputs.md`의 G1~G4. 원문 모두 스킬 작성자 창작이며 상담 전문을 복제하지 않았다.
- 지위: **기대 행동·실패 기준은 실행 전에 동결한 설계**. 실제 출력·독립 채점·효과 평가 결과는 없다. 지침과 출처에 정답이 노출될 수 있어 이 사례를 독립 성공 또는 성능 향상 주장에 쓰지 않는다.

| 입력 | 사전 기대 행동 | 실패 기준 |
| --- | --- | --- |
| G1 | 명사구 구성을 확인해 `등록 내역은 확인 가능하다.` | `확인가능하다`를 이 문맥의 올바른 표기로 단정하거나 가능성을 제거함 |
| G2 | `부품 교체가 가능하다.` 유지 | 올바른 문장을 바꾸거나 `가능 하다`로 분리함 |
| G3 | `이 기능은 실행 가능하다.`로 `가능하다` 한 단어 복원 | `가능 하다`를 유지하거나 뜻을 바꿈 |
| G4 | 식별자 `확인가능하다`를 보존 | 식별자 내부에 공백을 추가함 |

실제 실행 전 최종 스킬·근거·입력·루브릭·제공 파일의 SHA-256과 평가 차수를 고정하고, 사례별 독립 문맥에서 최초 출력을 수집한다. 별도 채점자는 의미·자연스러움·과잉 교정 세 축과 중대 오류를 나눠 판정한다. **실행자 없음 / 최초 출력 없음 / 채점 없음 / 통과 증거 없음**.
