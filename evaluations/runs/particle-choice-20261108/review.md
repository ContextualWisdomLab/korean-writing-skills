# ‘이/가’와 ‘은/는’ 선택 지침 검토

확인일: 2026-11-08. 기준판: `70b3a9ced7a102c2bda73d0d8ea3b7dd33c152c2`.

## 변경과 근거

기존판에는 두 조사의 일반적인 사용 우선순위가 없었다. 이번 보강은 공식 문법 설명과 편집자의 판단 순서를 구별하고, 문장 관계·질문·구체적인 대조와 설명을 확인한 뒤 조사를 선택하도록 명시한 것이다. ‘이/가를 먼저 선택하고 화제·대조가 있으면 은/는으로 바꾼다’는 절차를 채택하지 않는다.

직접 열람한 국립국어원 상담 3건과 한국어기초사전 항목, 한송화(2017)와 Park·Yeon(2024)의 해당 본문은 스킬의 [출처 장부](../../../skills/korean-editing/references/source-ledger.md)에 확인 범위를 기록했다. 조사 정의에서 보편적인 사용 순위를 도출하지 않으며, 저자 분석을 학계 전체의 합의나 맞춤법 규정으로 확대하지 않는다.

## 독립 내용 검토

작성자와 다른 검토자가 조사 선택 문서·본문 진입점·점검표·문장 수리 연결·새 출처 항목을 읽고 원문과 대조했다. 기능 설명의 과잉 일반화, 내부 충돌, 예문 자연스러움, 출처 귀속에 관해 수정이 필요한 오류를 발견하지 못했다.

선택적 보완 두 건을 반영했다. ‘주어를 표시하는 기본형’을 ‘주격 조사 용법’으로 바꾸어 담화적 기본값과 혼동하지 않게 했고, ‘비용은 적다’에서 다른 측면이 나쁘다는 사실도 임의로 추가하지 못하도록 명시했다. 검토자가 두 변경을 실제 파일에서 다시 읽고 통과 판정을 유지했다. 이 판정은 내용 검토이며 일반적인 교정 성능 평가가 아니다.

## 적용 점검의 독립성과 범위

- 별도 설계자가 대상 스킬·작성자 출력·이전 평가를 보지 않고 [입력](input.md)과 [기준](criteria.md)을 만들었다.
- 입력·기준·스킬 파일 해시를 실행 전에 [동결 기록](freeze.json)과 [스킬 명세](skill-manifest.json)에 남겼다.
- 실행자에게 새 문맥에서 동결한 스킬 복사본과 원시 입력만 제공했다. 기준·예상 답·다른 출력은 제공하지 않았다.
- 설계자와 실행자는 다른 역할이다. 설계자가 원시 입력·동결 기준·실제 출력만으로 채점하며 대상 스킬 초안을 보지 않는다.
- 안내문과 예문 8개를 묶은 **한 합성 과제(n=1)**다. 여덟 독립 표본이나 기존판 대비 성능 실험으로 계산하지 않는다.

## 적용 결과

[최초 출력](output.md)을 변경 없이 보존했다. [별도 채점](scoring.md)은 의미 보존 3, 한국어 자연스러움 3, 과잉 교정 억제 3으로 내부 수용 기준을 충족한다고 판정했고 중대 오류는 없었다. 승인자를 묻는 1번은 ‘팀장이’로 고쳤으며, 2–8번은 질문·화제·절·조건·검토 범위에 맞는 원문을 유지했다. 수정 개수를 성능 지표로 계산하지 않는다.

입력·기준·출력 해시와 눈가림 범위를 확인했다. 공개 채점문에서는 파일 정보의 경로 세 곳만 저장소 상대 파일명으로 바꾸었고 판정·근거는 보존했다. 원본과 공개 채점문 해시를 [결과 기록](result.json)에 함께 남겼다. 한 과제의 판정이며 기존판 대비 개선 폭이나 일반적인 효과를 입증하지 않는다.

## 자동 검사

Python 3.14 환경에서 `uv sync --locked --python 3.14`와 기존 `unittest` 검사 152개를 실행해 통과했다. 스킬 구조와 출처 ID 연결도 통과했다. 스킬 본문·참조 파일이 동결한 15개 파일의 해시와 일치함을 확인했다. 이 기록을 포함한 최종 판본의 공개 파일 검사와 `git diff --check`도 통과했다. GitHub의 검사·제출된 리뷰·병합 상태는 해당 PR에서 별도로 확인하며 로컬 통과로 대체하지 않는다.
