## A·B·C 점검

| 지점 | 판정과 근거 종류 |
| --- | --- |
| A: `r = 0.42` | `.42`로 선행 0 생략. 값 유지. APA 규정(Manual 6.36). |
| A: `p = 0.000` | `< .001`로 표기하고 원출력 확인 요청. 정확한 값을 발명하지 않음. APA 규정·공식 안내(6.36, A-NUM). |
| A: `R² = .18` | `.18` 유지. APA 규정(6.36). |
| A: `b = 0.31`, `SE = 0.08`, `M = 6.8`, `SD = 1.1` | 선행 0과 값 유지. APA 규정(6.36). |
| A: `M`·`SD` 정의 | 정의 문구 삭제. APA 규정(6.44). |
| A: `95% CI` | 첫 사용에 `신뢰구간(CI)`로 풀이. APA 공식 안내(A-NUM). |
| A: `위의 표와 같이` | `표 1`로 지시. 입력에 있는 표 번호 사용. APA 규정(7.5). |
| A: 표·본문 중복 | 본문 계수 나열은 유지했으나 확인 요청과 축소 대안을 제시함. 표 미제공 상황에서 허용. APA 공식 안내(A-NUM)와 편집 판단. |
| B: 현재형 자기 서술 | `검토한다`, `사용한다`로 충족. 저자 요구이며 APA 시제 규정으로 주장하지 않음. |
| B: 학위논문 쪽수 | 본문에서 삭제. 저자 요구. |
| B: 이전 연구 자료라는 출처 | 본문에서 삭제하고 확인 요청에도 옮기지 않아 미충족. 원문 첫 문장의 출처 사실이 사라짐. 저자 요구와 의미 보존 문제. |
| B: 2021년 10월 수집 | `수집된 자료`로 완료된 수집 사실과 시점 보존. 편집 판단. |
| C: 중대 오류 | 없는 결과·검정·수치·표본 특성·IRB·학술지 정보를 만들지 않았고 상관을 인과로 강화하지 않음. 지정 수치 변경 없음. |

## 세 축 점수

| 축 | 점수 | 점수 근거 |
| --- | --- | --- |
| 의미 보존 | **1/3** | “석사학위논문 … 자료를 활용하였다”가 본문에서 빠졌고 확인 요청으로도 이동하지 않았다. 자료가 이전 연구에서 왔다는 출처·범위의 중요한 누락이다. 나머지 수치·분석명·수집 시점은 유지됐다. |
| 한국어 자연스러움 | **3/3** | “본 연구는 … 본 연구에서는”을 “이 연구는 … 검토한다. 분석에는 … 사용한다”로 정리해 방법 문단이 매끄럽다. 결과 문단도 표 번호와 지표 설명이 자연스럽게 이어진다. |
| 과잉 교정 억제 | **2/3** | `R² = .18`과 계수 값처럼 유지할 부분을 보존하고 저자 요구를 APA 규정과 구분했다. 다만 자료 출처까지 삭제한 편집은 요청 범위를 넘었다. |

## 판정

**실패.** 의미 보존이 내부 통과 경계인 2점에 못 미친다. 세 축의 합산이나 평균은 적용하지 않았다. 접근 범위 위반은 자기보고상 없으므로 보류 사유는 없다. 이 판정은 제공된 기준표에 따른 독립 평가이며 APA 원문 자체는 허용 파일 범위 때문에 직접 재열람하지 않았다.
