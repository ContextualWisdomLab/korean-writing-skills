# C02 처리 결과

## C02-01 — 수정
시설팀은 장비 상태를 점검하고 이용자 문의에 답했다.

- 이유: `장비 상태`는 공유 서술어 `답했다`와 호응하지 않는다. 문맥에 명시된 완료 업무 `장비 상태 점검`에 따라 `점검하고`를 복원했다. 담당(시설팀)과 두 업무는 그대로 두었다.

## C02-02 — 수정
보수팀은 안내판을 나사 세 개로 로비 벽에 고정했다.

- 이유: 서술어가 빠져 문장이 끝나지 않았다. 문맥에 작업 내용이 `고정`, 상태가 `완료`로 명시되어 있어 `고정했다`를 복원했다. 수량(나사 세 개)과 위치(로비 벽)는 보존했다.

## C02-03 — 수정
시연자는 “센서를 바꾸면 오차가 절반으로 줄 수도 있다”라고 설명했다.

- 이유: `설명은 … 말했다`는 주어와 서술어가 호응하지 않는다. 발언 주체인 시연자를 주어로 두고 원문의 `설명` 뜻을 서술어로 살렸다. 따옴표 안 직접 인용과 가능성 표현(`줄 수도 있다`)은 바꾸지 않았다.

## C02-04 — 유지
반납된 출입증은 점검 뒤 보안실에 보관되었다.

- 이유: 보관 행위자가 기재되지 않은 문맥의 피동문으로 온전하다. 행위자를 만들어 능동으로 바꾸지 않았다.
