# C04 교정 결과

## 교정한 전문

나루자료관은 보존용 파일과 열람용 파일을 구분해 관리한다. 보존용 파일은 입수 당시의 상태를 그대로 유지하고, 열람용 파일은 검색과 화면 열람에 맞게 변환한다. 열람용 파일에서 글자가 흐리게 보이더라도 보존용 파일을 덮어쓰지 않는다. 변환 과정에 문제가 있는지 확인한 뒤 열람용 파일을 다시 만든다. 이렇게 구분하는 것은 원본성을 보장하기 위해서이며, 이용자가 보존용 파일을 직접 내려받을 수 있다는 뜻은 아니다.

열람 허가와 복제 허가도 서로 다른 절차다. 열람 허가를 받았다고 해서 복제 허가까지 받은 것은 아니다. 복제를 원하는 이용자는 별도의 신청서를 내야 하며, 신청서를 냈다고 해서 복제 허가가 난 것도 아니다. 담당자는 자료마다 기증자가 정한 이용 조건을 확인한 뒤 허가 여부를 통지한다.

공개 동의가 철회되면 열람용 파일의 공개를 중단한다. 다만 보존용 파일의 처리 여부는 기증 계약에 따라 따로 검토한다. 공개 중단과 보존 중단을 같은 조치로 설명해서는 안 된다.

이용 안내문에는 열람 허가의 범위와 복제 허가의 범위를 각각 적는다. 두 절차에서 공통으로 요구하는 연락처는 한 번만 입력하도록 하며, 이 방식은 기존 이용자에게도 적용된다.

한편 자료관은 사전 교육을 받은 신규 이용자와 외부 연구자에게 다음 달부터 원본 열람을 허용한다고 공지했다.

## 확인 질문

1. 마지막 문장의 `사전 교육을 받은 신규 이용자와 외부 연구자`에서 `사전 교육을 받은`이 신규 이용자에게만 걸리나요, 외부 연구자에게도 걸리나요? 두 가지로 읽힐 수 있어 원문 표현을 그대로 두었습니다. 답에 따라 `외부 연구자와, 사전 교육을 받은 신규 이용자`나 `사전 교육을 받은 신규 이용자와 사전 교육을 받은 외부 연구자`처럼 고칠 수 있습니다.
2. 같은 문장의 `원본 열람`이 앞에서 말한 `보존용 파일`의 열람을 뜻하나요, 아니면 실물 원본 자료의 열람을 뜻하나요? 앞부분에서 보존용 파일의 직접 내려받기는 허용하지 않는다고 했으므로, 그 관계를 독자가 헷갈리지 않게 하려면 대상을 확인해야 합니다. 확인 전까지 `원본 열람`은 그대로 두었습니다.

## 주요 변경과 유지

- 문단 나누기(편집 판단): 파일 구분, 열람·복제 허가, 공개 동의 철회, 안내문 작성 방식, 다음 달 공지의 다섯 쟁점으로 나눴습니다. 문장 순서는 바꾸지 않았습니다.
- `이러한 구분은 원본성 보장을 위한 것이며` → `이렇게 구분하는 것은 원본성을 보장하기 위해서이며`: 명사 연쇄를 풀어 읽기 쉽게 했습니다. 목적의 뜻은 같습니다.
- `보존용 파일을 이용자가 직접 내려받을 수 있다는` → `이용자가 보존용 파일을 직접 내려받을 수 있다는`: 행위자가 먼저 나오도록 어순만 바꿨습니다.
- 복제 신청 관련 두 문장은 `-며`로 이었고, `냈다는 사실만으로` → `냈다고 해서`로 바꿔 앞 문장과 같은 틀로 맞췄습니다. 신청서를 내도 허가가 확정되지 않는다는 뜻은 그대로입니다.
- 공개 동의 철회 문장은 둘로 나누고 `다만`으로 예외 관계를 드러냈습니다. 공개 중단은 열람용 파일에만, 별도 검토는 보존용 파일에만 걸리는 범위를 유지했습니다.
- 연락처 관련 두 문장은 `이 방식은`으로 합쳤습니다. 기존 이용자에게도 적용된다는 범위는 그대로입니다.
- 유지: `열람용 파일`·`보존용 파일`·`열람 허가`·`복제 허가`의 반복은 개념을 구별하는 데 필요해 줄이지 않았습니다. `허가 여부`의 대상(복제 허가만인지)은 문맥상 복제 신청 뒤에 나오므로 원문 그대로 두었고 새로 정하지 않았습니다. `변환 과정에 문제가 있는지 확인한 뒤 열람용 파일을 다시 만든다`도 조건을 새로 정하지 않도록 그대로 두었습니다.
