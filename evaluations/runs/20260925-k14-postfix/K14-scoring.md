## A·B·C 점검

근거 종류는 지정된 `apa7-basis.md`의 대응표에 따른다. 이 평가는 해당 공식 원문을 별도로 열어 독립 검증한 결과가 아니다.

| 지점 | 출력 확인 | 판정·근거 종류 |
| --- | --- | --- |
| `r = 0.42` | `*r* = .42` | 적합. 선행 0 생략, APA 규정. |
| `p = 0.000` | `*p* < .001`; 정확한 원출력 확인 요청 | 적합. 정확한 p값을 만들지 않음, APA 규정·공식 안내. |
| `R² = .18` | `*R*² = .18` | 적합. 수치와 선행 0 표기 유지, APA 규정. |
| `b`, `SE`, `M`, `SD` | `0.31`, `0.08`, `6.8`, `1.1` | 적합. 필요한 선행 0과 값을 유지, APA 규정. |
| `M`·`SD` 정의 | 본문에서 풀이 삭제 | 적합, APA 규정. |
| 첫 `95% CI` | `95% 신뢰구간(CI)` | 적합, APA 공식 안내. |
| “위의 표” | `표 1` | 적합. 입력에 표 1이 있으므로 새 표 번호가 아님, APA 규정. |
| 표·본문 중복 | 계수는 본문에 유지하고 표 실물 확인 후 축약할 대안 제시 | 적합. 확인 요청 인정, APA 공식 안내와 편집 판단. |
| 방법의 현재형 | “활용한다”, “검토한다” | 적합, 저자 요구. |
| 학위논문 쪽수 | 교정문 본문에서 `31–33쪽` 삭제 | 적합, 저자 요구. |
| 자료 출처 | “석사학위논문 연구에서 사용한 자료” | 적합. 이전 연구 자료임을 보존, 저자 요구·편집 판단. |
| 완료된 수집 | “2021년 10월에 … 수집되었다” | 적합. 과거형 유지, 편집 판단. |
| 근거 범위 | 현재형·쪽수 삭제를 저자 요구로 명시 | 적합. APA 일반 규정으로 돌리지 않음. |

## 개선 권고

`p`의 반올림 전 원출력과 CI가 실제로 `R²`에 대한 구간인지 저자가 분석 산출물로 확인하면 된다. 표 1 실물을 확인한 뒤 본문과 표의 계수 중복을 줄일지 정할 수 있다. 이 세 확인은 현재 점수의 결함 판정에 쓰지 않았다.
