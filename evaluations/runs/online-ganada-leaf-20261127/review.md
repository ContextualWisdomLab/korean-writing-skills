### 판정 규칙과 판정표 해시 범위

- 사례별 통과에는 세 분석 축 각각 2점 이상과 중대 오류 없음이 모두 필요하다. 여기에 **핵심 기대 행동과 직접 모순되는 답변은 축 점수와 관계없이 해당 사례 실패**로 판정한다. LF3에서 식물의 잎을 나타내는 문맥의 ‘잎’을 모두 반드시 띄어 써야 한다고 답하면 핵심 기대 행동 위반이므로 실패다.
- 표의 ‘실패 조건’ 열은 사례별 충분 실패 조건을 열거하며 분석 루브릭을 대체하지 않고 보완한다. 열거된 조건이 모든 가능한 오답을 망라한다고 보지 않는다. 루브릭은 통과의 필요 조건을, 기대 행동·실패 조건은 사례별 의미 기준과 명시적 실패 예를 제공한다.
- 직접 작성한 설명 예(원문 예문·평가 입력 아님): “식물 이름 뒤의 ‘잎’은 언제나 띄어 써야 한다.”는 LF3 기대 행동과 정면으로 모순되므로 실패다.
- 판정 규칙 SHA-256 범위: 위의 세 판정 규칙 문단 전체(사례별 통과 기준, 실패 조건 열의 역할, 직접 작성한 설명 예), UTF-8 바이트·LF 줄바꿈·세 번째 문단 뒤 LF 1개 포함. 이 해시 안내와 판정표 해시 범위 설명은 제외한다.
- 판정 규칙 SHA-256: `9693aef0bb1b8d391ddc9c9481e989babc66ae40e3c7ab828335c9818fdb66d8`.
- 이 판정 기준은 독립 실행 전에 보완했다. 기존 실행·채점 결과는 없으며 결과를 소급 재분류하지 않는다.
- 판정표 SHA-256 범위: `| 입력 |` 머리행부터 LF3 마지막 행까지의 Markdown 표 전체, UTF-8 바이트, LF 줄바꿈, 마지막 행 뒤 LF 1개 포함, 다음 빈 줄 제외.

## 실행 계약과 한계

- 이 입력과 판정 기준은 지침·출처 장부에 핵심 판단이 공개된 **비블라인드 진단 설계**다. 독립 블라인드 점수나 일반적인 교정 성능의 근거로 쓰지 않는다.

- **현재 상태: 설계만 완료. 독립 실행 0건, 별도 채점 0건, 통과 판정 없음.** 기존 N-20261126-malda ML1–ML5도 독립 실행 0건·별도 채점 0건이며, 이를 대신하지 않는다.
