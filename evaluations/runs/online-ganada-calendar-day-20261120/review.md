# 날짜·기간 ‘며칠’ 교정 과제 M1–M4 — 2026-11-20 입력·판정 기준 동결

## 출처·검증 지위

- 국립국어원 온라인가나다 [338655](https://www.korean.go.kr/front/onlineQna/onlineQnaView.do?mn_id=201&pageIndex=1&qna_seq=338655), 질문일 2026-11-18, 공식 답변일 2026-11-20, 답변 최초 확인 2026-11-20; 한국어 어문 규범 [한글 맞춤법 제27항 [붙임 2]·해설](https://www.korean.go.kr/kornorms/regltn/regltnView.do) 해당 절을 별도 직접 열람했다.
- 아래는 **평가 실행 전에 고정한 직접 쓴 가상 과제와 사전 판단**이다. 실행 출력·별도 평가자 채점·독립 제출 리뷰·반복 측정 결과는 **아직 없다**. 정답이 실행자에게 제공할 출처 장부·지침에 노출될 수 있으므로 **M1–M4를 블라인드 독립 성공 점수에 포함하지 않는다**. 교육·회귀 진단용 기준선이다.
- 실제 독립 평가를 주장하려면 사전에 과제 설계자와 실행자/평가자를 분리하고, 실행 직전 스킬·전달 파일과 과제·루브릭 SHA-256, 원본 입력·출력·실행 모델/환경, 개별 독립 채점·의견을 남긴 뒤 다른 미노출 입력으로 재검증한다. 이 기록은 검증 통과 증거가 아니다.

## 동결 입력·사전 기준

| ID | 고정 입력(직접 쓴 문장) | 사전 기대 행동 |
| --- | --- | --- |
| M1 | 다음 점검은 12월 몇 일에 시행하나요? | 날짜 표현 ‘몇 일’을 ‘며칠’로 고치되 월·질문과 시제는 유지한다 |
| M2 | 이번 조사에는 몇 일이 걸렸습니까? | 기간 표현 ‘몇 일’을 ‘며칠’로 고치되 소요 시간 수치를 새로 만들지 않는다 |
| M3 | 점검 일정은 며칠 연기됐다. | 바른 ‘며칠’과 원래 불확실한 기간을 유지한다 |
| M4 | 계약은 몇 년 동안 이어졌는지 모른다. | ‘몇 년’은 보존하고 원문에 없는 기간·계약 사실을 만들지 않는다 |

별도 문헌의 직접 인용, 원본 제목, 명칭·파일명은 정규식으로 조용히 치환하지 않는다. 상담의 ‘몇+일’ 구성이 [며딜]로 발음될 **이론적 가능성**을 표준어 표기 허용으로 승격하지 않는다.

## 실행·채점

- 실행 여부: **미실행**. 원시 출력: 없음. 독립 채점: 없음. 실제 성공률: 산출 불가.
- 기준: 표기 정확성, 날짜·기간 의미 보존, 허용형·인용·고유명 보존, 확정되지 않은 정보 추가 금지. 추후 실행은 이 동결본을 수정하지 않고 별도 차수·결과 파일에 기록한다.
