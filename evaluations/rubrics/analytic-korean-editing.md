# 분석적 한국어 퇴고 루브릭 (논문·Standards 근거, 잠정)

고정 시점: 평가 실행 전. 작성자 정답·초안 SKILL 본문 비공개. 근거 장부: [rubric-source-ledger.md](../references/rubric-source-ledger.md).

## 설계 결정과 문헌 한계

| 출처 | 가져온 것 | 적용하지 않은 것 |
| --- | --- | --- |
| R-KIM2010, R-AHN2026 | **분석적** 다차원·descriptor 구체화·채점자 신뢰도 **검증 필요성** | L2 학습자 작문 표본, ICC/FACETS 수치, 합격선 |
| R-KSL2019 | 준거 예: 내용·짜임·어휘·문장·맞춤법 | 6단계 점수·Rasch calibration |
| S-STD2014 | scoring rubric, PLD, cut score·standard setting **용어 구분** | 운영 cut score, Standard 5.21 절차 전체 이행 |
| P-SONG2013 등 | 행위자·생략 주어 **담화 조건** | 작문 점수 항목으로의 직접 calibrate |
| three-axis (기존) | 0–3 PLD, 사례 통과 규칙 | 합산 점수·가중치 |

**전이 한계**: 학습자 작문 연구의 “우수/미흡” 기술을 **전문가 학술·운영 보고 퇴고**에 그대로 쓰지 않는다. 본 루브릭은 **편집 행동** 평가.

## 수준별 기술 (M1 예시; 타 항목은 three-axis PLD에 위임)

**M1 — 의미 보존**

- **3**: M1 대조표 모든 앵커 일치; ‘가능/추정/필요’ 강도 유지.
- **2**: 핵심 유지, 경미한 모호 1–2处.
- **1**: 범위·조건·용어 중 하나 이상 **중요** 변경.
- **0**: M1 중대 오류(날조·뒤집기) — `three-axis.md` 중대 오류 목록.

**M2 — 행위자 (운영 보고·K6)**

- **3**: 다른 worker 행위에 담당자 명시; pending vs pass 구분.
- **2**: 모호하나 오해 가능성 낮음.
- **1**: `확인했습니다`만으로 코디네이터 수행으로 읽힘.
- **0**: 행위자 날조.

**V1 — 피동·사동 (K5)**

- **3**: `삭제되었다` 등 행위자 불명 피동 유지; `건너뛰었다`→행위자 분명 시만 능동.
- **1**: `보여졌다`→`보였다` 등 **문맥 없이** 일괄; 수량 해석 변경(M-HEO1).
- **0**: 책임·인과·가능성 왜곡.

## 경계·반례 (채점 시 필수 확인)

- `연구팀이 분류했다` → 같은 주어 이어질 때만 생략 가능; 혼동 시 **M2·S1 유지**.
- `위원회에 의해` → 행위자 있으면 능동 **후보**이나 초점 이동 시 **유지**(examples.md).
- 학술 **피동**·익명 행위자: **V1 유지**가 3.
- 사용자 선호(U1): **O1**에서 규정과 분리; 위반만으로 M1 실패 처리하지 않음.

## 블라인드 평가·일치도 기록

- 시나리오: `scenarios/blind-inputs.md` K1–K6, A1–A3.
- 채점: 항목별 판정 + three-axis 0–3 + 통과/실패/보류.
- **일치/불일치**: `runs/`에 평가자별 근거 문장 저장; 불일치 시 루브릭 수정안을 **기록**하되 초기 실패 판정 **덮어쓰지 않음**(`protocol.md`).
- **4/4 통과 ≠ 타당도 확립**; ICC·FACETS·표준 설정 **미실시** 명시.

## three-axis와의 관계

- **three-axis.md**: 실행·채점용 **요약 PLD**(3축).
- **본 파일**: 항목·구성개념·문헌 대응·경계 사례.
- 충돌 시 **의미(M1) > 과잉(O1) > 자연스러움(D1/S1)** 순으로 보류 사유 기록(프로젝트 결정, S-STD2014 특정 조항 아님).
