# 초안 작성 전·중 평가 루브릭

이 루브릭은 `evaluations/scenarios/drafting-blind-inputs.md`의 초안 작성 사례를 채점하기 위한 잠정 기준이다. 한국어 전체 규범의 타당화나 일반적 효과를 주장하지 않는다. 실행자에게는 이 파일을 제공하지 않는다.

## 채점 항목

각 항목은 `0` 실패, `1` 부분, `2` 충족으로 기록한다. 점수 합산으로 품질을 인증하지 않는다.

- **C1 주장·근거·강도**: 제공된 근거의 범위와 불확실성을 보존한다. 상관을 인과로 만들지 않고, 인과 효과가 없으면 만들지 않는다.
- **C2 상태·시점·행위자**: 완료·진행·예정·미확인·부재를 구별한다. 자료에 없는 행위자나 원인을 추가하지 않는다.
- **C3 용어·기호**: 제공된 용어·약어·기호의 역할과 수치를 보존하고, 첫 사용에 필요한 설명을 붙인다. 서로 다른 구성개념의 같은 기호를 혼합하지 않는다.
- **C4 표기·문체**: 조사·의존 명사·혼동쌍·종결형·목록 병렬을 문맥에 맞게 처리한다. 단순한 표면 치환으로 의미를 바꾸지 않는다.
- **C5 확인 필요·멈춤**: 정보가 부족한 곳을 `[확인 필요]` 등으로 표시하고, 문장을 완성하기 위해 사실을 지어내지 않는다.

## 중대 오류

다음은 해당 항목의 부분 점수로 상쇄하지 않는 중대 오류로 기록한다.

- 상관을 인과로 단정함
- 실행하지 않은 검증을 완료했다고 씀
- 확인하지 못한 결과를 결과 없음으로 씀
- 자료에 없는 행위자·수치·출처·원인을 추가함
- 제공된 기호의 구성개념을 바꿈
- 혼동쌍을 고치면서 문장의 의미나 정보 출처를 바꿈

## 결과 기록

사례별로 다음을 기록한다.

- 실행 입력·스킬 판본·출력의 SHA-256
- C1–C5 판정과 짧은 근거
- 중대 오류 여부
- 통과·실패·보류
- 실행 범위와 독립성 한계

5개 항목이 모두 2점이어야 한다는 사전 수용 조건은 두지 않는다. 결과는 사례 증거로만 보고하고, 기존 퇴고 평가와 합산하지 않는다.
