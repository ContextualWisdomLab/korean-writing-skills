# 독립 평가 절차

담당자: 독립 평가 워커(term_0b67ee43-39c9-4806-9d98-26c901d8db4e). 소유 범위: evaluations/.

## 독립성

- 평가 설계자·채점자는 작성자의 정답과 초안 SKILL.md 본문을 읽지 않는다. 경로·준비 여부·파일 해시는 확인할 수 있다.
- 실행자는 새 독립 에이전트로 둔다. 해당 스킬, 관련 근거 파일, scenarios/blind-inputs.md의 담당 사례만 제공한다. 루브릭, 예상 답, 작성자의 설명, 다른 실행 결과, 채점 결과는 제공하지 않는다.
- 출력은 저장소 밖 임시 디렉터리에 만든다. 원본 출력과 실행 범위를 확인한 후 평가 증거만 evaluations/runs/에 복사한다.
- 루브릭과 시나리오의 해시를 실행 전에 기록한다. 실행 후 기준을 바꾸어 통과시키지 않는다.

## 실행과 채점

1. 조정자에게 준비가 끝난 한국어·APA 스킬 경로를 받는다. 초안이 수정 중이면 실행을 기다린다.
2. 스킬 및 참조 파일을 임시 디렉터리에 복사하고 경로별 SHA-256을 기록한다. 이는 실행한 버전의 증거이며 원격 커밋 확인을 대체하지 않는다.
3. 한국어 사례 K1–K4, APA 사례 A1–A3를 각 실행자에게 전달한다. 실행자는 요청별 교정문과 이유 또는 요청된 산출물을 반환한다. 새 사실이나 외부 메시지 발송은 허용하지 않는다.
4. 채점자는 원문과 실제 출력만 대조하여 three-axis.md의 세 점수, 중대 오류 여부, 짧은 근거, 통과·실패·보류를 사례별로 기록한다.
5. 관찰된 실패만 수정 요청으로 전달한다. 재평가가 필요하면 수정 버전과 실행 차수를 별도로 남긴다. 첫 실패 기록을 덮어쓰지 않는다.

완료 기준: 양쪽 스킬을 대상으로 실제 블라인드 실행 1회, 모든 사례별 채점, 실행 입력·버전·출력·독립성 한계 기록. 단일 실행은 일반적 효과나 작성자 대비 성능 향상을 입증하지 않는다.
